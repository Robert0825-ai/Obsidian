## 1. 根上挂脚本

```gdscript
[node name="CemeteryStitch" type="Node2D"]
script = ExtResource("0_script")
```

| 名词 | 人话 |
|------|------|
| `script` | 把 `.gd` 贴到这个节点上 |
| `ExtResource` | 场景开头声明过的外部文件 |

跑起来会先执行脚本的 `_ready`，去找相机、设边界。

## 2. 远景：`Parallax2D`

```
[node name="L1_Far" type="Parallax2D" parent="."]
z_index = -16
scroll_scale = Vector2(0.22, 0.12)
```

| 名词 | 人话 |
|------|------|
| `Parallax2D` | Godot 4 的视差节点。相机关了，它按比例跟着挪 |
| `z_index = -16` | 画在人后面。数字越小越靠后 |
| `scroll_scale` | 乘数。`1` = 跟相机一样快；`0.22` = 只走两成，看起来很远 |
| `Vector2(0.22, 0.12)` | x 慢、y 更慢。跳的时候山几乎不上下晃 |

**语法：** `Vector2(横, 竖)` 两个小数，逗号隔开。点 `.` 是小数点，不是「点谁」。

## 3. 雾：半透明图层

```
[node name="Fog" type="ColorRect" parent="L1_Fog"]
color = Color(0.2, 0.21, 0.26, 0.28)
mouse_filter = 2
```

| 名词 | 人话 |
|------|------|
| `ColorRect` | 一块纯色矩形 |
| `Color(r, g, b, a)` | 红绿蓝 + **a = 透明度**。`1` 不透，`0` 全透。`0.28` 是一层薄雾 |
| `mouse_filter = 2` | 忽略鼠标，别挡住点触屏 |

这就是「透明图层」：不是扣图，是整块颜色带着 alpha。

## 4. 人必须在可走层，前景数字要更大

```
[node name="Play" type="Node2D" parent="."]
z_index = 0

[node name="TestPlayer" parent="Play"]
z_index = 8

[node name="L4_Foreground" type="Parallax2D" parent="."]
z_index = 20
scroll_scale = Vector2(1.22, 1.06)
```

| 行 | 代码 | 作用 |
|----|------|------|
| Play | `z_index = 0` | 可走层在中间 |
| 人 | `z_index = 8` | 人画在地面零件前面 |
| 前景 | `z_index = 20` | 草和藤画在**人前面** |
| 前景 | `scroll_scale = Vector2(1.22, 1.06)` | 走起来比人快，像贴镜头 |

人话：同一帧里，先画山，再画人，再画脚边的草。草会挡小腿，挡不到眼睛（草只放画面下沿，藤挂左右）。

## 5. 相机别看出世界

文件：`scenes/cemetery_stitch.gd`

```gdscript
func _ready() -> void:
	var cam := get_node_or_null("Play/TestPlayer/Camera2D") as Camera2D
	if cam == null:
		return
	cam.limit_left = cam_limit_left
	cam.limit_right = cam_limit_right
```

| 名词 | 人话 |
|------|------|
| `_ready` | 节点进场景后自动跑一次 |
| `get_node_or_null("Play/TestPlayer/Camera2D")` | 顺着路径找相机。找不到就给 `null`，别崩 |
| `as Camera2D` | 告诉电脑：这是相机 |
| `:=` | 声明变量并赋值 |
| `limit_left` | 镜头不能再往左 |
| `@export` | 检查器里能改这四个数，不用改脚本 |

路径里的 `/` 是「这个节点下面的那个」。人被挪进 `Play` 以后，相机路径从 `TestPlayer/Camera2D` 变成 `Play/TestPlayer/Camera2D`。
