# 详细代码解释 · 墓园路面缩放锁定

日期：2026-08-18  
脚本：`C:\Users\yehai\Documents\firebot\scenes\lock_sprite_scale.gd`  
设计：[[设计说明-墓园路面缩放锁定]]

挂在场景树 `Play / Pieces / 陆地 / 路面` 上。

**2026-08-18 后来：** 路面已卸掉此脚本。新路段 PNG 高度不一，锁死 0.24 会一块大一块小。下面仍解释脚本本身，需要再锁时再挂回去。

## 1. 让编辑器里也跑

```gdscript
@tool
extends Node2D
```

| 名词 | 人话 |
|------|------|
| `@tool` | 普通脚本只在按 Play 后跑。加上这行，**编辑器里摆东西时也跑** |
| `extends Node2D` | 这张纸贴在 2D 节点上。`路面` 本身就是 Node2D |

**语法：** `@` 开头是注解，给 Godot 看的标记，不是给玩家看的字。

## 2. 锁成多大

```gdscript
@export var lock_scale := Vector2(0.24, 0.24)
```

| 名词 | 人话 |
|------|------|
| `@export` | 出现在检查器里，点 `路面` 就能改，不用改代码 |
| `lock_scale` | 锁定的缩放。横 0.24、竖 0.24，和现在地面一致 |
| `Vector2` | 两个数：x 和 y |
| `:=` | 声明变量并马上给默认值 |

**人话：** 孩子们的 Scale 必须等于这两个数。你改检查器里的 `lock_scale`，整条路面一起变。

## 3. 进场景时先对齐一次

```gdscript
func _ready() -> void:
	_snap_children()
```

| 名词 | 人话 |
|------|------|
| `_ready` | 这个节点进树后 Godot 自动叫一次 |
| `_snap_children` | 我们自己起的名字：把孩子的大小掰回去 |
| `-> void` | 这个函数不返回值 |

## 4. 编辑器里每一帧再看一眼

```gdscript
func _process(_delta: float) -> void:
	if Engine.is_editor_hint():
		_snap_children()
```

| 名词 | 人话 |
|------|------|
| `_process` | 每一帧调用。你拖角的那一下，下一帧就会被掰回来 |
| `_delta` | 离上一帧过了多少秒。前面下划线 = 这个值我不用 |
| `Engine.is_editor_hint()` | 现在是不是在编辑器里。是才每帧检查，玩游戏时不空转 |

**语法：** `if` 后面条件为真才跑缩进的那一行。`.` 表示「谁的什么」：`Engine` 这个对象上的 `is_editor_hint`。

## 5. 真正掰回去

```gdscript
func _snap_children() -> void:
	for child in get_children():
		if child is Sprite2D:
			var sprite := child as Sprite2D
			if sprite.scale != lock_scale:
				sprite.scale = lock_scale
```

| 名词 | 人话 |
|------|------|
| `get_children()` | `路面` 下面那一层孩子：GroundLeft、DirtLip… |
| `for child in …` | 一个一个拿出来 |
| `is Sprite2D` | 是图才管。夹子节点不管 |
| `as Sprite2D` | 告诉电脑：把它当精灵用，才能改 `scale` |
| `!=` | 不等于 |
| `sprite.scale = lock_scale` | 写回 0.24 |

**人话：** 只改大小，不改 `position`。所以你拖着地面左右挪，坐标会变，Scale 不会。
