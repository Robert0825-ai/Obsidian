## 你的直觉对在哪

PC 上「按住 A/D 再按 S」很自然：一只手 WASD 全包。

手机上左拇指已经按着 ◀▶：

- 再去点旁边的「下/滑」= **同一根拇指要同时干两件事**（或两指挤在左下角）  
- 很容易松方向、点空、误触  

所以：**大多数横版/动作手游，不会把「滑铲」做成方向键旁边的组合键。**

---

## 行业里常见怎么拆这三件事

### 1）冲刺（Dash）和闪避（Dodge）——经常是同一个键

| 做法 | 说明 | 常见于 |
|------|------|--------|
| **右侧一颗「冲/闪」** | 点一下：朝面向或摇杆方向猛冲一小段，常带无敌帧 | 横版动作、类银河、许多动作 RPG 手游 |
| **冲 = 闪** | 不做两颗键，避免右手按钮爆炸 | 独立游戏 / 精简操作 |
| **双击方向闪避** | 左摇杆/方向区快速双击 ←/→ | 部分格斗、魂like 移植 |
| **技能轮盘里的闪避** | 闪避当技能 CD | MMO、一部分动作手游 |

**firebot 当前选择：** `Dash` = 冲刺兼闪避（PC：Shift/C；手机右侧「冲」）。  
以后若要「短闪避」和「长冲刺」分开，再拆成两个动作也不迟。

### 2）滑铲（Slide）——手机几乎都是「独立一键」或「手势」

| 做法 | 怎么触发 | 优缺点 |
|------|----------|--------|
| **A. 右侧独立「滑」键** | 点一下，朝**当前面向**滑 | 最好学、最好点；firebot **已改成这路** |
| **B. 左摇杆向下滑/轻扫** | 在移动区 swipe down | 省按钮；新手可能不会 |
| **C. 跑动中点「蹲」自动滑** | 移动时点蹲=滑铲 | 要先跑起来，手感看调参 |
| **D. 复制 PC：按住方向再点下** | 左下组合键 | **最别扭**，少见作为主方案 |

跑酷类（地铁跑酷、Temple Run）：常用 **下滑手势 = 滑铲/俯身**，因为没有复杂攻击键。  
横版动作带攻击的：更常见 **右手「滑」独立键**。

### 3）典型屏幕分区（横版）

```text
┌─────────────────────────────────────┐
│                                     │
│              游戏画面                 │
│                                     │
│   (○ 摇杆)           跳  攻          │
│  上爬/下爬/左右       冲  滑          │
│                     （技能/闪在右）    │
└─────────────────────────────────────┘
```

口诀：

- **左手 = 去哪**（圆形摇杆：走 + 上爬/下爬）  
- **右手 = 干什么**（跳、打、冲、滑）  
- **不要**让「干什么」挤回左手方向区里搞组合键（除非你做纯跑酷手势）  
- firebot 左侧已改为圆形摇杆（`virtual_joystick.gd`），不再用方块 ◀▶

## firebot 现在怎么对齐这个习惯

| 平台 | 滑铲 | 冲刺/闪避 |
|------|------|-----------|
| **PC** | 仍可：按住左右 + S（熟悉键位） | Shift / C → `Dash` |
| **PC 备选** | Ctrl（动作名 `Slide`）也可单独滑 | 同上 |
| **手机** | 右侧独立 **「滑」** → `Slide`，朝面向滑，**不必按住方向** | 右侧 **「冲」** → `Dash` |

玩家脚本（`sword_player.gd`）两种触发都认：

1. `Slide` 刚按下 → 滑  
2. 或：`Down` 刚按下且正在按左右 → 滑（PC 习惯）

虚拟键：`Scene/ui/touch_controls.tscn`  
左：圆形摇杆（`virtual_joystick.gd`，上爬/下爬/左右）；右：跳 / 攻 / 冲 / 滑。

## 以后还可以升级的方向（先知道即可）

1. **左摇杆代替 ◀▶**（摇杆更像商业手游，实现稍难点）  
2. **在移动区下滑 = 滑铲**（跑酷手感）  
3. **冲与闪拆开**：短无敌闪 / 较长位移冲  
4. **自定义键位界面**（玩家自己拖按钮）——中后期再做  

现阶段：独立「滑」+「冲=闪」已经够用，也符合大多数玩家预期。

## 问答记录

### Q：感觉滑铲在方向键旁边，手游做不到？（2026-08-11）

**答：** 对。手游通常不把滑铲做成「方向区组合键」，而是：

- 右手独立「滑」，或  
- 移动区下滑手势，或  
- 跑动中点蹲自动滑。  

冲刺/闪避多在右手，且常常合并成一键。  
工程已把手机滑铲改为右侧独立「滑」。

### Q：摇杆推到左下/右下也会滑铲，别的游戏也这样吗？（2026-08-11）

**答：一般不会。** 那是 bug/串台，不是市面设计。

原因：玩家脚本里曾有「`Down` + 左右 = 滑铲」（给 PC 的方向+S 用）。  
圆形摇杆推斜下时会同时注入 `Down` + `Left`/`Right`，被误判成滑铲。

**市面常见：** 摇杆斜下 = 仍在移动/下蹲/向下爬，**不会**自动滑铲；滑铲靠右手键或下滑手势。

**已修：** 组合滑铲仅当物理键 `S` 或 `↓` 按下时才生效；摇杆注入的 `Down` 不再触发滑铲。手机请用右侧「滑」。
