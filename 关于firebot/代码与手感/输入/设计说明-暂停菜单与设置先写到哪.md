## 设计原因

测试场是给 **PC + 手机** 用的。只写键盘，手机上没有摇杆、没有跳/冲按钮，等于没测到真机操作。

Esc 暂停要尽早有：继续、退出。设置可以先开一个门，**不要**第一天就做完整改键界面。

| 现在写 | 以后写 |
|--------|--------|
| 左摇杆 + 右 跳/攻/冲/滑 + 右上暂停 | 音量、画质、语言 |
| Esc / 暂停键 → 变暗、停物理 | 点一下就改键的侦听界面 |
| 设置页展示默认键位 | 存玩家自定义键到 `user://` |

改键现在走 Godot 自带的 **项目 → 项目设置 → 输入映射**。那就是引擎已经做好的改键面板。自己再做一个，等于检查器之外再造一层，和「先不要写数值插件」是同一类提前量。

## 改动清单

| 文件 | 做什么 |
|------|--------|
| `ui/virtual_joystick.gd` | 圆形摇杆，注入 `Left` `Right` `Climb` `Down` |
| `ui/touch_controls.gd` / `.tscn` | 右下四键 + 右上暂停；电脑上也显示方便试 |
| `ui/pause_menu.gd` / `.tscn` | Esc 暂停；继续 / 设置 / 退出 |
| `scenes/test_rig.tscn` | 挂上上面两块 |
| `project.godot` `[input]` | **没改键**：方向键仍在，冲刺仍是 Shift 或 C |
| `player/test_player.gd` | **没改**：仍然只听动作名 |

故意没动：滑铲公式、攻击、改键侦听、导出安卓包。攻/滑按钮已经接到动作名，灰盒角色暂时还没用这两下。

## 数据流（人话）

```text
键盘 Shift / 键 C / 屏幕「冲」
        ↓
   动作名 "Dash"
        ↓
   test_player.gd 里 is_action_just_pressed("Dash")
```

手机和电脑走同一条水管。玩家脚本不写 `KEY_SHIFT`。

暂停：

```text
Esc 或屏幕「暂停」→ 动作名 "Pause"
        ↓
pause_menu.gd 把 get_tree().paused = true
        ↓
玩家物理停；菜单 process_mode = ALWAYS，还能点
```
