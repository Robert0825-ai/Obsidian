## 一张图看懂两种特效

![两种特效对比](C:/Users/yehai/.cursor/projects/c-Users-yehai-Documents-godot-2d/assets/firebot-burst-two-styles.png)

（若你把图拷进本库 `关于firebot/attachments/`，也可写成：`![[attachments/firebot-burst-two-styles.png]]`）

| 名字 | 长什么样 | 适合干什么 |
|------|----------|------------|
| **时间停滞** | 身后留下 4～5 个彩色**角色残影** | 特殊技能、演出感强的滑铲/大闪避（边缘行者那种） |
| **疾风线** | 身后刷出一束**速度线**，没有人影残影 | 日常冲刺、滑铲、普通闪避（更干净，身位好认） |

**我替你定的默认建议（你可改）：**

- **闪避 / 普通冲刺 / 普通滑铲** → 用 **疾风线**
- **要「时间被拽住」的演出** → 用 **时间停滞**（可再打开慢动作）

原因：闪避要看清自己在哪；残影太多时，新手容易看花。大招再用残影更爽。

## 怎么切换（不用改代码）

![检查器切换说明](C:/Users/yehai/.cursor/projects/c-Users-yehai-Documents-godot-2d/assets/firebot-burst-inspector-guide.png)

1. 打开 `Scene/sword_player.tscn`（场景在 Scene 文件夹；脚本仍在 `Sprite/`）
2. 点根节点 **`Sword_Player`**
3. 右边检查器找到 **Burst Visual → Visual Style**
4. 选：
   - `Time Stop` = 时间停滞（残影）
   - `Speed Lines` = 疾风线
   - `None` = 只有位移 + 无敌，无特效
5. `F5` 运行试手感

**调残影个数 / 颜色：**  
选中子节点 `Effects/TimeStopAfterimage`，改 Count、Spacing、Colors、Use Slow Mo。

**调线条粗细 / 颜色：**  
选中 `Effects/SpeedLines`，改 Line Count、Length、Width、Color；要彩色线就勾 `Use Rainbow`。

## 文件在哪（即插即用结构）

```
Sprite/
  sword_player.tscn          ← 角色场景（已挂好 Effects）
  sword_player.gd            ← 位移 / 无敌帧 / 切换特效
  effects/
    burst_effect.gd          ← 特效基类（别删）
    timestop_afterimage_effect.gd   ← 时间停滞
    speed_line_effect.gd            ← 疾风线
```

以后要第三种特效（比如只闪白）：

1. 复制一份 `speed_line_effect.gd` 改逻辑  
2. 挂到 `Effects` 下当子节点  
3. 在 `sword_player.gd` 的 `Visual Style` 枚举里加一项  

**移动逻辑和特效是分开的**——换皮不用重写冲刺。

## 无敌帧是什么

冲刺 / 滑铲过程中 `is_invincible = true`：

- 角色会轻微闪烁  
- 以后写挨打逻辑时调用：`if player.can_take_damage(): ...`  
- 特效换了，无敌帧逻辑不用动

## 性能会不会炸？

不会。这些只是检查器参数 + 每次爆发生成少量节点（几个残影或几根线），立刻淡出删除。  
真正要担心的是「每帧无限 new 几千个」，我们没有这么做。

## 你以后最常做的三件事

1. 选 `Visual Style`（Time Stop / Speed Lines）  
2. 拧距离：`Dash Travel` / `Slide Travel`  
3. 拧特效自己喜欢的颜色和数量  

拧爽了再叫 AI「把当前数字锁成默认值」即可。
