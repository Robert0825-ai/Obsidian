## 这一课要记住的

师傅说「小」，**不是**「做一屏方块应付上架」。  
也**不是**「做成《空洞骑士》那么大」。

是三档里的中间那档：

- **A** 练习：2～8 分钟一条路（给自己跑通）  
- **B** 第一款：一座森林，主线 **20～45 分钟**能通关（你已经选的 Q5）  
- **C** 太大：4～5 个世界、回廊恶魔城（以后再说）

完整数字表在 [[设计说明-第一款有多小]]。本课讲：**怎么自己量、在 Godot 里长什么样。**

## 怎么做（手把手量体量）

1. 打开 Godot，进你要测的那一关（现在可能是空的或 `forest_playable` 一类）。  
2. 手机打开秒表。从出生点玩到你心里的「过关」（第一款过关 = 看到带走 / 线索，不是打完整条蛇史诗）。  
3. 看时间：  
   - **不到 15 分钟**又没有收束 → 还在 A，可以再铺几屏地，**不要加新系统**。  
   - **20～45 分钟**能看到结尾 → 落在 B，这就是第一款该有的小。  
   - **超过 90 分钟**还没结尾 → 往 C 滑了，先砍房间和怪种。  
4. 每想加「背包 / 商店 / 第二种大地图」，问一句：没有它，这座林子还能通关吗？能 → 第一款不做。

## 工程里「小」长什么样

小的第一款，文件夹大概是这样（名字可以不同，**份数**要对）：

```
res://player/cat_player.tscn      ← 玩家只有这一份，所有关卡实例化它
res://levels/forest_01.tscn       ← 第一章主路（或再拆成 2～3 个房间）
res://ui/touch_controls.tscn      ← 手机键，已经有的那套
res://ui/ending.tscn              ← 通关画面（目击带走）
```

太大的第一款会长这样（不要）：

```
res://levels/forest_a.tscn
res://levels/forest_b.tscn
…（二十个互不相通的林子）
res://levels/city_01.tscn
res://levels/factory_01.tscn
res://systems/inventory.gd
res://systems/shop.gd
```

**人话：** 玩家身体只做一份；关卡是「把同一只猫放进不同的地」。第一款的地 = 一座林子，不是五个世界。

## 详细代码解释

这课几乎不改 firebot 代码。要看的是：**通关时工程在干什么。** 下面是「小」的写法，不是要你今晚必须贴进去。

### A. 玩家只有一份

```gdscript
# 关卡 forest_01.tscn 里，把猫拖进来当子节点
# 或代码生成一份：
var cat := preload("res://player/cat_player.tscn").instantiate()
add_child(cat)
```

| 词 | 人话 |
|----|------|
| `preload` | 游戏开始前就把这个场景文件准备好 |
| `instantiate` | 复印一份到当前关卡里 |
| `add_child` | 放到这棵场景树上，才会出现、才会跑 |

**人话：** 八屏林子也是同一只猫。不要为每一屏复制一份 `cat_player.gd`。

**语法点：** `"res://…"` 是工程内部路径，引号包起来。`.` 点的是「对这个对象做什么」。

### B. 走到终点就进通关，不要进下一座城

```gdscript
func _on_forest_exit_body_entered(body: Node2D) -> void:
	if body.is_in_group("player"):
		get_tree().change_scene_to_file("res://ui/ending.tscn")
```

| 词 | 人话 |
|----|------|
| `_on_…_body_entered` | 有东西走进 Area2D 时 Godot 自动叫的函数 |
| `is_in_group("player")` | 确认走进来的是猫，不是一块掉落的石头 |
| `get_tree()` | 整棵游戏树 |
| `change_scene_to_file` | 关掉当前关，打开另一个场景文件 |

**人话：** 第一款的门通向 **ending**（带走、线索），不通向 `city_01.tscn`。城是第 2 款。

**语法点：** `-> void` 表示这函数不把答案交回去。`if` 后面的冒号开始缩进的那一块才在条件成立时跑。

### C. 和「太大」的对比

太大常常是：这个出口去城，城的出口去工厂，工厂再开技能树。  
第一款小：这个出口只去通关图。故事可以暗示「还要去城里找」，**场景文件先不建。**
