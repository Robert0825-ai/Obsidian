## 详细代码解释

路径：`player/test_player.gd`

### A. 这具身体是什么

```1:2:player/test_player.gd
extends CharacterBody2D
## 测试场灰盒角色：走、二段跳、冲。外观以后换成猫，尽量只换 Visual 里的图。
```

| 词 | 人话 |
|----|------|
| `extends` | 我是哪种节点 |
| `CharacterBody2D` | 会走路、会被重力拉、会撞墙的 2D 身体 |

**人话：** 测试场的「人」首先是一块会撞地的身体，不是一张图。

**语法点：** 文件第一行决定它能挂在哪种节点上。

### B. 能在检查器里拧的数字

```4:7:player/test_player.gd
@export var speed := 220.0
@export var jump_velocity := -420.0
@export var dash_speed := 520.0
@export var dash_time := 0.14
```

| 词 | 人话 |
|----|------|
| `@export` | 出现在右边检查器，不用改代码也能拧 |
| `speed` | 左右走多快 |
| `jump_velocity` | 跳起来的向上速度；Godot 里 **Y 往下为正**，所以跳是负数 |
| `:=` | 既定类型又给默认值 |

**人话：** 手感不对，先拧这几个，不要先改整份脚本。

### C. 每一帧在干什么

```18:21:player/test_player.gd
func _physics_process(delta: float) -> void:
	if dash_left > 0.0:
		dash_left -= delta
		velocity.x = float(facing) * dash_speed
```

| 词 | 人话 |
|----|------|
| `_physics_process` | 物理时钟每一拍叫一次，适合移动 |
| `delta` | 这一拍过了多少秒 |
| `velocity` | 身体这拍要往哪滑 |
| `facing` | 1 朝右，-1 朝左 |

**人话：** 还在冲的时候，左右键暂时不管，按面向横着飞一小段。

**语法点：** `func` 开头定义函数。`-> void` 表示做完不交回值。

### D. 跳

```36:39:player/test_player.gd
	if Input.is_action_just_pressed("Jump") and jumps_left > 0:
		velocity.y = jump_velocity
		jumps_left -= 1
```

| 词 | 人话 |
|----|------|
| `Input.is_action_just_pressed` | 这一拍**刚按下**，按住不连跳 |
| `"Jump"` | 输入映射里的动作名，空格键；**不是**键码 |
| `jumps_left` | 落地补回 2，所以能二段跳 |

**人话：** 和第 1 课同一件事。地上跳一次，空中还能再跳一次。

### E. 真正贴地移动

脚本末尾是 `move_and_slide()`。

**人话：** 光改 `velocity` 不会自己走。这句才按速度滑，并处理踩地、撞墙。
