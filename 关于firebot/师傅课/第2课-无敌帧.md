## 这节课要搞懂什么

冲刺/滑铲（或挨打闪白）时，角色可以「暂时打不中」。

**核心不是特效，是一条规则：**

> 有一段时间里，能不能受伤 = 否。

闪烁、残影是「让玩家看出来」；没判断就扣血 = 假无敌。

## 要记住的东西

```gdscript
var is_invincible: bool = false
```

| 值 | 意思 |
|----|------|
| `false` | 可受伤 |
| `true` | 无敌中 |

对外询问：

```gdscript
func can_take_damage() -> bool:
	return not is_invincible
```

- `can_take_damage` = 现在能不能受伤  
- `not` = 取反：无敌为真 → 返回「不能受伤」

---

## 何时打开 / 关掉

```text
开始冲刺或滑铲 → is_invincible = true
动作结束       → is_invincible = false
```

以后「挨打短暂无敌」同样：受伤时开，计时结束关。（计时器可后续再课细讲。）

## 受伤时必须先问

```gdscript
func take_damage(amount: int) -> void:
	if not can_take_damage():
		return  # 无敌：不扣血
	# 这里才扣血、播受击……
```

**常见错误：** 只做闪烁，扣血前不判断。

## 和闪烁的关系

`sword_player` 里无敌时可改 `anim.modulate.a` 做闪烁。

- 无闪烁也可以真无敌（规则在）  
- 只有闪烁、无开关 → 不是真无敌  

第 2 课重点：**布尔开关 + 扣血前检查**。

## 详细代码解释

> 2026-08-11 回填。对照：`Sprite/fighter_player.gd`（F/V 练习）与 `sword_player.gd` 同思路  
> 结构：小段代码 → 名词/小表 → 人话 → 语法点

### 1）无敌开关本身只是一个真/假盒子

```gdscript
var is_invincible: bool = false
```

| 词 | 人话 |
|----|------|
| `var` | 声明一个有名字的盒子 |
| `is_invincible` | 盒子名：现在无敌吗？ |
| `: bool` | 类型：布尔，只能是真或假 |
| `= false` | 默认：不无敌（可以受伤） |

| 值 | 意思 |
|----|------|
| `false` | 关：可受伤 |
| `true` | 开：无敌中 |

**人话：** 无敌帧的「骨头」先是这一个开关。闪白、残影都是皮；没有这个开关被扣血逻辑读到，就不是真无敌。

**语法点：** `bool` 只有两个合法值；赋值用 `=`，判断相等常用 `==`（本课后面用 `not` 更直接）。

---

### 2）对外询问：现在能不能受伤？

```gdscript
func can_take_damage() -> bool:
	return not is_invincible
```

| 词 | 人话 |
|----|------|
| `can_take_damage` | 函数名：问「现在能受伤吗」 |
| `-> bool` | 这个函数会交回一个真/假 |
| `return` | 把后面的结果交出去，并结束函数 |
| `not` | 取反：真变假、假变真 |

**人话：**

- 无敌是 `true` → `not true` = `false` →「不能受伤」  
- 无敌是 `false` → `not false` = `true` →「能受伤」

**语法点：** 为什么不直接在外面写 `if is_invincible`？抽成函数后，以后扣血、陷阱、子弹都问同一句，改规则只改一处。

---

### 3）受伤入口：先问，再扣

```gdscript
func take_damage(amount: int) -> void:
	if not can_take_damage():
		print("挡住了（无敌中），伤害 ", amount, " 无效")
		return
	print("受伤了，伤害 ", amount)
```

| 词 | 人话 |
|----|------|
| `amount: int` | 参数：这次伤害数字；`int` = 整数 |
| `if not can_take_damage():` | 若「不能受伤」为真…… |
| `print(...)` | 在输出面板打字，方便你看见发生了什么 |
| `return` | 立刻结束：后面的「真的受伤」不执行 |

**人话：** 任何伤害都先过安检。安检不通过 → 报「挡住了」并离开；通过 → 才报「受伤了」（以后这里再接扣血、受击动画）。

**语法点：** `print` 多个参数用逗号拼在一行输出；练习阶段用打印代替真扣血，是为了先练「判断顺序」。

---

### 4）练习用按键：假装挨打 / 切换无敌

```gdscript
if Input.is_action_just_pressed("Attack"):
	take_damage(1)
if Input.is_action_just_pressed("Combo"):
	is_invincible = not is_invincible
	print("无敌开关现在是: ", is_invincible)
```

| 词 | 人话 |
|----|------|
| `Attack`（常是 F） | 假装挨一下打，走 `take_damage` |
| `Combo`（常是 V） | 把无敌开关拨到另一边 |
| `is_invincible = not is_invincible` | 新值 = 旧值的反面（开↔关） |

**人话：** 运行中按 V 切换，再按 F 看输出是「受伤」还是「挡住」——这比停游戏改脚本变量好测。

**语法点：** 冒号必须是英文 `:`；中文 `：` 会让脚本语法炸掉。动作名 `"Attack"` / `"Combo"` 要和输入映射一致。

## 问答记录

### Q：第四条练习感觉很奇怪？（2026-08-10）

原题写「手动把 `is_invincible = true`」不适合边玩边测——运行中不能随手改脚本变量。

**更好的测法：**
- `Attack`（F）：调用 `take_damage(1)` → 看输出「受伤了」或「挡住了」
- `Combo`（V）：`is_invincible = not is_invincible` 切换开关 → 再按 F 对比

另外注意：冒号必须是英文 `:`。若写成中文 `：`，脚本会报错/行为异常。
