## 一、这节课要搞懂什么

第 1 课：跳。第 2 课：暂时打不中。  
第 3 课：**冲刺/滑铲时「看起来很快」——那层皮。**

两种皮：

| 名字 | 眼睛看到什么 | 适合 |
|------|----------------|------|
| **时间停滞（残影）** | 身后留下几个半透明「自己」 | 大招、演出 |
| **疾风线** | 身后刷出速度线，没有人影 | 日常冲刺、闪避 |

**重要：** 残影/线条 **不等于** 无敌帧。  
可以：有位移 + 无敌，但选 `NONE` 完全不播特效。  
特效是皮肤；无敌与位移是骨头。

## 三、为啥要拆成「玩家脚本」和「特效脚本」

如果全写在一个巨大的 `player.gd` 里：

- 换残影为线条要改一大坨  
- 调颜色、数量和移动逻辑缠在一起  

所以 firebot 里是：

```text
玩家（sword_player.gd）
  ├─ 负责：走、跳、冲刺距离、无敌开关
  └─ Effects/
        ├─ TimeStopAfterimage  ← 残影
        └─ SpeedLines          ← 疾风线
```

玩家只喊三句话（约定）：

1. `begin_burst` — 爆发开始了  
2. `step_burst` — 这段时间又移动了多少  
3. `end_burst` — 爆发结束了  

特效脚本自己决定：要不要生成影子、生成几个、什么颜色。

这就是「即插即用」：**换皮肤换子节点/检查器选项，不重写移动。**

## 四、基类长什么样（约定菜单）

文件：`Sprite/effects/burst_effect.gd`

```gdscript
class_name BurstEffect
extends Node

@export var effect_enabled: bool = true

func begin_burst(_host: Node2D, _facing: int, _is_slide: bool) -> void:
	pass

func step_burst(_host: Node2D, _facing: int, _moved: float) -> void:
	pass

func end_burst(_host: Node2D) -> void:
	pass
```

| 词 | 人话 |
|----|------|
| `class_name BurstEffect` | 给这种特效起个类型名，方便标注「这是特效」 |
| `pass` | 这里暂时什么都不做（留给子类去填） |
| `_host` | 谁在冲刺（玩家节点） |
| `_facing` | 朝左还是朝右（1 / -1） |
| `_moved` | 这一小段移动了多少距离 |
| 参数名前面的 `_` | 基类里没用到，避免「未使用变量」警告 |

残影脚本、疾风线脚本都是：`extends BurstEffect`，然后**重写**这三个函数。

## 五、残影在干什么（时间停滞）

文件：`Sprite/effects/timestop_afterimage_effect.gd`

### 人话流程

```text
开始冲刺
  → 拍一张「现在的样子」贴在地上（半透明、可换色）
  → 每跑够一段距离，再拍一张
  → 拍满 N 张就停
  → 每张影子慢慢变透明，然后删掉
```

### 关键旋钮

| 参数 | 意思 |
|------|------|
| `afterimage_count` | 一共几张影子 |
| `afterimage_spacing` | 两张之间至少隔多远（越大越好认） |
| `afterimage_lifetime` | 影子存在多久后淡出 |
| `afterimage_colors` | 每张用什么颜色轮换 |
| `use_slow_mo` | 是否额外把全场时间变慢（选修，慎用） |

### 和「复制一张图」的关系

残影不是魔法：

1. 从 `AnimatedSprite2D` 取出**当前帧的贴图**  
2. `new` 一个 `Sprite2D`，设同样位置/翻转  
3. 改 `modulate`（颜色和透明度）  
4. 用 Tween 把透明度收到 0，然后 `queue_free()` 删掉  

所以：**残影 = 短命的复制精灵。**

## 六、疾风线在干什么

文件：`Sprite/effects/speed_line_effect.gd`

### 人话

```text
开始冲刺
  → 在身后画几根短线（Line2D）
  → 移动过程中再刷几束
  → 线很快淡出删除
```

没有「人的剪影」，只有线，所以更干净，适合当日常闪避皮。

旋钮：`line_count`、`line_length`、`line_color`、`use_rainbow` 等。

## 七、玩家怎么「点菜」用哪一种皮

`sword_player.gd` 里：

```gdscript
enum VisualStyle { TIME_STOP, SPEED_LINES, NONE }

@export var visual_style: VisualStyle = VisualStyle.TIME_STOP
```

检查器 **Burst Visual → Visual Style** 三选一。  
冲刺/滑铲开始时：

```text
打开无敌（第2课）
开始移动一段距离
叫当前选中的特效：begin → 多次 step → end
关掉无敌
```

**推荐（可改）：**  
日常冲刺/闪避 → 疾风线；演出大招 → 时间停滞。

```text

  → is_invincible = true          （第2课）
```

## 十一、补课：残影到底怎么「制作」出来（具体操作）

> 2026-08-10 学员反馈：第3课缺「怎么写出来」。本节补上。  
> 2026-08-10 再次反馈：步骤仍太简略。已补「十一-B 手把手从打开 Godot 到看见残影」。

### 11.1 和你看到的时间线怎么对上

```text
按冲刺 → begin（可先拍第1张）
每帧往前冲 → step（每跑够一段距离再拍一张）
路程跑完 → end（停止再拍）
```

**先学会做「一张」残影**；再谈 begin/step 里反复调用。

### 11.2 一张残影的 5 步（骨头级）

1. 从 `AnimatedSprite2D` 取出**当前帧贴图**  
2. `Sprite2D.new()` 做一个临时精灵  
3. 位置/翻转抄角色现在的  
4. `modulate` 改颜色和透明度  
5. Tween 把 `modulate.a` 收到 0 → `queue_free()` 删掉  

最小函数见练习稿：`Sprite/fighter_player.gd` → `spawn_one_afterimage()`  
测试：`my_test` 里按 **W / Climb** 生成一张。

### 11.3 关键代码在说什么

```gdscript
var tex = anim.sprite_frames.get_frame_texture(anim.animation, anim.frame)
```
= 拿「正在播的动画、当前帧」那张图。

```gdscript
var ghost := Sprite2D.new()
ghost.texture = tex
ghost.global_position = anim.global_position
```
= 新建精灵，贴同一张图，钉在世界坐标「此刻所在处」。

```gdscript
get_parent().add_child(ghost)
```
= 挂到场景父节点。这样角色走开后，影子还留在原地（残影感）。

```gdscript
tween.tween_property(ghost, "modulate:a", 0.0, ghost_lifetime)
tween.finished.connect(ghost.queue_free)
```
= 在若干秒内把透明度变成 0，做完删除节点，避免越积越多。

### 11.4 怎样变成「一串」残影（和冲刺连接）

在冲刺逻辑里（第4课路程循环）伪代码：

```text
开始冲：spawn 一张；ghosts_left = N-1；dist = 0
每帧：
  dist += 这一帧移动距离
  若 dist >= 间距 且 ghosts_left > 0：
      spawn 一张
      dist = 0
      ghosts_left -= 1
```

工程里现成实现：`Sprite/effects/timestop_afterimage_effect.gd`。

### 11.5 疾风线差在哪

不复制人物贴图，而是 `Line2D.new()`，加点画短线，同样 Tween 淡出删除。  
文件：`Sprite/effects/speed_line_effect.gd`。

### 步骤 H：代码在干什么（对着函数读）

文件：`Sprite/fighter_player.gd` 函数 `spawn_one_afterimage`

1. `anim` = 角色身上那个会播动画的节点（`@onready var anim = $AnimatedSprite2D`）  
2. `get_frame_texture(...)` = 把「现在这一格动画图片」取出来，放进变量 `tex`  
3. `Sprite2D.new()` = 现场做一个新的图片节点（还没放进场景）  
4. `ghost.texture = tex` = 让这个新节点显示刚才那张图  
5. `ghost.global_position = anim.global_position` = 钉在**世界坐标**里「此刻人站的位置」  
6. `ghost.modulate = ghost_color` = 染色+半透明，看起来不像真人  
7. `get_parent().add_child(ghost)` = 把影子交给**场景**（`MyTest`），不是永远粘在人身上  
8. `tween... modulate:a → 0` = 透明度慢慢变 0  
9. `queue_free` = 淡完删掉，避免场景里堆几千个影子  

**为何挂 parent：**  
若影子是角色的子节点，人一走开，影子会跟着走，就不像「留在原地的残影」。挂到父场景后，人走了，影子还停在刚才坐标。

### 和冲刺大招残影的关系（先知道即可）

练习：你按 W → 调用一次 `spawn_one_afterimage` → 一张。  
正式剑士冲刺：开始/每跑一段路 → 自动多次调用类似逻辑（在 `timestop_afterimage_effect.gd`）。  
**同一件事，调用次数不同。**

### 1）找到动画层：`anim`

```gdscript
@onready var anim: AnimatedSprite2D = $AnimatedSprite2D
```

| 词 | 人话 |
|----|------|
| `@onready` | 等这个节点准备好了，再把右边结果装进左边盒子 |
| `var anim` | 盒子名叫 `anim`，以后用短名指「动画那一层」 |
| `: AnimatedSprite2D` | 声明：这个盒子里装的是「会播帧动画的 2D 精灵」类型 |
| `$AnimatedSprite2D` | 从**自己身上**找名叫 `AnimatedSprite2D` 的子节点（`$` = 找子节点的快捷写法） |

**人话：** 残影要复制「现在长什么样」，所以必须先拿到播动画的那个节点。没有 `anim`，后面取当前帧会失败。

**语法点：** `$名字` 等价于 `get_node("名字")`，但只找**直接/路径下的子节点**；拼写必须和场景树里的节点名完全一致。

---

### 2）两个旋钮：`ghost_lifetime` / `ghost_color`

```gdscript
@export_group("Afterimage Practice")
@export var ghost_lifetime: float = 0.45
@export var ghost_color: Color = Color(0.3, 0.9, 1.0, 0.8)
```

| 词 | 人话 |
|----|------|
| `@export_group("…")` | 只负责检查器分组标题，**不**参与逻辑 |
| `@export` | 把变量变成检查器旋钮，可鼠标改、不必改代码 |
| `float` | 小数（秒） |
| `Color(...)` | 颜色：四个数按 **r, g, b, a** 排列 |

颜色四通道小表（后面 Tween 会反复用到）：

| 通道 | 英文 | 意思 |
|------|------|------|
| r | Red | 红 |
| g | Green | 绿 |
| b | Blue | 蓝 |
| a | Alpha | **不透明度**：0=全透明看不见，1=完全实心 |

`Color(0.3, 0.9, 1.0, 0.8)` 人话：偏青、比较亮、一开始就有点半透明（a=0.8）。

### 3）开关：按 W 才做一张

```gdscript
if Input.is_action_just_pressed("Climb"):
	spawn_one_afterimage()
```

| 词 | 人话 |
|----|------|
| `Input` | 引擎的「键盘/手柄问询台」 |
| `is_action_just_pressed("Climb")` | 输入映射里名叫 `Climb` 的动作，**这一帧刚按下**吗？（按住不连触发） |
| `spawn_one_afterimage()` | 调用做残影的函数；**必须有 `()`** 才真正执行 |

**人话：** 每帧都会跑到这段；只有刚按下 Climb（一般是 W）那一瞬间，才做一张影。

**语法点：** `"Climb"` 是字符串，必须和「项目设置 → 输入映射」里的动作名一致；写错就永远不触发。

### 4）函数壳 + 安全检查

```gdscript
func spawn_one_afterimage() -> void:
	if anim == null or anim.sprite_frames == null:
		print("没有 AnimatedSprite2D，做不了残影")
		return
```

| 词 | 人话 |
|----|------|
| `func …() -> void` | 定义函数；`void` = 做完不往外「交回一个值」 |
| `null` | 空：盒子里什么都没有 |
| `or` | 或者：两边任一成立，整个条件就真 |
| `sprite_frames` | 动画资源：里面装着 Idle/Run 等动画的一格格图 |
| `return` | 立刻结束这个函数，后面步骤不跑 |

**人话：** 没有动画节点或没有动画数据，就打印原因并停手，避免后面崩溃。

### 5）取出「当前这一帧」的图片

```gdscript
var tex: Texture2D = anim.sprite_frames.get_frame_texture(anim.animation, anim.frame)
if tex == null:
	print("当前帧没有贴图")
	return
```

| 词 | 人话 |
|----|------|
| `tex` | 盒子：准备装「一张贴图」 |
| `Texture2D` | 2D 贴图类型（一张图） |
| `anim.animation` | 正在播哪个动画名（如 `"Idle"`） |
| `anim.frame` | 当前是第几格（从 0 起） |
| `get_frame_texture(动画名, 帧号)` | 把那一格的图取出来 |

**人话：** 先问「现在播哪个动画、第几格」，再把那格的图放进 `tex`。这就是「留下那一帧模样」的技术含义。

**语法点：** `A.B.C(...)` 是一层层往下问：先 `anim`，再它的 `sprite_frames`，再对这个资源调用方法。

---

### 6）新建临时精灵，抄位置/朝向，染色

```gdscript
var ghost := Sprite2D.new()
ghost.texture = tex
ghost.global_position = anim.global_position
ghost.flip_h = anim.flip_h
ghost.z_index = z_index - 1
ghost.modulate = ghost_color
```

| 词 | 人话 |
|----|------|
| `Sprite2D.new()` | 现场做一个「只会显示一张图」的节点（还没放进场景） |
| `:=` | 声明并赋值；类型常由右边推断 |
| `texture` | 这个精灵要显示哪张图 |
| `global_position` | **世界坐标**位置（相对整个场景，不是相对爸爸） |
| `flip_h` | 是否左右镜像 |
| `z_index` | 谁画在谁前面；减 1 = 略画在角色后面 |
| `modulate` | 整节点染色乘数（Color：含 r/g/b/a） |

**人话：** 做一个假人 `ghost`，贴同一张图，钉在人此刻站的世界坐标，左右朝向一致，染成半透明色。此时它还在「空气里」，没 `add_child` 你看不见。

**语法点：** `ghost.xxx = …` 是在改这个新节点的属性；等号右边常常在「抄」`anim` 的现状。

---

### 7）放进场景：为什么挂 parent

```gdscript
var parent_node := get_parent()
if parent_node:
	parent_node.add_child(ghost)
else:
	add_child(ghost)
```

| 词 | 人话 |
|----|------|
| `get_parent()` | 问：我的爸爸节点是谁（my_test 里通常是场景根） |
| `if parent_node:` | 若爸爸存在（不是空） |
| `add_child(ghost)` | 把 ghost 收成子节点，这才真正出现在游戏里 |
| `else: add_child(ghost)` | 万一没有爸爸，只好挂自己身上（少见兜底） |

**人话：** 挂到爸爸后，人走开，影子还停在刚才的世界坐标 → 才像残影。若影子一直是角色的子节点，人走影也走，就不像「留在原地」。

### 8）Tween 淡出，然后删掉（你指定要细到这种）

```gdscript
var tween := ghost.create_tween()
tween.tween_property(ghost, "modulate:a", 0.0, ghost_lifetime)
tween.finished.connect(ghost.queue_free)
```

#### 先懂 `a` 是什么

`a` 不是奇怪单位，它是 **Alpha（阿尔法通道）**，取值通常 **0～1**：

| 通道 | 意思 |
|------|------|
| r | 红 |
| g | 绿 |
| b | 蓝 |
| a | 不透明度：0=全透明，1=完全不透明 |

口语常说「透明度」；引擎属性 `a` 量的是「有多不透明」。`modulate` 是整个节点的 `Color`，里面有 `.r .g .b .a`。

#### 人话（这一行在干什么）

`tween.tween_property(ghost, "modulate:a", 0.0, ghost_lifetime)` =

在 `ghost_lifetime` 秒内，把影子的 **a（不透明度）** 从当前值慢慢变成 **0** → 看起来渐渐变淡直到看不见。

#### 语法点

| 片段 | 意思 |
|------|------|
| `create_tween()` | 做一个「慢慢变」的小动画机，挂在 ghost 上 |
| `"modulate:a"` | Tween 专用写法：只改 `modulate` 里的 **a**，红绿蓝不动 |
| `0.0` | 目标值：完全透明 |
| `ghost_lifetime` | 花多少秒做完这次变化 |
| `finished.connect(queue_free)` | 变完后发「结束」信号 → 调用删除节点，避免场景堆垃圾 |

**范围再记一句：** a 从约 0.8（你设的 ghost_color）收到 0；1=全看见，0=全看不见。没有别的神秘区间。

```text
按 W
```
