## 一、这节课要搞懂什么

前三课分别是：跳、无敌、好看。  
第 4 课讲骨头里的另一块：**按一下，往前冲固定一段距离，然后要等冷却才能再冲。**

人话三句：

1. 按下冲刺键 → 进入「冲刺状态」  
2. 按面向方向高速移动，直到「剩余路程」用完  
3. 结束后进入冷却：冷却没好之前再按无效  

滑铲同理（换动画、可蹲碰撞），本课以**冲刺**为主。

## 二、四问表

| 问题 | 冲刺的答案 |
|------|------------|
| ① 谁？ | 玩家 |
| ② 何时触发？ | `Dash` 刚按下，且冷却完毕，且当前不在别的爆发里 |
| ③ 条件？ | `dash_cooldown_left <= 0` |
| ④ 结果？ | 面向方向冲 `dash_travel` 远；开无敌；播特效；冷却开始倒计时 |

## 三、要记住哪些数

| 名字 | 像什么 |
|------|--------|
| `dash_speed` | 冲得多快（速度） |
| `dash_travel` | 这一下总共冲多远（路程额度） |
| `dash_cooldown` | 规矩：冲完要等多久才能再冲 |
| `dash_cooldown_left` | 口袋：现在还剩多少秒冷却 |
| `_travel_left` | 这一下还剩多少路程没跑完 |
| `_burst_speed` | 这一下用的速度（冲刺或滑铲可能不同） |
| `action` | 当前状态：普通 / 冲刺 / 滑铲 |

类比第 1 课：

- `dash_cooldown` ≈ 上限规矩（不随便 -1 改坏）  
- `dash_cooldown_left` ≈ 剩余，会每帧减少  

路程也一样：`dash_travel` 是这一下的总额度；`_travel_left` 是还剩多少。

## 四、状态机（极简版）

```text
平时 action = NONE
  → 按 Dash 且冷却好 → action = DASH，开始爆发
  → 路程跑完 → action = NONE，关无敌，冷却继续走
```

为什么要有 `action`？  
因为冲刺中的移动规则和平时不同：平时用左右键控速；冲刺中往往**锁定**朝一个方向猛冲，直到结束。

每帧大致：

```text
如果 action 不是 NONE：
    走「爆发中」逻辑
否则：
    走「普通」逻辑（走、跳、检测要不要开冲）
```

## 五、触发：什么时候开始冲

普通逻辑里（简化）：

```gdscript
if Input.is_action_just_pressed("Dash") and dash_cooldown_left <= 0.0:
	_start_dash()
```

必须同时：

1. 这一帧刚按下 `Dash`  
2. 冷却剩余 ≤ 0（冷却好了）  

`_start_dash` 里典型会做：

```text
action = DASH
dash_cooldown_left = dash_cooldown   # 立刻进入冷却倒数
_begin_burst(速度, 路程, 是否滑铲=false)
播 Dash 动画
```

`_begin_burst` 里再：

```text
is_invincible = true          # 第2课
_travel_left = 路程
_burst_speed = 速度
特效 begin_burst              # 第3课
```

## 六、爆发中：怎么「跑完一段路」

每一物理帧（简化理解）：

```text
这一帧横移速度 ≈ 面向 × 爆发速度（可略做前重后轻）
实际移动量 step ≈ |速度| × delta
_travel_left -= step
特效 step_burst（告诉皮：又跑了 step）
若 _travel_left <= 0：结束爆发
```

要点：

- 用**路程**结束，不是瞎猜「固定 0.2 秒」（当然用时间也可以，本项目用路程更直观：调 `dash_travel` 就是调冲多远）  
- `delta` 仍然是「这一帧多少秒」，用来算这一帧走了多远  

结束时 `_end_action`：

```text
特效 end_burst
action = NONE
is_invincible = false
```

---

## 七、冷却怎么走

每帧（无论是否在冲）：

```gdscript
dash_cooldown_left = maxf(0.0, dash_cooldown_left - delta)
```

- 每过 `delta` 秒，冷却剩余减一点  
- `maxf(0, …)`：不要减成负数  
- 开始冲刺时设为 `dash_cooldown`（例如 0.45 秒）  
- 减到 0 才能再次 `_start_dash`  

注意：冷却从**开始冲**就计，还是从**冲完**再计，是设计选择。当前参考实现是**一开始冲就写入冷却**。

## 八、完整时间线（串起 2、3、4 课）

```text
冷却好了，按 Shift/C
  → action = DASH
  → 无敌开
  → 特效 begin（残影或线）
  → 冷却剩余 = 0.45 起跳倒数
每帧猛冲，_travel_left 减少，特效 step
路程到 0
  → 特效 end
  → 无敌关
  → action = NONE
冷却继续减到 0
  → 可以再冲
```

## 详细代码解释

> 2026-08-11 回填。对照参考：`Sprite/sword_player.gd`（名字以你文件为准）  
> 结构：小段代码 → 名词/小表 → 人话 → 语法点  
> 说明：正式冲刺比练习残影长；这里把「会反复见到的几句」拆开讲。

### 1）两对「规矩 vs 剩余」

```gdscript
@export var dash_travel: float = 220.0
var _travel_left: float = 0.0

@export var dash_cooldown: float = 0.45
var dash_cooldown_left: float = 0.0
```

| 名字 | 像什么 | 会不会每帧变 |
|------|--------|--------------|
| `dash_travel` | 规矩：这一下总共冲多远 | 一般不；你在检查器拧 |
| `_travel_left` | 口袋：这一下还剩多远 | 会，冲刺中每帧减 |
| `dash_cooldown` | 规矩：冲完要等多久 | 一般不 |
| `dash_cooldown_left` | 口袋：还要等多久 | 会，每帧减到 0 |

**人话：** 和第 1 课 `max_air_jumps` / `_air_jumps_left` 同一副模板：上限放检查器，口袋放脚本。

**语法点：** 前导 `_` 常表示「内部状态，不打算导出检查器」；`@export` 的才是旋钮。

---

### 2）触发：刚按下且冷却好了

```gdscript
if Input.is_action_just_pressed("Dash") and dash_cooldown_left <= 0.0:
	_start_dash()
```

| 词 | 人话 |
|----|------|
| `"Dash"` | 输入映射动作名（常是 Shift / C） |
| `and` | 并且：两个条件都要满足 |
| `<= 0.0` | 冷却剩余已经 ≤ 0（冷却好了） |
| `_start_dash()` | 开始冲刺的函数（真正执行要有括号） |

**人话：** 连按没用——必须「刚按下」且「冷却口袋已经空了」。

**语法点：** 把「能不能冲」写在 `if` 条件里，比冲进去再判断更清晰；冷却没好时根本不会调用 `_start_dash`。

---

### 3）开始冲：写入状态、路程、冷却、无敌

开始函数里典型会做（理解用伪结构）：

```text
action = DASH
dash_cooldown_left = dash_cooldown
_travel_left = dash_travel
is_invincible = true
特效 begin_burst(...)
```

| 词 | 人话 |
|----|------|
| `action = DASH` | 标记：我现在处于冲刺状态（和平时移动规则不同） |
| `dash_cooldown_left = dash_cooldown` | 把冷却口袋装满，开始倒数（本项目常见：一开始冲就计） |
| `_travel_left = dash_travel` | 把路程口袋装满，准备边冲边花 |
| `is_invincible = true` | 第 2 课骨头：冲刺中先打不中 |

**人话：** 按下那一刻，同时打开「状态 / 路程额度 / 冷却倒数 / 无敌」，再通知第 3 课的皮开始播。

**语法点：** `A = B` 是「用规矩 B 的当前值去填口袋 A」；之后减的是口袋，不是去改检查器里的规矩。

---

### 4）爆发中：用路程花光来结束

每物理帧（理解用）：

```text
横移速度 ≈ 面向 × dash_speed
这一帧走的距离 step ≈ |速度| × delta
_travel_left -= step
若 _travel_left <= 0：结束冲刺
```

| 词 | 人话 |
|----|------|
| `delta` | 这一帧多少秒 |
| `step` | 这一帧实际冲了多远 |
| `-=` | 从路程口袋里扣掉这一帧的距离 |

**人话：** 不是瞎猜固定播 0.2 秒动画就停；而是「额度花完就停」。所以拧 `Dash Travel` 就是拧冲多远。

**语法点：** `|速度|` 表示取绝对值（不关心正负，只关心「走了多远」）；面向用 +1/-1 决定左右。

---

### 5）冷却每帧往 0 靠

```gdscript
dash_cooldown_left = maxf(0.0, dash_cooldown_left - delta)
```

| 词 | 人话 |
|----|------|
| `dash_cooldown_left - delta` | 过了这一帧的秒数，口袋少一点 |
| `maxf(0.0, …)` | 两个小数取较大者：结果不要小于 0 |

**人话：** 冷却倒数减到 0 就停在 0，不会变成 -0.01 这种怪数字；到 0 才能再满足触发条件。

**语法点：** `maxf` 的 `f` 常表示处理浮点数（float）；防止减穿是常见防御写法。

---

### 6）结束冲刺时关什么

```text
特效 end_burst
action = NONE
is_invincible = false
```

**人话：** 路程花完 → 停冲刺状态 → 关无敌 → 让皮收尾。  
**冷却口袋**此时往往还在继续减（若一开始冲就写入了），别和「无敌开关」搞混：无敌结束 ≠ 冷却一定已经好。

---

### 7）串课口诀

```text
按 Dash（冷却好）
  → 开状态 + 填路程 + 填冷却 + 开无敌 + 皮 begin
每帧
  → 花路程；皮 step；冷却口袋继续减
路程 0
  → 皮 end；关状态；关无敌
冷却口袋 0
  → 可以再按
```

## 问答记录

### 2026-08-10 · 「我没有这种编程思维怎么办」

**徒弟担心：** 看到「规矩 vs 剩余」两对表就慌，觉得自己没这种思维。

**师傅：** 这不是天赋，是反复套同一副模板练出来的。  
任何「有上限、会耗尽、再补满」的玩法，都先拆成：

| | 规矩（检查器 / `@export`） | 剩余（运行中会变） |
|--|--|--|
| 二段跳 | `max_air_jumps` | `_air_jumps_left` |
| 冲刺路程 | `dash_travel` | `_travel_left` |
| 冲刺冷却 | `dash_cooldown` | `dash_cooldown_left` |

每帧：剩余往 0 减（或跳一次减 1）；到 0 → 结束该行为 / 允许再按。  
练习口诀：「上限放检查器，口袋放脚本，每帧掏口袋。」

**检查题作答（徒弟）：**  
`max_air_jumps` = 规矩；`_air_jumps_left` = 剩余。  
脚踩地：答成「脚踩地是规则，改成是否踩到地面」→ **半对半混。**

**纠正：**  
`is_on_floor()` 不是「规矩/剩余」那一对里的数，它是**条件开关**（现在踩没踩地）。  
踩到地时要改的是**剩余口袋**：`_air_jumps_left = max_air_jumps`（把次数补满）。  
规矩 `max_air_jumps` 一般不在落地时改。

**检查题 2（徒弟答 C）：**  
「`_travel_left`→0 表示刚按冲刺、冷却开始」→ **错。**

**纠正：**  
- `_travel_left`→0 = **这一下路程跑完** → 结束冲刺（关无敌等）→ 选 **B**。  
- **冷却开始**多半在**按下冲刺的那一刻**（`dash_cooldown_left = dash_cooldown`），不是路程归零时。  
- A 是 `dash_cooldown_left`→0 才能再按。  
- 名字是 `_travel_left`（路程），不是 gravel。

**检查题 3（徒弟答 A，理由说「开始时倒计时」）：**  
理由对、字母错 → 正解是 **B `_start_dash()`**。  
A 是结束函数；「开始就倒计时」对应开始函数。代码里：`dash_cooldown_left = dash_cooldown` 写在 `_start_dash`。
