# 第9课 · 刀光与残影不是同一套

日期：2026-08-15  
对象：yehai 说刀光要；直觉残影那句代码生成不了刀光；问大佬怎么做  
相关：[[第3课-残影与疾风线]] · [[第8课-锁骨做动画再导出帧]] · [[设计说明-刀光另层生成]] · [[像素猫-外观锁定]]

## 师傅这课的判断（先看这四句）

1. **你的直觉对。** `spawn_one_afterimage()` 复制的是**整只角色当前那张图**，淡掉。它做的是残影/残像，**不是**那道弯弯的刀光。
2. **刀光要，但不焊进走、站、跑的猫 PNG。** 大作几乎都是：角色还是干净的姿势，**攻击那一下另开一层**放出弧光。
3. **大佬常用的不是「只靠粒子乱喷」。** 好看的那一刀「C」形，多半是一张（或几张）弧光图 / 一块弧形网格；粒子负责火花、尘土、击中。两层叠在一起才像《空洞骑士》《死亡细胞》。
4. **今天不把刀光塞进玩家。** 先认路。工程里其实已经有「特效即插即用」的架子（剑士玩家的残影 / 疾风线），刀光以后应做成同一种：**攻击时播，不是冲刺时复制全身。**

## 2. 大佬常见四条路（由常用到更强）

### 路 A · 单独的刀光精灵（2D 动作游戏最常见）

角色挥砍时，**再生成一个节点**，贴一张弯弯的弧（或 3～8 张小动画），播完删掉。

- 《空洞骑士》：角色本身姿势往往很简单，**特效层**告诉你「这一刀打到哪、有多狠」（分析向视频：[The Effects Animation of Hollow Knight](https://www.youtube.com/watch?v=SIJtfr-PO4Y)）。
- 很多像素动作：攻击帧是角色姿势，刀光是**另一张表**，叠在身前。

**人话：** 猫还是猫，刀光是「贴在爪子前面的一张月牙」。  
猫没有剑也可以：那就是**爪光**，形状一样，不必先给猫加剑。

### 路 B · 粒子打点缀，不负责那道大弧

《死亡细胞》美术 Thomas Vasseur 写过：攻击动画是姿势对姿势，**动感、力度靠 VFX**；打击感还叠顿帧、慢放、血雾（[Gamasutra / Game Developer 深潜](https://www.gamedeveloper.com/production/art-design-deep-dive-using-a-3d-pipeline-for-2d-animation-in-i-dead-cells-i-)；武器手感还提到格斗游戏那套粒子 + 停帧：[50 把武器](https://www.gamedeveloper.com/design/designing-each-of-the-50-weapons-in-i-dead-cells-i-to-feel-distinctive)）。

粒子擅长：火花、碎片、烟。  
粒子不擅长：单独喷出一道**永远那么干净的镰刀形**。所以大作是 **弧光图 + 粒子**，不是「只有粒子」。

### 路 C · 跟着刀尖拖一条带子（Line2D / 粒子拖尾）

剑尖每帧记一个点，连成线，像 3D 游戏的 ribbon。Godot 可用 `Line2D`，或 `GPUParticles2D` 的 trail。

VFX 艺术家 Mae van Diesen 写过：刀很快时，带子会**跟不上、缺口、发飘**，她后来改成**一张弧的材质/着色器**画扇形（[Dark Sword Slash VFX](https://www.bluebendypencil.com/my-work/dark-sword-slash-vfx)）。

**适合：** 以后骨头上真有一把剑、挥得连续。  
**不太适合当第一课：** 像素猫还没剑骨；快斩时带子容易丑。

### 路 D · 网格 + 遮罩着色器（更强、更偏「特效师」）

有人用 Blender 做出一条「刀光布」，进 Godot 用 shader 把亮部和透明「刷」出来（例：[Making a Sword Slash in Godot](https://www.youtube.com/watch?v=qF7EOzwJoO4)）。这是大炮：以后精美立绘、要每刀形状都能调时很强。现在做像素猫偏重，但**可以学，不拦你**。

## 3. 和你现在代码的关系

| | 残影（你已有） | 刀光（你要的） |
|--|----------------|----------------|
| 复制什么 | 整只角色当前帧 | **另一张弧光图**（不是猫） |
| 什么时候 | 冲刺/闪避/你按 W 练习 | **按攻击的那一帧** |
| 长什么样 | 半透明的猫停在原地 | 身前一道 C / 月牙 |
| 你这句代码行不行 | 行 | **不行**（直觉对） |

剑士玩家 `sword_player.gd` 已经把特效拆开了：`TIME_STOP` 是残影，`SPEED_LINES` 是疾风线，位移脚本不管画画。刀光以后应是第三种：**挂在 Effects 下，攻击时 `begin`，不是 dash 时复制全身。**

## 4. 师傅建议你怎么走（不劝退强工具）

| | |
|--|--|
| **用路 A 做你现在要的刀光** | **可以**，也是空洞骑士、大多数 2D 斩击的底。 |
| **不局限于此** | 路 D 的 shader 弧、路 C 的刀尖带子，才是特效岗位真正天天调的东西。 |
| **和当前猫的差距** | 还没有签字的攻击姿势，也没有剑骨；先做「攻击时弹出一张爪光」。 |
| **对照** | 只开粒子：有火花、没有那一刀。只画进 walk 帧：走路上也带着刀光，脏。 |

推荐叠两层（以后做，今天不写进玩家）：

1. **主刀光：** 独立 `AnimatedSprite2D` 或 `Sprite2D`（3～8 帧弧）  
2. **击中点：** `GPUParticles2D` 火花  

帧图目录以后可加 `attack/`，里面仍是**干净的猫姿势**；刀光图另放例如 `四脚猫/attack/刀光/`，不要画进 idle。

## 5. 怎么做（手把手；先认，不改 `fighter_player.tscn`）

等你有一张月牙 PNG（灰底或透明）之后：

1. Godot：文件系统右键 → 新建场景 → 根用 `Node2D`，存成 `Scene/fx/slash_arc.tscn`（先别挂到玩家身上）
2. 根下加 `AnimatedSprite2D`，名字 `Arc`
3. SpriteFrames 新建动画 `Slash`，把弧光 01、02、03…拖进去，`loop` 关掉
4. 选中 `Arc`：`Animation Finished` 信号连到根脚本，里面写 `queue_free()`（播完自杀）
5. 导入弧光图：若是像素，Filter = Nearest
6. 以后接到攻击：玩家脚本在「挥到那一帧」时 `var s := slash_scene.instantiate()`，`add_child`，位置偏向 `facing`，`flip_h` 跟面向

练习用：现在 `fighter_player.gd` 的 F 还是「假装挨打」，不要和刀光耦在一起，等攻击动画有了再接。

## 6. 印不出来的，还是要另生成（他让记住）

你不一定能数出全部特效名字。规矩只一条：

> 把角色**当前这一帧**印一份、改个色、淡掉——看起来对不对？  
> **对** → 代码做（残影、闪白）。  
> **不对** → **还是要另生成**（另开一层图或粒子）。刀光就是这一类。

对照（不是现在全做；点名再生成）：

| 印得出来（代码） | 印不出来（要另生成） |
|------------------|----------------------|
| 残影、受伤闪白、无敌闪烁、左右翻转 | 刀光/爪光、冲击波圈、命中星芒、弹道、法阵、蓄力光环、专设计的烟尘/裂地 |

已点名要的： **刀光**。图以后放 `四脚猫/fx/`。走/站 PNG 仍然干净。

## 详细代码解释

### A. 残影复制的是「整只猫这一帧」——所以不是刀光

```83:95:C:\Users\yehai\Documents\firebot\Sprite\fighter_player.gd
	# 2) 取出「当前这一帧」的图片
	var tex: Texture2D = anim.sprite_frames.get_frame_texture(anim.animation, anim.frame)
	if tex == null:
		print("当前帧没有贴图")
		return

	# 3) 新建一个临时精灵，贴上同一张图
	var ghost := Sprite2D.new()
	ghost.texture = tex
	ghost.global_position = anim.global_position  # 停在「现在这个位置」
	ghost.flip_h = anim.flip_h                    # 左右朝向一致
	ghost.z_index = z_index - 1                   # 画在角色后面一点
	ghost.modulate = ghost_color                  # 换色/半透明，看起来像残影
```

| 词 | 人话 |
|----|------|
| `get_frame_texture` | 取出正在播的那一张角色图 |
| `ghost` | 残影这个临时节点 |
| `texture = tex` | 残影贴的还是**猫**，不是月牙 |
| `modulate` | 整张乘一个颜色，所以看起来像染色影子 |
| `z_index - 1` | 画在角色后面 |

**人话：** 无论你怎么调颜色、淡出，它都是「半透明的猫」。刀光需要**另一张图**。

**语法点：** `anim.animation` 是当前动作名，`anim.frame` 是第几张。`.` 点的是动画节点身上的东西。

### B. 现在按 F 连攻击都还没做——只是假装挨打

```44:46:C:\Users\yehai\Documents\firebot\Sprite\fighter_player.gd
	# 第2课：F 假装挨打；V 开关无敌
	if Input.is_action_just_pressed("Attack"):
		take_damage(1)
```

| 词 | 人话 |
|----|------|
| `Attack` | 输入动作名（默认 F / 鼠标左键） |
| `take_damage(1)` | 自己扣 1 点（练习无敌用） |

**人话：** F 现在不是挥砍。以后刀光应写在「真的攻击」里，不要写在这三行上，否则一按 F 又挨打又喷刀光，练习会搅在一起。

**语法点：** `is_action_just_pressed` = 刚刚按下的那一帧为真。引号里必须和 InputMap 的动作名一样。

### C. 剑士那边已经把「特效」和「位移」分开了

```6:12:C:\Users\yehai\Documents\firebot\Sprite\sword_player.gd
@onready var fx_timestop: BurstEffect = $Effects/TimeStopAfterimage
@onready var fx_speed_lines: BurstEffect = $Effects/SpeedLines

enum VisualStyle {
	TIME_STOP, ## 时间停滞：角色残影（偏闪避大招 / 演出）
	SPEED_LINES, ## 疾风线：线条表现极速（偏日常冲刺 / 滑铲）
```

| 词 | 人话 |
|----|------|
| `BurstEffect` | 你们自己定的「爆发特效」基类（冲刺/滑铲用） |
| `enum` | 一组起了名的选项 |
| `TIME_STOP` / `SPEED_LINES` | 残影套装 / 疾风线套装 |

**人话：** 冲刺残影、疾风线、**刀光**是三种插头。刀光不要塞进 `spawn_one_afterimage` 里改造，另做一种「攻击时播」的插头。

**语法点：** `$Effects/TimeStopAfterimage` 是路径：玩家 → Effects → 这个子节点。`:` 后面是类型。

### D. 残影生成函数长什么样（对照：刀光应换贴图）

```61:72:C:\Users\yehai\Documents\firebot\Sprite\effects\timestop_afterimage_effect.gd
func _spawn_ghost(host: Node2D) -> void:
	if _anim == null or _anim.sprite_frames == null:
		return
	var tex := _anim.sprite_frames.get_frame_texture(_anim.animation, _anim.frame)
	if tex == null:
		return
	var ghost := Sprite2D.new()
	ghost.texture = tex
	ghost.global_position = _anim.global_position
	ghost.scale = _anim.global_scale
	ghost.flip_h = _anim.flip_h
	ghost.z_index = host.z_index - 1
```

**人话：** 和练习残影同一思路：`texture` 来自角色。刀光只要把 `tex` 换成弧光贴图，位置改到身前（`facing` 那一侧），`z_index` 改成角色前面。

**语法点：** `host` 是玩家节点。`-> void` 做完不返回值。

### E. 以后刀光最小写法（现在不要贴进玩家，先认字）

```gdscript
@export var slash_scene: PackedScene

func spawn_slash() -> void:
	var s := slash_scene.instantiate() as Node2D
	s.global_position = global_position + Vector2(facing * 48.0, -8.0)
	s.scale.x = float(facing)  # 面向左就整段特效翻过来
	get_parent().add_child(s)
```

| 词 | 人话 |
|----|------|
| `PackedScene` | 一个场景文件（`.tscn`）打包好，随时 `instantiate` 克隆 |
| `instantiate()` | 克隆出实际节点 |
| `facing` | 1 朝右，-1 朝左 |
| `scale.x = facing` | 负数就会左右翻转 |

**人话：** 攻击那一下，在身前丢一个「刀光场景」。场景自己播完 `queue_free()`。猫的 PNG 仍然没有刀光。

**语法点：** `Vector2(x, y)` 两个数是右/上偏移（y 负常常是往上）。`as Node2D` 告诉电脑「把它当成 2D 节点」。`float(facing)` 把整数 1 / -1 变成小数，才能赋给 `scale.x`。

### F. 粒子只做火花（认字，今天不加节点）

```gdscript
$HitSparks.restart()
```

| 词 | 人话 |
|----|------|
| `GPUParticles2D` | 显卡画很多小点 |
| `restart()` | 重新喷一轮（打中一下喷一次） |

**人话：** 打中时喷火星。没有月牙图，看起来会像烟花，不像刀。

**语法点：** `$HitSparks` 是子节点名字，必须和场景树里一致。
