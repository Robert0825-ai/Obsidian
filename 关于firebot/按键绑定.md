## 先懂一句：手机要不要「绑键盘」？

**不要。** 详解见 [[输入-PC与手机同一套动作]]。

**另一句：** 手游一般**不会**把滑铲做成「方向键旁边的组合键」——见 [[手游操作-滑铲冲刺闪避常见做法]]。

## PC 默认

| 动作名 | 主键 | 副键 | 干什么 |
|--------|------|------|--------|
| `Left` | **A** | ← | 左移 |
| `Right` | **D** | → | 右移 |
| `Climb` | **W** | ↑ | 上 / 攀爬 |
| `Down` | **S** | ↓ | 下；按住左右再按 = 滑铲 |
| `Jump` | **空格** | — | 跳跃 |
| `Attack` | **F** | 鼠标左键 | 攻击 |
| `Combo` | **V** | — | 连招 / 练习开关 |
| `Dash` | **Shift** | **C** | **冲刺（兼闪避）** |
| `Slide` | **Ctrl** | X | **滑铲（专用，朝面向）** |
| `Pause` | **Esc** | — | 暂停 |
| `Interact` | **E** | — | 互动（预留） |

## 滑铲怎么按

| 平台 | 怎么按 |
|------|--------|
| **PC 习惯** | 按住 A/D（或 ←/→）再按 **S** |
| **PC 专用** | **Ctrl**（动作 `Slide`），朝当前面向滑 |
| **手机** | 右侧点 **「滑」**（不必按住方向；朝面向滑） |

只按 S、不按方向：不滑铲（除非用 Ctrl / 手机「滑」）。

## 手机虚拟键对照

```text
左：圆形摇杆（市面常见）
    左/右 = 走
    上 = Climb（爬）
    下 = Down（向下爬）
右：跳  攻
    冲  滑
```

| 控件 | 动作 | 约等于 PC |
|------|------|-----------|
| 摇杆 ← → | Left / Right | A/D |
| 摇杆 ↑ | Climb | W（爬） |
| 摇杆 ↓ | Down | S（向下爬） |
| 跳 / 攻 / 冲 / 滑 | Jump / Attack / Dash / Slide | 空格 / F / Shift / Ctrl |

脚本：`Sprite/ui/virtual_joystick.gd`  
开发期电脑上也显示，可用鼠标拖摇杆试。  

逐段讲解 + 改版原因：[[详细代码解释-圆形摇杆与虚拟键]]

## 人话记法

- 走：WASD 或 ◀▶  
- 跳 / 打：空格·F 或「跳」「攻」  
- 冲刺闪避：Shift 或「冲」  
- 滑铲：方向+S，或 Ctrl，或手机「滑」
