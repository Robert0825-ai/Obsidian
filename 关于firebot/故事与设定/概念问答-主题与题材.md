**Q1（2026-08-15 师傅问）：一句话更接近短关卡、类恶魔城，还是先短后大？**  
**A（徒弟）：** 想做类恶魔城，但可能要先做短关卡，因为不知道后面会怎样。执着骨骼：①解决逐帧不连续、很怪；②担心 Godot 做不到想要的效果，可能要 Unity（C#、性能更强）。不确定对不对。  
**师傅：** ①先短关、目标恶魔城，对。②骨骼解决不连续，对。③这款 2D 不必为性能先换 Unity。详见 [[设计说明-先短关卡再类恶魔城]]。

**Q2（2026-08-15 师傅问）：玩家操控的是不是这只四脚像素猫？**  
**A（徒弟）：** 是。后话：猫视角冒险；本想猫+战争反战，因压抑穿插；像素想定可改；森林翠绿美好把人带进来 → 城市繁华暖心 → 工业污染环保 → 战争警示 → 废墟；结局未定；伙伴敌人 NPC 是扩展；不一定是类恶魔城，对游戏了解少。让师傅直说问题并可补细节。  
**师傅：** 主旨听懂了：对比，不是开场战争。像素可作当前决定。类型先不锁恶魔城。详见 [[设计说明-猫视角冒险与主旨]]。

**Q2 更正（2026-08-15）：** 打字是「反战」不是犯罪。气味用 NPC+环境衬托。「骗进来」=游戏里先暖、不是商店骗人。「一家人」=不要屠杀同胞。战争不血压，成堆尸体稍微模糊过审。  
**师傅：** 听偏了，已改笔记。商店页那条收回。小孩/伤兵那条收回。

**Q3 更正（2026-08-15）：** 不是森林里 4～5 张小图，是大约 **4～5 个世界**（一章一个世界），每章里还有多个场景（数量未定）。也可能做成 4～5 款小游戏。独立开发第一款，体量大怕头疼，又不想太烂、没有好玩法。战争=暖城改（昔日美好因战争变成这样）；废墟=同一座暖城：繁华→硝烟→废墟。问：开场森林要不要先放废墟，结尾废墟长草呼应森林，会不会更差。  
**师傅：** 4～5 个全新世界对第一款偏大；战争/废墟用暖城改，实际独特地图更像 2～3 套。开场森林不要放明显废墟；结尾废墟长草更好。

**Q5（2026-08-15）：第一款是单独森林小游戏，还是大作第一章？**  
**A（徒弟）：** 大概率是 1。这样能把森林塑造得更漂亮，让人感受大自然，才好和后面战争对比。  
**师傅：** 记下。第一款交付物=完整森林。漂亮不是加戏，是对比的本钱。核心乐趣（森林里反复干什么）下一问。

**Q6（2026-08-15）：森林里反复干什么？**  
**A（徒弟）：** 还不确定。或许为了寻找失踪的伙伴（也是猫），可贯穿到最后。结局候选：虐心——伙伴死于战争，尸体化为大自然养料；或最后找到。不知道老不老套。  
**师傅：** 「寻猫」当贯穿线可以。森林这款通关时找没找到，决定第一款怎么收。

**Q7（2026-08-15）：森林打完时，伙伴找没找到？**  
**A（徒弟）：** 森林结尾只找到线索。整个游戏世界都是为了寻找昔日伙伴。  
**师傅：** 记下。第一款完整=「这一段找到线索」；后话继续找。虐心/团圆仍留在最后。下一问：森林怎样算通关。

**Q8（2026-08-15）：森林怎样算通关？**  
**A（徒弟）：** 有人看见伙伴被人类带走。可能是抓走；也可能无意受伤或被 boss 打伤，后被人类带走治疗。暂时不确定哪个更好。  
**师傅：** 通关画面定为「目击带走」。抓走 vs 治疗见主旨说明。

**Q9（2026-08-15）：带走更靠近抓走还是治疗？**  
**A（徒弟）：** 选 2。可能是救被蛇咬的小孩、与大蛇战；伙伴抓伤蛇（瞎一只眼）；蛇因费力且嗅到父母来而逃（身上划痕）；伙伴也受伤、捡回半条命。带走后悬疑：可能半路没治上就死、也可能治好——半路死玩家不喜欢，也不想要，只是悬疑。父母知真相后带猫去治疗。  
**师傅：** 锁「治疗」不锁「半路死」。通关=父母带走去治。下一问：玩家打不打蛇。

**Q10（2026-08-15）：和蛇是玩家打，还是只看结尾？真相谁说？**  
**A（徒弟）：** 玩家通过蛇的对话才知道这些。后面和蛇有大战。不确定：蛇亲口说猫被人类带走，还是另一个无意间的角色说看见带走。一开始蛇骗「伙伴被我吃了」，玩家伤心，为报仇也为活命和蛇生死决斗。  
**师傅：** 大战=可打的 boss。谎当决斗燃料。当时误写成「打完父母开口」——时间线不对，Q11 作废那条。

**Q11（2026-08-15）：战后谁说真话？蛇要不要立体？**  
**A（徒弟）：** 玩家大战在伙伴大战之后，伙伴已被小孩和父母带走，现场没人。应另造 NPC 透露伙伴还活着。大蛇前面撒谎后面说真话不好。角色塑造虽可立体，蛇没必要；纯粹的坏可以。  
**师傅：** 记下。时间线锁：人已走 → 蛇只骗 → 决斗 → NPC 揭谎。蛇锁「纯粹的坏」。真话不靠蛇、不靠小孩/父母（他们不在场）。下一问：这个 NPC 是谁（先想一只林中动物即可）。

**Q12（2026-08-15）：揭谎 NPC 是谁？主角怎么和 boss 碰上？**  
**A（徒弟）：** 鸟。碰上理由：①无意救下险境中的蛇（戴眼罩，看不清抓痕），蛇装可怜，其实想骗了再吃主角；②当时蛇正要吃鸟蛋，主角见义勇为拦住；③诡计被戳穿，蛇不装了，摘眼罩，脸上有猫抓痕，骗「伙伴被我吃了」。可能用捕兽夹让蛇陷入险境。语文差，只有这些块，让师傅整理、看要不要改时间线。  
**师傅：** 鸟锁。三块收成先后三拍，不是三个并列理由。夹子用猎人遗留、真夹假可怜。鸟更早看见带走，救蛋之后才说。整理见 [[设计说明-猫视角冒险与主旨]]。下一问：救蛇和拦蛋是连着一幕，还是中间隔几关。

**Q13（2026-08-15）：摊牌谁说？鸟妈妈打不打？鸟爸爸干什么？**  
**A（徒弟）：** 不要「吃蛋被拦就装不下去」。改成鸟妈妈说出：那是坏蛇，常吃小动物，揭漏好人身份。妈妈要护孩子；不确定她参不参战，倾向玩家来之前她已和蛇打过、受伤，后面大战只玩家打。鸟爸爸外出找食物，才给蛇可乘之机；后来赶来一块解决大蛇。了解经过后，他说找食物时看见那只猫被人类带走。  
**师傅：** 记下。两只鸟两句话：妈妈拆假好人，爸爸说带走。妈妈不进玩家这场。爸爸残血助攻，不当第二玩家。见主旨说明场次表。救蛇到巢是否连着，仍未锁。

**Q14（2026-08-15）：救蛇和鸟巢中间隔多久？分道后蛇怎么翻脸？**  
**A（徒弟）：** 隔两三关。蛇想骗玩家：它见过伙伴，当时往某个地方去了。当时玩家身边有其他伙伴，蛇小心谨慎。分道扬镳后，蛇觉计划得逞，但不急着吃；找借口离开去埋伏。路上见鸟妈妈带孩子，可饱餐，也为偷袭攒体力，上树打鸟妈妈；妈妈护孩子所以受伤。正巧被玩家看见、阻止。玩家先质问形象和以前不一样，再鸟妈妈揭穿假好人。蛇不装了，摘眼罩露爪印，开始大战。鸟爸爸只助攻，不当第二可玩角色。  
**师傅：** 隔两三关锁。巢边顺序锁：阻止 → 玩家质问 → 妈妈揭穿 → 摊牌大战。分道前只说「见过往某处」，摊牌才说「吃了」。其他伙伴先短随行。方向诱饵建议含糊/带错，真方向留给鸟爸爸。借口与其他伙伴是谁未锁。

**Q15（2026-08-15）：同行伙伴是谁？蛇为什么谨慎？路上不对劲？**  
**A（徒弟）：** 别的猫更好。蛇之前被伙伴打伤，不敢贸然和两只猫打；瞎了一只眼，视力受限；路上略变大、实力略强。玩家途中察觉一点点不对劲（伏笔，还没想好）。可能是嘴角一丝血迹，蛇狡辩说不小心弄到的。  
**师傅：** 同行锁成一只短随行猫（加玩家=两只）。谨慎理由锁。略变强只一点点。伏笔先写上：嘴角一丝血 + 狡辩「不小心弄到的」（蛇要吃东西；想到更好的可替换）。分道原因仍未锁。

**Q18（2026-08-15）：和被带走的猫原先认识吗？怎么开始找？**
