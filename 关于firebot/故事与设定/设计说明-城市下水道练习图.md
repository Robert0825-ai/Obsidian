## 设计原因

徒弟要的是空洞骑士那种**四通八达**（房间上下左右都通、能绕路），不是一条走廊。  
四通八达靠的是**房间怎么连**，不是必须画成下水道。林子也能四通八达。  
先用水库/城市下水道当**练习皮**：竖井、管道、闸门，绕路更好懂。第一章故事仍是森林，这张图不取消林子、不抄空洞骑士拆包。

「类恶魔城元素都要有」= 类型工具箱，不是空洞骑士全作（护符墙、四十个 Boss、整套经济不要）。

| 有 | 干什么 |
|----|--------|
| 12 间 4×3，每间能上下左右 | 不是走廊 |
| 能力是捷径 | 冲/滑/打墙能抄近，不会也能绕 |
| 爬 | 掉下去的洞要爬回来（管道里学） |
| 存档石 + E 回枢纽 | 椅子 |
| 虫子掉废铁 + 枢纽小摊 | 最小商店 |
| 假墙 F 打穿 | 隐藏捷径 |
| 小地图、羽毛、生命+1、蛇 | 收集 / Boss |

## 详细代码解释

### 房间怎么变成「格子」

```gdscript
const RW := 1280.0
const RH := 720.0
```

| 名词 | 人话 |
|------|------|
| `RW` / `RH` | 一间房的宽、高。相机一次只框这一块。 |
| `_L(列, 行, x, y)` | 把「第几间里的坐标」换成整张大地图像素。 |

语法：`const` 是写死的数，游戏运行中不改。

### 竖井：能掉下去，要爬才能上来

```gdscript
_slab_xy(_L(col, row, west_cut, 560), maxf(sx - 80.0 - west_cut, 40.0))
_vine(_L(col, row, sx, 560), 520)
```

| 行 | 代码 | 作用 |
|----|------|------|
| 地板两截 | `_slab_xy(... sx - 80 ...)` | 中间留洞，人会掉到下一间 |
| 管道 | `_vine(..., 520)` | 加进 `vine` 组；有爬、按 W 才能上去 |

人话：跳的高度够不到上一间（大约 90 像素），所以**上**必须会爬。**下**随时能掉。这就是绕路的一半。

### 废铁和商店

```gdscript
func add_scrap(n: int) -> void:
	scrap += n
	scrap_changed.emit(scrap)
```

| 名词 | 人话 |
|------|------|
| `scrap` | 废铁数量，存在 `GameState` 里，关游戏还能读 |
| `emit` | 喊一声「变了」，头顶那行字会改 |

虫子 `take_hit` 死掉时调用 `add_scrap(3)`。枢纽里 `shop_keep.gd` 看 `Interact`（E）：够 12 就 `max_hp + 1`。

### 椅子传送

`save_bench.gd` 碰到人就 `register_bench(房间名, 位置)`。  
不是枢纽的椅子上按 E：把猫 `global_position` 设成枢纽那把椅子的坐标。

### 假墙

`breakable_wall.gd` 的 `collision_layer = 5`：人走不过去（第 1 层），爪也打得到（第 3 层，和虫子同一层）。`take_hit()` 就 `queue_free()` 删掉。

墙砖接缝我没把握抹平。房间不再是黑真空：后墙填满、管子贴墙、地面重复铺、刺用铁刺图。

对照 itch 素材包的**种类清单**（KR Sewer / Minifantasy / Kauzz）和真下水道（拱顶、中间水槽、两侧走道、拍门、闸门、井、梯），补了一批原创零件并铺进房间。不抄他们的像素，也不抄空洞骑士。
