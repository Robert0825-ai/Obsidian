# 设计说明 · 猫视角冒险：对比主旨（后话先记下）

日期：2026-08-15  
概念格子：[[概念问答-主题与题材]] · [[像素猫-外观锁定]]  
徒弟原文大意：猫的冒险；先森林美好，再人类繁华，再工业污染，再战争与废墟；反战穿插、不全盘阴暗；像素可后改。

## 设计原因（主旨，师傅复述）

这不是「一上来打仗的战争游戏」。  
玩家操控**一只猫**，用猫的眼睛走完一条路：

翠绿森林（生机）→ 人类城市（繁华、被喜欢）→ 工业区（灰、臭、污染）→ 战场（硝烟、死伤）→ 废墟。

靠**前后对比**让人真切感到：自然美、和平贵、繁华脆弱。猫有「可爱」标签，用来把人带进门；反战、环保是穿插的戏份，不是整款游戏从头压抑到尾。结尾未定。伙伴 / 敌人 / NPC 是扩展。

**「大家都是一家人」** = 人类不要肆意屠杀同胞（反战），不是「猫交几个朋友」。  
**「骗进来」** = **游戏里**前期玩家没发现后面会变，只觉得是暖心猫游；**不是**商店页写成纯暖心去骗购买。  
气味：用 **NPC 反应 + 周围环境** 衬托（捂鼻、对话、灰雾、枯植物），不是真的闻。

**当前决定（可改）：像素画风。** 这种东西存在。

**类型先别锁死类恶魔城。** 故事更像章节旅程。了解游戏少很正常。

**Q3 已答后更正：不是「森林 4～5 张小图」，是大约 4～5 个世界。** 每章多个场景，数量未定。战争与废墟都用**暖城当模板改**（繁华 → 硝烟 → 废墟）。也可能拆成 4～5 款小游戏。第一款独立，体量大怕做不完，又不想烂、不想没玩法。

开场森林要不要先放废墟、结尾长草呼应：见下「开场废墟」。

## 师傅怎么看（他让直说）

### 好的、该留

- 用对比而不是开场轰炸，这个判断对。开场战争确实容易劝退。
- 反战不全盘当卖点、穿插进来，也是对的：玩法仍要好玩，主题才站得住。
- 猫视角成立。《迷失》（Stray）就是猫走城市；你多了森林→污染→战争这条弧。
- 像素适合「换色盘换心情」：绿、亮、灰、火光。
- **战争/废墟用暖城改：对。** 同一条街从灯火到硝烟到空壳，对比比「另做一张战场图」更痛，也更省工。
- **第一款做成能通关的森林小游戏（Q5）：对。** 把自然做漂亮，既是第一款品质，也是以后战争对比的本钱。城和战争当后话/第 2 款。

### 体量（第一款独立）

4～5 个**全新**世界、每章还很多场景，对第一款来说**偏大**，容易做到一半又烂又没玩法——你的担心成立。

但你已经给了一条减负：战争和废墟不是第 4、第 5 张全新地图，是暖城的两套皮肤。独特世界更接近：

| 世界 | 地图从哪来 |
|------|------------|
| 森林 | 新做 |
| 暖城 | 新做 |
| 工厂 | 多半新做（或城边改） |
| 战争 | **暖城改**（硝烟、破楼） |
| 废墟 | **还是暖城改**（空了、再长草） |

等于主要新做 2～3 套地方，后面是「同一座城变了」。这比五套全新地砖小得多。

**对照（不是劝你放弃大故事）：** 已选大概率 **第 1 款=能单独卖完的森林小游戏**；城和战争以后再做。第一章森林必须能当短篇结束。

不想烂、又要有玩法：第一款把**跳冲滑 + 森林里反复干什么**做好，比五章都薄更重要。

### 开场森林要不要放废墟？

**结尾：废墟长满草、呼应森林——好，建议留。** 玩家记得开头的绿，再看见同一套暖城骨架上长出草，对比会咬住。

**开头森林里就放战争废墟——更容易变差。** 会提前告诉玩家「这世界已经坏了」，和「游戏里先暖、还没发现」打架。

若仍想首尾呼应、又不剧透，只能用**当时看不懂的一点点**：一块长满苔的怪形状，结尾才认出是暖城的某栋楼。开场不要成堆废墟、不要炮痕。

- **化为大自然养料** 和「废墟长草呼应森林」是同一句话：生命回去喂树。这条比纯团圆**更贴你的主旨**，也没那么通用。
- **团圆结局**也可以留作另一档；现在不必锁。
- **坑：** 森林结尾只找到线索（Q7）。通关（Q8→Q9）：**不是抓走。** 小孩被蛇咬 → **B** 与大蛇打（抓瞎一只眼；蛇因费力、嗅到人类父母来而逃走）→ B 也受伤 → 人类父母知真相后带 B 去治疗。悬疑=带走之后治好没有。**不要半路死掉**。

**带走：已选「治疗」**（Q9）。骨架（救小孩打蛇）老套，但接得上先暖和暖城。蛇的「恋战没意义」用行为演：父母靠近就逃，不必内心独白。

#### 开场（Q16 已改，Q21）

**祖辈家 = C 的祖辈家**，不是 A 的，也不是 B 的。  
Q16「A 被派去探望自己祖辈（猫妈妈怀孕、猫爸爸照顾）」**挂错人了，作废**（若还要当 A 家里的闲笔，另说；不再当 A 出现在这片林子的原因）。

正确顺序：

1. B **一开始就不见了**。A 出门找 B。
2. 到达 **C 的祖辈家**之前，A **可能**认识过其他短期伙伴（先不具名，防膨胀）。
3. A **路过 C 的祖辈家**，才遇到 C。因一些事成为好朋友（事由空着）。同行两三关后 C 回家。

第一款不必做成「在爷爷奶奶家过日子」。A 出现在这片林子、路过 C 家的原因=**找 B**，不是来探望。

**和寻猫怎么接：**

- A 与 B **一开始就是好朋友**。B **一开始就不见了**。A 去找 B，**路上路过 C 的祖辈家**，才遇到 C 等一系列事。
- **祖辈家只属于 C。** 不是 A 家，不是 B 家。
- 遇到 C 之前可以有过别的短期伙伴，先不取名。
- C 在自己祖辈家附近认识 A，事由空着；同行后回家。
- A 遇到动物基本都问有没有见到 B。蛇答「见过、往那边」；鸟爸答「人类带走」。

**时间线（Q11～Q16）：隔两三关假同伴，再翻脸。**

人类小孩/父母不在决斗现场。蛇**纯粹的坏**，最终大 Boss，不要可爱。  
揭穿假好人 = 鸟妈。说出带走 = 鸟爸（残血助攻，不当第二可玩角色）。  
中间那两三关 **A 与 C 同行**。蛇只说「见过 B、往某个地方去了」当诱饵；**不说吃了**。吃了是摊牌才甩的谎。  
蛇刚被 **B** 抓瞎眼，**不敢贸然和 A+C 两只猫打**；独眼视力差；路上略变大/略变强。C 回家后才剩 A，它才敢去埋伏。

#### 玩家看不见的前史

1. 小孩被咬 → **B** 与蛇打 → 抓伤蛇眼 → 人类父母带走受伤的 B 去治。
2. 鸟爸爸外出找食物，看见人类抱走伤猫。
3. 蛇踩进猎人捕兽夹（真夹），眼罩挡抓痕。

#### 为了合理，只加这几条

- **C 同行、然后回家。** 家=C 自己那边。A+C=两只猫，蛇才不敢打。遇到 C 之前的短期伙伴不具名。
- **开场原因=A 找 B。** 路过 C 的祖辈家才遇上 C。Q16「A 探望自己祖辈」作废。
- **路上不对劲（当前）：嘴角一丝血 + 狡辩。** 想到更好的可替换。别一嘴鲜红。
- **略变大/略变强**只一点点。蛇作为最终 Boss 不要做成可爱。
- **C 还在时只说「见过 B、往那边」，摊牌才说「吃了 B」。**
- **「往某个地方」含糊或带错。** 真方向由鸟爸纠正。
- **离开的借口仍要像好人**，具体句子未锁。
- 夹子真、眼罩挡抓痕、鸟妈不进 A 这场、鸟爸只助攻：仍锁。
- **路上其他 Boss 名单不先堆**，想到一个记一个。最终大 Boss=蛇。新具名角色先停。

不要半路死。悬疑仍是治好没有。

### 难体现（不是做不到，是要换手段）

| 你想给的感觉 | 游戏里实际靠什么 | 坑 |
|----------------|-------------------|----|
| 难闻的味道 | **NPC + 环境衬托**（捂鼻、台词、灰雾、枯叶） | 台词太直会像说教；环境和 NPC 对上就够 |
| 战争残酷 | 不搞血压刺激；成堆尸体**稍微模糊** | 模糊 ≠ 审核当没看见。Steam 相对能发（要如实勾暴力）。手机/小游戏更严，战争章可能只能 PC 或无尸体版 |
| 「游戏里先暖」 | 前几章不剧透战争；玩家自己走着才变 | **不是**商店页骗人。两件事不要混 |
| 大家都是一家人 | **反战：人类不要屠杀同胞** | 不是交朋友、组家庭 |
| 玩家觉得有意思 | **林子好看 + A 手感 + 该可爱的可爱、蛇要凶** | 故事骨架老套不是主因。素材漂、不像同一只、A 不可爱，才会没意思 |

### 制作顾虑（Q22，比「俗套」更重）

徒弟更担心：素材老出问题、不够可爱、玩家觉得没意思。**这款要上架**，不是练习稿交差。他自己也说不清是「帧和帧不像」还是「不够可爱太糊」——两条都当上架阻断，觉得有用就用。

- **少做几只、做好：** 具名停在 A/B/C + 蛇 + 鸟妈鸟爸。每多一只独特猫，就多一套会漂的皮，商店页一眼能看出来。
- **A 必须稳到能截图：** 黑猫 + 白手套；锁一张标准图再动。未签字不覆盖 `idle.png`；**上架前**必须有一张带白手套的锁图，后面所有帧只改姿势。
- **可爱分级（上架也按这个）：** 鸟、C、路上小动物 → 尽量可爱。小兵可爱可以。蛇和其他 Boss → 不要可爱，要威慑。商店页第一眼：林子美 + A 可爱；蛇只当威胁。
- **第一款的「有意思」：** 森林漂亮、跳得好、救蛇那两三关不对劲和翻脸清楚。不靠再编一条更新的主线。
- 骨骼正本、按动作文件夹收纳。素材不稳时先停生成、先锁参考，不要连夜换画风。AI 可以出草稿，**不能直接当上架精灵表**（会漂）。
- firebot 玩家皮：没签字不换。

### 不合理 / 容易烂尾（范围）

- 五个全新世界一次做完仍容易烂尾。**现在必须有：一个能打完的森林世界**。路上其他 Boss 不先列名单。新具名角色先停（现在有 A/B/C + 蛇 + 鸟妈鸟爸就够写主线）。
- 战争=暖城改：留下。开场森林明显废墟：不建议。结尾废墟长草：建议。

### 过审（战争章，后话）

- 不搞血压、成堆尸体稍微模糊：方向记下。
- **Steam：** 往往能发，但要在后台如实选暴力等描述；模糊是减刺激，不是瞒过勾选。
- **手机应用商店 / 小游戏：** 比 Steam 严得多。若仍要 APK，战争章可能要砍尸体或只出 PC 版。这不是现在森林段的事。

### 师傅补的细节（未锁死，可删）

- 森林高潮（暂定）：B 一开始就不见→A 去找（路上可有无名短期伙伴）→**路过 C 的祖辈家**遇 C→救蛇与 C 同行后 C 回家→蛇打鸟妈→大战（最终 Boss=蛇）→鸟爸说出 B 被带走。Q16「A 探望自己祖辈」作废。
- 暖城三态（后话）：繁华 / 硝烟 / 废墟长草——同一套 TileMap 换砖、换 `CanvasModulate`。
- 工厂气味：NPC + 环境衬托。
- 战场：少血压；尸体可成堆但模糊。刀光另层。

| `0.3, 0.9, 1.0, 0.8` | 偏青的半透明（现在残影用） |

**人话：** 残影是给**影子**染色。以后工厂章可以给**整张关卡**乘一层灰黄（`CanvasModulate`），森林则几乎不乘或乘一点绿。这不是战争特效，是「对比」的技术口。

**语法点：** 四个小数对应 RGBA。`a = 0.8` 表示还有两成透明。

### C. 以后整关变灰（现在不要加进玩家）

```gdscript
# 挂在关卡根上的 CanvasModulate，工厂章举例
$CanvasModulate.color = Color(0.55, 0.55, 0.5, 1.0)
```

| 词 | 人话 |
|----|------|
| `CanvasModulate` | Godot 节点：给这一层画布上的东西整体乘一个颜色 |
| `0.55, 0.55, 0.5` | 发灰发闷，绿被压下去 |

**人话：** 同一只像素猫、同一套跳，走进工厂就像「天变了」。森林章把这行改回接近白 `Color(1,1,1,1)`。这就是「翠绿 vs 灰蒙蒙」在引擎里的最小做法。

**语法点：** `$CanvasModulate` 找子节点。`color =` 赋值。`1.0` 的白 = 不染色。

### D. 地块换皮肤，不是换引擎

测试场已有 `TileMapLayer`（`Scene/node_2d.tscn`）。森林用绿草砖，工厂用水泥砖，是换 TileSet / 图集，角色脚本不用重写。

### E. 暖城三态：同一张地图，换砖（现在不要做）

```gdscript
# 以后：战争章 / 废墟章仍用暖城那张 TileMap 的格子布局
$TileMapLayer.tile_set = war_tileset   # 破楼、焦黑
# 废墟长草章再换成：
$TileMapLayer.tile_set = ruin_grass_tileset
```

| 词 | 人话 |
|----|------|
| `tile_set` | 这层地砖用哪一套图 |
| `war_tileset` | 战争用的砖（缺口、焦） |
| `ruin_grass_tileset` | 废墟上长草的砖 |

**人话：** 街道怎么拐、楼在哪，还是暖城那张。变的是砖的样子和天的颜色。所以「五个世界」里有两个其实是**同一座城的昨天和今天**，工时不是五倍。

**语法点：** `.tile_set =` 是整套换皮。格子坐标不用重摆。
