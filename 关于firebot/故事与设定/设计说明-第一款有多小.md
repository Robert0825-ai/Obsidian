# 设计说明 · 第一款「小」到底有多小

日期：2026-08-17  
来源：徒弟问师傅「第一款必须小」是什么样的小  
对照：[[概念问答-主题与题材]] Q5 · [[设计说明-猫视角冒险与主旨]] · [[设计说明-先短关卡再类恶魔城]] · [[第10课-第一款有多小]]

## 设计原因

「小」如果只是形容词，徒弟会往两个错的方向猜：

1. 猜成 **5 分钟玩具**，和已经选定的「能单独卖完的森林小游戏」打架。  
2. 猜成 **空洞骑士那种一座城**，第一款做不完。

所以「小」要有**能数的尺寸**。下面三档是 nested 的：练习切片 ⊂ 第一款上架 ⊂ 以后的大愿景。

## 三档（人话）

| 档 | 是什么 | 别人玩多久 | 你做多久（一个人、业余） | 算不算「第一款」 |
|----|--------|------------|--------------------------|------------------|
| **A 练习切片** | 一条路，证明走跳冲滑 + 几块地 | **2～8 分钟** | **几天到两周** | 不算。是给自己跑通的 |
| **B 第一款上架** | 一整座森林，能通关，能当短篇结束 | **主线 20～45 分钟**（东摸摸可以到 1 小时） | **几个月，不是几年** | **算。这就是 Q5 那款** |
| **C 太大** | 4～5 个世界、回廊恶魔城、十种怪、技能树 | 5～20 小时 | 几年，容易半路烂 | 第一款不要 |

师傅说的「必须小」，指的是：**做 B，不要做 C。A 是路上的检查站，不是卖的东西。**

不是把你已经点头的森林再砍成一屏方块。

## 对照你熟悉的游戏（感觉，不是抄）

| 体量 | 例子 | 跟 firebot 的关系 |
|------|------|-------------------|
| 比 A 还碎 | 教学关一屏 | 只够测手感 |
| 接近 B | 《蔚蓝》序章那种「能讲完一个完整感觉」；短篇 itch 小品 | **第一款要对这个量级** |
| 已经偏 C | 《空洞骑士》全作、完整类恶魔城 | 那是愿景，不是第一款交付 |
| 你本地的拆包 | Hello Knight | 那是别人 **C 档成品**，不能当第一款尺子 |

《空洞骑士》好看，所以会骗你：你会以为第一款也要那么大。它不是尺子。

## firebot 第一款（B 档）具体格子

已经锁的：森林能通关、漂亮、找 B 的线索、结尾不是打完整条蛇史诗。

建议当成验收用的数（可改，但先有数才知道超没超）：

| 项 | 小（B） | 已经太大（滑向 C） |
|----|---------|-------------------|
| 世界 | **1 座林子** | 林子 + 城 + 工厂一起做 |
| 主线时长 | 自己不刻意磨，**20～45 分钟能看到通关** | 主线超过 **90 分钟** 还没结尾 |
| 相机里的「屏」 | 大约 **8～20 屏** 路（可有分叉，但不是 200 个房间） | 房间数多到你自己都画不完地图 |
| 玩法系统 | **现有的**：走、跳、冲、滑、爬、打。不再加背包经济、多职业、联网 | 每想到一个酷的就加一条系统 |
| 敌人种类 | **1～3 种**（同一种多放几只） | 每种怪一套 AI、一套动画 |
| NPC | C、鸟妈；通关线索（鸟爸可残血出场） | 第一章就做完整蛇 Boss 战 + 全员动画 |
| 美术 | 同一套森林碎块 / 能铺的砖，重复用 | 每屏一张独一无二的海报 |
| 工程 | **1 个玩家场景**反复用；关卡 1～3 个 `.tscn` | 40 个互不相通的关卡文件 |

通关仍按你已答的：森林结尾是**线索 / 带走去治**，不是后话全部演完。

## 怎么自己量（操作）

1. 打开你自己的关，从出生点玩到你认为的「过关」，看手机计时。  
2. 主线 **不到 15 分钟** 且没有故事收束 → 还停留在 A，可以再铺几屏，不必加新系统。  
3. 主线 **超过 90 分钟** 还没有「目击带走」→ 在往 C 滑，先砍房间和怪，不砍跳冲滑。  
4. 每想加一个系统，问：没有它，这座林子还能通关吗？能 → 第一款不做。
