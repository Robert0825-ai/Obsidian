## 为什么这样切（判断依据）

| 原先不妥 | 现在 |
|----------|------|
| 根目录：按键、森林方案、主线、踩坑、黑骑士挤在一起 | 按「打开时会一起看的」拆夹 |
| `角色与外观` 里放 **森林地砖提示词** | 森林进 `美术总监/第一章森林`；总监脑子 00～06 同夹 |
| `像素猫-外观锁定` 孤零零在根上 | 搬进 `角色与外观`（和角色设定、生成提示词是一类） |
| 刀光、Spine、锁骨和森林砖平铺 | `美术/动画与特效` |
| 黑骑士禁区和猫锁并列 | `美术/黑骑士`（不是同一只角色） |
| 跳的参数和键位表和搭场景混在根上 | `输入` / `移动` / `搭建` 三个子夹 |

**故意没把 `角色与外观` 再塞进 `美术/` 或 `美术总监/`：** Cursor 规则路径是 `关于firebot/角色与外观/`。猫锁每天翻；森林关卡是另一件事。A 的 walk/idle 不进总监夹。

**故意没拆 `师傅课`：** 第 1～9 课按编号是一组。课里的设计长文（锁骨、刀光）另放 `美术/动画与特效`，课本身留在 `师傅课`。
