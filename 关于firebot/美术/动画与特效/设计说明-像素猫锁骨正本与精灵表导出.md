# 设计说明 · 像素猫：骨骼是正本，精灵表是导出

日期：2026-08-15  
细讲与代码：[[第8课-锁骨做动画再导出帧]]  
外观：[[像素猫-外观锁定]]

## 设计原因

徒弟选择：**先锁骨做走/跳等动画，再导出帧图、精灵表、未分割图**，避免 AI 逐帧漂成另一只猫，并希望 Godot 里更流畅。

这管线**能做完**，也是常见烘帧做法。骨头真正强的是游戏里**直接播骨骼**（中间姿势是算的）。`AnimatedSprite2D` 只换 PNG，不会自动补帧；烘少了仍会顿。帧/表/未分割要留作备份，**能拉的骨头工程才是正本，不要删**。按动作文件夹收纳：`帧图` `精灵表` `未分割图` `骨骼` `动画`。特效不画进 PNG；残影用游戏生成，其它用粒子。

皮未定：不拆件、不换进 `fighter_player.tscn`。

## 数据流

```
定皮 → 拆件 → 各动作/骨骼 + 动画（正本，禁止删）
                ↓ 烘帧
         各动作/帧图 + 未分割图 + 精灵表
游戏层另做：残影 spawn_one_afterimage；刀光等 GPUParticles2D
         不要画进上述 PNG
```

物理：`fighter_player.gd` 改 `velocity` → `move_and_slide()`  
画面：现在 `AnimatedSprite2D` 换图；以后 `AnimationPlayer.play("Jump")` 或填烘好的帧。
