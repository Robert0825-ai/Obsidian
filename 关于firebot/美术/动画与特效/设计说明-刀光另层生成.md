## 设计原因

徒弟要刀光，并直觉 `spawn_one_afterimage()` 做不出来。该函数复制**整只角色当前帧**并淡出，是残影，不是弧形刀光。

2D 大作常见做法：角色 PNG 保持干净姿势；**攻击时另开一层**播弧光图（空洞骑士一类）。粒子做火花/尘土，不单独承担那道「C」形。刀尖带子、shader 扇形是更强后路，快斩时带子还可能缺口。

徒弟补充：**类似刀光这种「印角色印不出来」的，还是要另生成。** 判断口诀见第9课 §6。已点名刀光；其它对照项点名再做。图放 `四脚猫/fx/`。

## 数据流（以后）

```
按攻击 → 播角色 Attack 姿势（干净猫）
       → instantiate 刀光场景（弧光图，身前，跟 facing 翻转）
       → 可选：命中时 GPUParticles2D 火花
不要：把弧画进 idle/walk；不要用 get_frame_texture(角色) 当刀光
```

现有对照：`sword_player.gd` 里残影 / 疾风线已是独立 Effects 插头；刀光应是攻击插头，不是改残影函数。
