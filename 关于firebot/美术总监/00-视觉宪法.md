# 00 · 视觉宪法

日期：2026-08-16  
用途：任何一张图、一块砖、一层背景，先过本页再画。  
对照：[[像素猫-外观锁定]] · [[设计说明-第一章森林美术方案]]

---

## 一句话

**温暖、治愈、生机、童话、自然的横版森林；笔法跟那只黑猫；结构可以像「草盖在土上的有机平台」，心情不可以像空洞骑士的暗。**

## 五条决策（拍板，不要每张图再讨论）

1. **同一片林子。** 第一章一套草/土/石/木/藤色盘。区域差异 = 阳光多少 + 叶子疏密 + 平台形状 + 很浅的空气颜色。禁止为每个区新做一套画风。  
2. **猫是近黑剪影。** 琥珀眼和白手套是唯一的「亮点」。场景绿必须让眼睛和爪子跳出来。密林可以墨绿，禁止把背景做成和猫身体一样的炭黑。  
3. **1 像素硬描边 + 每色最多 3 档。** 平涂。禁止抗锯齿、照片纹理、渐变雾烤进砖里。视差远景 **不要描边**。  
4. **光从右上来。** 和猫背、头上的亮边一致。林窗可以有暖光柱 `#ffd88a`，光柱是半透明另层，不画进地砖。  
5. **玩法先于漂亮。** 图要能回答：走 / 跳 / 冲 / 滑 / 爬 / 藏。装饰藤无碰撞；可爬藤一眼能认。不要梯子。

## 我们是 / 我们不是

| 是 | 不是 |
|----|------|
| 早晨到黄昏的林子，空气是金绿的 | 暗魂、空洞骑士的黑、废土 |
| 童话里「能住进去」的自然 | 糖彩霓虹、Q 版三头身场景 |
| 侧面横版，地是横条 | 俯视 RPG 地砖 |
| 野生，无项圈、无路牌文字 | 现代公园指示牌、UI 画进场景 |
| 开场美好 | 开场废墟、蛇巢当主视觉 |
| 野生硬像素 / 他点名的夜或赛博试稿 | 马里奥卡通平台（生成默认禁；要用先申请） |

## 和空洞骑士的关系（只说一次）

借：**草/苔盖在潮土上、顶边略有机、可以藏、可以爬。**  
不借：手绘软边、雾画进砖、暗金对比、骑士剪影气质。

气质可对一眼（只借心情，不借笔法、不抄砖）：Ori 的林间暖光、Spiritfarer 的「能住进去」、Celeste 的「一屏能读出能跳到哪」。笔法仍锁猫。

## 禁止清单（场景）

- 木梯、铁梯、绳梯（爬 = 藤）  
- 项圈、铃铛、第二只猫画进装饰  
- 刀光、雾、粒子焊进 walk/idle 或地砖  
- 红/青/黄调试色、文字水印  
- 俯视、等距  
- 灰绿（没生机）、荧光绿（假生机）  
- **AI 味**（见下；过稿一票否决）
- **马里奥风**（2026-08-16 他禁）：生成素材默认不准。红伞白点菇、亮绿圆丛、棒棒糖树、Kenney/SMW 卡通平台参考。要用必须先申请。工程里已有 Kenney 临时砖可继续铺，那不是新生成。规则 `no-mario-style`

## 什么叫 AI 味（2026-08-16 他问过，必须懂）

AI 味 **不是**「这张图是不是 AI 画的」。Kenney 那种人画的简单砖可以没有 AI 味；生成图就算很密、很精致，也可以全是 AI 味。

它是眼睛的第一感觉：**像一张生成海报 / 概念图，不像能铺进游戏的一套像素。**

| 有 AI 味（拒） | 没有（要） |
|----------------|------------|
| 颜色糊成一团，档数数不清 | 每材料大约 3 档，能点着像素数 |
| 叶子/苔是棉花绿团 | 成簇、有边、苔往下挂 |
| 树皮像 3D 材质、水像照片 | 裂纹是 1～2 像素的线 |
| 每张都是独一无二的「作品」 | 同一套砖能重复铺 |
| 自己发明宝石、门缝神光、符文 | 只用宪法里有的零件 |
| 灰底正中摆一件，像商品图 | 按格子、能拼接、能进 512×288 的屏 |
| 这一张圆、下一张尖；这一张亮、下一张灰 | 整套像同一片林子 |

反面教材：`assets/forest/` 里 v3/v4 生成套。正面对照：苔石锁、花木锁、Kenney 草地（简单但齐）。

## 心情软 ≠ 笔法软（2026-08-16 他问）

「温暖、治愈、童话」是**心情**，不是叫出图模型把毛画成棉花、把苔画成绿雾。

| | 要 | 不要（一写进提示词就 AI 味） |
|--|----|------------------------------|
| 猫 | 硬 1 像素外轮廓、平涂 3 档、剪影清楚。可爱靠大琥珀眼和白手套，不靠绒毛发光 | fluffy / soft fur / airbrush / glow / 圆棉花身子 |
| 林 | 苔成坨往下挂、草有顶边、能当砖重复 | gentle moss / dreamy light / painterly / 每张独一无二的海报 |
| 骑士为什么好看 | 盔甲、剑、披风是**硬材料**，剪影狠，模型最会画「一张酷插画」 | 把同一套「漂亮插画」能力拿去画可拼接的软森林，会翻 |

**生硬**不是因为画软画失败。软词只会让毛边糊、关节更看不清。游戏里能动、能读的猫，笔法要硬；心情可以软。

## 总监怎么拍板一张图

过这 4 问，全是才进游戏：

1. 侧面吗？和猫同一套描边粗细吗？  
2. 黑猫叠上去，头和眼睛还在吗？  
3. 这张图在教走跳冲滑爬藏的哪一个？  
5. 有没有 AI 味？（糊团、商品图、发明宝石门光、不能当砖重复）有就退。
