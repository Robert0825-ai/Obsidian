# 03 · 镜头分层与可读性

日期：2026-08-16  
一屏 512×288 世界像素（见 [[01-比例与像素密度]]）。黑猫必须在任何区都读得出来。

---

## 五层（每屏都有，不许省）

从后到前：

| 层 | 节点习惯 | 视差 | 描边 | 职责 |
|----|----------|------|------|------|
| L0 天/冠 | `Parallax2D` 几乎不动 | 0.05～0.1 | 无 | 暖天、树冠漏光。不要照片蓝天 |
| L1 远 | `Parallax2D` | 0.2～0.3 | 无 | 浅雾绿树柱 `#63a08a` |
| L2 中 | `Parallax2D` | 0.5～0.6 | 无 | 中绿树团 `#2c5a45` |
| L3 Play | `TileMapLayer` + 道具 | 1.0 | **有** | 碰撞、猫、可互动物 |
| L4 前景 | `Parallax2D` 或贴在相机前 | 1.15～1.3 | 有，但更暗 | 只挡 **腿和脚**，到不了眼睛 |

密林若加「近景暗树拱」，放在 L2 和 L3 之间，**左右和顶可以暗，画面中带必须透**，给猫留空。

## 黑猫可读性（硬指标）

叠一张猫在场景上，必须同时看见：

- 耳朵尖  
- 琥珀眼  
- 白手套（至少一只）  
- 身体剪影和背景不是同一明度  

自检：把场景截图转成灰度。如果猫身体和身后树干糊成一块，背景太暗或太黑绿 → 加亮 Play 层后的 8～16 像素（土的亮档、叶缝、浅边）。

前景草最高到猫胸口以下。垂藤装饰可以过画面，但不要一条黑藤贴在猫头上。

## 构图习惯

- 主路沿屏幕 **下 1/3 到中线** 走，不要整屏贴地（看不见树）也不要猫永远在屏幕底边。  
- 沟、对岸、高台要在 **当前屏内看见**，玩家才知道能回去。类恶魔城靠「看见够不着」。  
- 存档、门、家：剪影要比普通灌木 **高一截、对称一点**，才能当路标。  

## UI（以前完全缺）

第一章 **不要**把 HUD 画成森林浮雕。手感测试阶段：

| 元素 | 美术规格 |
|------|----------|
| 触屏键 | 现有 `touch_controls.tscn` 可先保持干净几何；若换皮：半透明深色圆 + 1px 暖边，不要大块木纹挡住场景 |
| 血量/生命 | 若有：小图标跟猫眼睛同色系琥珀，不要红十字医院风 |
| 暂停 | 半透明暖暗幕 + 大字；不要突然变黑魂菜单 |
| 对话 | 第一章遇 C、鸟：浅暖底、深字；不要游戏机绿屏 |

UI 是 **另层 CanvasLayer**，不进 TileMap。第一章可以极简，但颜色必须服从宪法：暖、不霓虹、不纯黑。

## 安全区

屏幕四角留给触屏（左摇杆、右技能）。**重要路标不要画在右下角技能键底下。** 存档石放中景偏左或偏上，不要贴死右下。
