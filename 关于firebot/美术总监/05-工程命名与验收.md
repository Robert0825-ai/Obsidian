## 仓库里的目录（新建，不要和猫帧混）

猫帧继续：`assets/pixel_cat/`。  
森林全部进：

```
assets/forest/
  tiles/          32×32 砖、水面、可爬藤、树干段
  props/          石、花、灌木、倒木、装饰藤、门、存档
  parallax/       L0–L2、光柱、前景草
  fx/             尘、花粉、落叶、烟
  npc/            C、鸟妈（以后）
```

文件名：**英文小写 + 下划线**，能从名字看出区和种类。

例：

- `tiles/grass_top_01.png`  
- `tiles/dirt_fill_01.png`  
- `tiles/vine_climb_01.png`  
- `props/vine_deco_hang_01.png`  
- `props/rock_s_01.png` … `rock_l_03.png`  
- `props/save_stone_01.png`  
- `parallax/far_mist_a.png`  
- `fx/dust_land_01.png`

禁止：`最终最终2.png`、`藤蔓拷贝.png`、中文文件名（Godot 在部分环境下会烦）。

## 总监过稿清单（每一批素材）

生成之后、进游戏之前：

- [ ] 侧面，不是俯视  
- [ ] 1px 描边（远景层除外）  
- [ ] 该材料只有 3 档色  
- [ ] 草是黄绿、藤是墨绿，没有并成一种  
- [ ] 没有 AI 味（糊团 / 商品图 / 发明零件 / 不能当砖重复），见 [[00-视觉宪法]]  
- [ ] 没有猫、没有字、没有梯子  
- [ ] 砖：左右（或上下）能接  
- [ ] 能踩的顶面够宽  
- [ ] 灰度下黑猫还在  

进游戏之后：

- [ ] 文件在 `assets/forest/` 且已 import  
- [ ] 日志无 `Failed loading resource`  
- [ ] 脚踩在砖顶，不漂、不陷  
- [ ] 装饰藤穿身无碰撞；可爬藤能爬  
- [ ] 前景没有挡住 Amber 眼  

**没过清单的图，不准进第一章关卡。** 宁可少，不要一屏复制同一块大石头。
