# 07 · 出图走哪条软件（助手必须用）

日期：2026-08-16  
他拍板：**不买 PixelLab。** 像素正本在 **Aseprite**（他已有 1.3.17）。助手要画进 `.aseprite`，方便他打开改、看图层和帧。PNG 只是导出给 Godot。

---

## 有没有 MCP？

Aseprite **官方没有** MCP。社区有：

| 包 | 适合 |
|----|------|
| **[diivi/aseprite-mcp](https://github.com/diivi/aseprite-mcp)**（已接到 `mcp.json`） | 画笔工具多。本机：`C:\Users\yehai\Projects\aseprite-mcp` |
| aseprite-live-mcp | 试过：和当前 `mcp` 库版本对不上，先不用 |

MCP 是**遥控画笔**（建画布、铺像素、图层、帧），不是网页那种「一段英文出一张图」。复杂角色仍可先出图再 **导入成图层**；砖、藤、简单道具可以直接在 Aseprite 里画。

## 分工

| 软件 | 干什么 |
|------|--------|
| **Aseprite** | 正本 `.aseprite`。助手 MCP / `--batch` 脚本写入；他在窗口里改 |
| **Godot** | 只吃导出的 PNG |
| PixelLab | **不买、不用** |
| Cursor GenerateImage | 不当成品；最多当参考再导入 Aseprite |
