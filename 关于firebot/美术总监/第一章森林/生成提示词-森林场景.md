## A · 风格锁（每次都贴）

```
STYLE LOCK — match the attached cat sprite's craft exactly:
True pixel art on a visible pixel grid. 1-pixel hard near-black outline (#14100f) around every solid shape.
Flat cel-shading, at most 3 tones per material (light / mid / shadow). No anti-aliasing, no blur, no gradients, no dithering noise, no painterly brushwork, no photo texture, no outer glow.
Light comes from the upper right; highlights on top edges, shadow underneath.
SIDE VIEW for a 2D side-scrolling platformer (not top-down, not isometric, not 3/4).
Warm, lush, alive forest palette:
grass #9ede4f / #4faa4a / #24693f
dirt  #a9713f / #7c4a2a / #4d2d1c
stone #9aa39b / #6b7570 / #414a48
wood  #b07a44 / #7d5230 / #4a2f1c
sunlight #ffd88a, deep forest #1d3b32, mid forest #2c5a45, far mist #63a08a
Do NOT copy the cat itself. Reference it only for outline weight, pixel density and shading style.
```

## B · 禁止项（每次都贴）

```
FORBIDDEN: anti-aliased or soft edges; painted fog or glow baked into the sprite; more than 3 tones per material;
gray-washed or desaturated colors; neon or acid colors; text, logos, watermarks, UI frames;
characters, cats, knights, insects, people; cyan / magenta / yellow debug colors;
top-down or isometric view; drop shadows on the background; copying any existing game's official assets.
```

## 自检（生成后看这几条）

- 描边是不是和猫一样粗，颜色是不是每种最多 3 档
- 是不是真格子（放大后是方块，不是模糊边）
- 草是翠绿带黄绿高光，不是灰绿、不是荧光绿
