## 完整制作方案

### 阶段 0 · 文档对齐（0 张图）

1. 提示词文首标明：G6、J2 第一章停用；爬 = 藤。  
2. 新笔记只链 [[笔记分类]]，避免再写进「随便一篇设计说明」。  
3. 锁图继续用 `A_暂定皮.png`；PixelLab 上传 `A_暂定皮_pixellab256.png`。  
4. 工程验收脚本已有：`tools/preflight_resources.py`、`tools/audit_cat_frames.py`（角色帧）。场景砖进工程后补「Failed loading resource」无界面跑。

**本阶段完成标准：** 任何人打开提示词，不会再去生成木梯子。

### 阶段 1 · 能走路的一屏（F1 最小）

目标：Godot 里猫能站在草地上向右走，脚不漂。

| 序 | 素材 ID | 用提示词 | Tile / Sprite | 次数预算（约） |
|----|---------|----------|---------------|----------------|
| 1 | T-grass | C1 | Tile 32 | 20～40 |
| 2 | T-dirt | C2 | Tile 32 | 20～40 |
| 3 | T-edge | C3 | Tile 32 | 20～40 |
| 4 | 拼进 `TileMapLayer` | — | 工程 | 0 |

**验收：** 无界面加载无 `Failed loading resource`；猫碰撞底边贴砖顶；三块横拼看不出接缝。失败就重出砖，**不要**先画树。

### 阶段 2 · 一屏像森林（仍是 F1）

| 序 | 素材 | 提示词 | 说明 |
|----|------|--------|------|
| 5 | T-slope | C4 | 可推迟到溪谷前 |
| 6 | L1 远景（改 320 宽条，横拼两条） | F1 改尺寸 | 不要描边 |
| 7 | S-rock 多尺寸 | **J1** | Size 48 出表 |
| 8 | 小花 / 矮草 | D4 矮的 + D6 | Sprite |
| 9 | 前景草 | F6 | 只挡腿 |

**验收：** 同一屏里石头有大有小；黑猫叠在远景上仍看得出耳朵和眼睛。

### 阶段 3 · 藤（按你已签字的样子）

| 序 | 素材 | 做法 |
|----|------|------|
| 10 | S-vine-deco | **一条墨绿带叶垂藤**，无碰撞。不要梯子、不要横档。提示词用本篇「补丁 A」 |
| 11 | T-vine-climb | 可竖拼 32 砖，墨绿带叶，能看出「可爬」但不是木梯。提示词用「补丁 B」 |

**验收：** 两张并排，玩家能分清「挂着的」和「能爬的」。

### 阶段 4 · 溪谷能过（F2）

岸 E3、水面 E1、倒木 D5、石墩用 J1 里扁顶那几块。瀑布 E2 放到隐藏之前。

**验收：** 跳过一条浅溪；水会动但水位不变。

### 阶段 5 · 密林房间（F3）

T-trunk（D3）、S-canopy（D2）、装饰藤多摆、可爬藤当竖路。近景视差 F3 必须中间镂空。

**验收：** 平路被挡住后，能沿藤上去，到上层平台。

### 阶段 6 · 林窗 + 根廊 + 林屋（F4–F6）

存档 G2、光柱 F4、花更多。根廊：土更深（C2 变体）+ 滑铲高度的洞。林屋：门 G1 改成暖木+苔，不要地牢拱门感。可破坏墙 G3。

**验收：** 能存档；能从洞钻到另一边；能看见「家」的剪影。

### 阶段 7 · 隐藏与粒子

瀑布后、叶帘、碎墙。粒子 H 最后加，禁止焊进砖。

## 进 Godot 的固定流水（每批素材都走）

1. PNG 放进 `firebot/assets/` 对应文件夹（不要只放在 Cursor `assets/`）。  
2. 编辑器打开工程或无界面 `--import`，确认有 `.import`。  
3. Tile：建成 `TileSet`，碰撞多边形贴顶边。  
4. Sprite：`Sprite2D`，`texture_filter = nearest`。  
5. 装饰藤：**不要**加碰撞。可爬藤：碰撞或 `Area2D` 给现有爬。  
6. 跑预检：日志无 `Failed loading resource`。  
7. 才叫人打开场景。

角色帧继续走现有 `build_cat_a_frames.py` / `audit_cat_frames.py`；**场景砖不要拿去跑猫的体量审计**。

## PixelLab 额度（Apprentice 2000 次）怎么花

按「点一次 20～40 次」计，第一章主路径大约：

| 批次 | 轮数 | 约扣次数 |
|------|------|----------|
| 草土边砖 | 3 | 60～120 |
| 远景两条 | 2 | 40～80 |
| 石头表 J1 | 1 | 20～40 |
| 花草前景 | 2 | 40～80 |
| 装饰藤 + 可爬藤 | 2 | 40～80 |
| 水/岸/倒木 | 3 | 60～120 |
| 树干+叶簇 | 2 | 40～80 |
| 存档/门/碎墙 | 3 | 60～120 |
| **合计主路径** | ~20 轮 | **约 400～800** |
| 试错预留 | | 建议再留 400 |

256 一次一张的点法**禁止**当主流程。绳桥、尖刺、宝箱、木梯不进这 800。

## 提示词补丁（先写入提示词笔记，生成时用）

### 补丁 A · 装饰用，一条墨绿带叶藤（无碰撞）

用途：S-vine-deco。禁止梯子、横档、双杆。

```
SUBJECT: ONE single hanging forest vine, side view, pixel art.
A single dark ink-green vine (墨绿) hanging down, with small leaves along the stem. Not a ladder, no rungs, no wooden poles, no rope ladder.
Palette: ink green #1a3d32 / #245c45 / #2f7a58 only (3 greens). No yellow-neon, no brown wood rails.
1-pixel hard black outline, flat cel-shade. SIDE VIEW. Transparent background or #888888.
Width about 16-32px, height 96-160px. One vine only. No characters.
```

### 补丁 B · 可爬藤砖（仍是藤，不是梯）

用途：T-vine-climb。可竖拼。

```
SUBJECT: one seamless vertical CLIMBABLE VINE TILE, exactly 32x32 pixels, side view.
Dense dark-green living vines with leaves, a slightly straighter column so it stacks into a climbable wall. Player must read it as climbable: irregular leafy footholds, NOT wooden ladder rungs, NOT two poles with steps.
Palette: #1a3d32 / #245c45 / #2f7a58. 1px black outline, 3 tones. Seamless top-to-bottom.
Transparent background. No characters.
```

G6、J2 全文保留在提示词笔记里当历史，文首标注停用即可。
