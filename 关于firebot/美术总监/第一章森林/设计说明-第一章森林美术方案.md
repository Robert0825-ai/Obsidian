## 游戏定位（美术必须服从）

| 项 | 锁 |
|----|----|
| 类型 | 2D 横版，目标类恶魔城；第一款先交付能通关的森林 |
| 主角 | A：四脚黑猫、白手套、无项圈，侧面朝右 |
| 气质 | **温暖、治愈、生机、童话、自然**。不是空洞骑士式黑暗、不是废土 |
| 结构可学 | 苍绿之径那种「草盖土、有机边、可爬可藏」；**笔法必须跟猫**：1px 硬描边、每色最多 3 档 |
| 故事在这一章 | A 找 B；路上温暖；**路过 C 的祖辈家**才遇 C。开场森林 **不要战争废墟** |
| 黑猫可读性 | A 是近黑剪影。背景不能同样是一团黑绿，否则猫会溶掉 |

### 总监三条硬规矩

1. **一套砖，多种密度。** 第一章只用同一套草/土/石/木色盘。区域差异靠：阳光多少、叶子疏密、平台形状、空气颜色（很浅的 `CanvasModulate`），不要做 7 套完全不同的 tileset。  
2. **玩法先于漂亮。** 每张图先回答：玩家在这是走、跳、冲、滑、爬，还是藏。不能回答的图，不进第一章。  
3. **装饰不挡读图。** 前景草、垂藤可以遮一点腿，**不能遮头和琥珀眼睛**。可爬的藤必须一眼看出「能上去」，装饰藤必须一眼看出「只是挂着」。

## 1. 第一章森林应该有哪些区域

商业第一章：玩家 **40～90 分钟**能走完主线，并愿意绕回去找藏物。区域 **5 个主场景 + 1 个故事锚点**。全部仍是「同一片林子」，不是五个星球。

```
林缘晨光 ──► 苔径溪谷 ──► 藤影密林 ──► 阳光林窗（休息）──► 祖辈林屋外围
    │              │            │              │
    └──── 根廊（地下捷径/隐藏）◄─┴──────────────┘
              学会爬藤或冲刺后，可从林窗抄回路缘
```

| 编号 | 区域 | 玩家经过时在干什么 | 氛围（仍是暖的） | 这一段教什么 |
|------|------|-------------------|------------------|--------------|
| F1 | **林缘晨光** | 从空地走进林子，平路、小台阶、几朵花 | 金绿、侧光、最「童话」 | 走、跳；建立「这世界是安全的」 |
| F2 | **苔径溪谷** | 贴着浅溪向右/向上，踩草台和倒木 | 湿润、水光、黄绿高光更亮 | 落差、单向台、第一次小水坑 |
| F3 | **藤影密林** | 树干变密，主路变窄，必须往上爬 | 墨绿为主、光斑从叶缝漏下来 | **爬藤**；第一次「迷路但不可怕」 |
| F4 | **阳光林窗** | 突然开阔，能坐、能存 | 最暖、花最多、鸟鸣感（画面上用花和光柱代替） | 休息、存档、给故事换气 |
| F5 | **根廊** | 从溪谷或密林的洞钻进去，低矮、可滑 | 土暖褐 + 根，不阴森 | 滑铲隧道、隐藏、把地图连成环 |
| F6 | **祖辈林屋外围** | 主线终点方向：能看见家，先不进战争 | 木屋+花圃+旧石，仍是森林童话 | 故事锚点（遇 C 的舞台）；独特但复用木/石砖 |

**不放进第一章的：** 蛇巢、眼罩蛇、工厂、废墟、夜晚全黑、血雾。蛇若出现，最多在林窗或林屋附近「受伤的暖色鳞光一瞥」，不能把区域画成洞穴恐怖片。

### 玩家主路线（商业关卡读法）

1. **F1 林缘**：从左进，地面连续，右边第一道矮坎用跳过。镜头里能看见远景树，告诉玩家「林子很深」。  
2. **F2 溪谷**：路被浅溪切开。玩家沿石头/倒木跳过水面；低处有看得见但暂时够不着的对岸（以后冲刺或从根廊绕）。  
3. **F3 密林**：平路被树根挡住 → 看见**一条带叶的墨绿藤**挂在可爬的树干上 → 向上进入立体层。这里第一次给「房间」感（左右都有墙）。  
4. **F4 林窗**：爬出密林后的奖励空间。存档点、阳光、花。鸟妈可以在这里用可爱剪影出现（不必第一章就开战）。  
5. **F6 林屋**：从林窗再向右/向下，地面出现人工痕迹（石径、篱笆、烟，但是暖的炊烟）。第一章主线停在「看见家、遇见 C」或「家在眼前但要先帮一个小忙」。  
6. **回头**：拿到爬或冲之后，F5 根廊打开，林缘的高台和溪谷对岸变成捷径。这才是类恶魔城，不是一直往右走。

### 场景层次（每一屏都这 5 层）

从后到前，商业横版标准层。黑猫走在 **Play** 层。

| 层 | 名字 | 动法 | 画什么 | 描边 |
|----|------|------|--------|------|
| L0 | 天 / 冠 | 几乎不动或极慢 | 树冠漏光、暖米色天，不要大块蓝天写真 | **不要**黑描边 |
| L1 | 远景 | 视差 0.2～0.3 | 雾树剪影，浅雾绿 `#63a08a` | 不要描边 |
| L2 | 中景 | 视差 0.5～0.6 | 树团、远树干，中绿 `#2c5a45` | 不要描边 |
| L3 | **Play 碰撞层** | 1.0 | 地砖、水、可爬藤、倒木平台、石头、屋子 | **要** 1px 描边 |
| L4 | 前景 | 视差 1.15～1.3 | 遮挡草、近叶，略暗，只挡腿和脚 | 要描边，但更暗 |

光：默认从**右上**来（和猫高光一致）。林窗加几条暖 `#ffd88a` 光柱（半透明叠层，不要画进地砖）。密林减少光柱、增加叶缝光斑。

### 地形变化（用同一套砖拼出五种走法）

| 走法 | 地形 | 出现区域 |
|------|------|----------|
| 走 | 连续草皮盖土，顶边几乎平 | F1、F4、F6 |
| 跳 | 缺口 1～2 格；溪上石墩 | F1 末、F2 |
| 冲 | 3～4 格宽沟，或看得见的对岸 | F2 回头、F4 后 |
| 滑 | 根廊净高约 1 只猫高的隧道 | F5 |
| 爬 | 竖着的墨绿藤面，不是木梯子 | F3 主、F5 连接竖井 |
| 藏 | 瀑布后、可破坏苔墙、草帘后的小室 | F2、F3、F5 |

### 隐藏区域（第一章至少 3 处，全部「温暖的秘密」）

1. **溪谷瀑布后**：浅瀑后面一条干廊，里面是花或一枚收集物，不是骷髅。  
2. **密林草帘 / 叶帘**：看起来像墙的垂叶，走过是空的（无碰撞），后面小平台。  
3. **根廊可破坏苔墙**：外观几乎等于普通石/土，只有细裂纹和苔藓略不同；打了出现回头捷径。  

隐藏里禁止：血、骨头堆、突然变黑。秘密也要像童话里「树洞里的巢」。

## 2～3. 每个区域需要哪些素材，以及为什么

下面「为什么」只回答关卡和气质，不写生成提示词。

### F1 林缘晨光

| 素材 | 为什么需要 |
|------|------------|
| 草皮盖土地砖 + 左右端 + 斜坡 | 玩家 80% 时间踩这个；第一章记忆色 |
| 土填充砖 | 平台下面不能镂空；切面要像潮土 |
| 远/中/前景三层树 | 没有层次会像纸片关卡 |
| 2～3 棵完整大树（稀疏） | 「刚进林」，树要少、要能数清 |
| 小石、卵石若干尺寸 | 打破地砖重复；衬托猫的体量 |
| 矮草丛、小花（白/暖黄） | 治愈、童话；告诉玩家可以靠近植物 |
| 阳光光柱（淡） | 晨光；后面密林会对比变少 |
| 前景遮挡草（矮） | 镜头有深度；F1 不要太密 |

### F2 苔径溪谷

| 素材 | 为什么需要 |
|------|------------|
| 岸边砖（草土接水） | 溪是这一段的「路的形状」 |
| 水面砖（可 4 帧） | 活的水 = 生机；水位必须固定 |
| 浅瀑（可拼竖条） | 隐藏入口的门面；也是声音/动效锚点 |
| 倒木平台、树桩 | 过溪的脚踏；比纯砖更自然 |
| 石墩（中等、扁平顶） | 跳点；顶面必须能站 |
| 芦苇 / 岸草 | 岸的轮廓，避免土块直接切进水 |
| 可踩单向木台（薄） | 从下往上跳到溪岸上层 |

### F3 藤影密林

| 素材 | 为什么需要 |
|------|------------|
| 更密的中景树干 | 把路收窄，产生「房间」 |
| **装饰用墨绿垂藤（一条，带叶）** | 气质；**无碰撞**。你指定的样子：一条墨绿、带叶子，不是梯子 |
| **可爬藤面砖** | 玩法。必须有可读的「手点/叶阶」，否则玩家不知道能爬 |
| 树干段砖（可竖拼） | 当墙、当爬的附着物 |
| 叶簇（大中小） | 遮挡上层、做树冠天花板 |
| 光斑碎点（很淡） | 密但不黑；黑猫还要能看清 |
| 叶帘（无碰撞） | 隐藏 2 |

### F4 阳光林窗

| 素材 | 为什么需要 |
|------|------------|
| 开阔草地（仍用 F1 砖） | 奖励「终于出来了」 |
| 花变体更多、蘑菇点缀 | 治愈顶点；仍禁止文字和 UI 画进图 |
| 存档石 / 休息标记 | 类恶魔城刚需；外形要像被苔和花吞掉的旧石，像安全 |
| 强光柱 | 和密林对比 |
| 鸟巢或鸟剪影（小） | 给鸟妈铺垫；第一章可以不说话 |
| 坐石 / 倒木长凳感 | 暗示「可以停」；不必真做坐下动画也能懂 |

### F5 根廊

| 素材 | 为什么需要 |
|------|------------|
| 更深的土填充、露出的根砖 | 地下仍是暖褐，不是灰洞穴 |
| 低平台、扁隧道口 | 滑铲的形状要从美术上读出来 |
| 可破坏苔墙（3 帧） | 隐藏 3 + 地图成环 |
| 少量发光菌/暖黄小点 | 照明，不是恐怖绿光 |
| 竖井可爬藤 | 从地下回到林窗 |

### F6 祖辈林屋外围

| 素材 | 为什么需要 |
|------|------------|
| 石径砖（仍 3 色，带苔） | 第一次「有人住过」；仍是森林材料 |
| 木篱 / 门框 / 窗（独立图） | 家的剪影；不要现代房屋 |
| 花圃、陶盆不要（野生林子） | 用地上的花簇代替人工盆，保持野生童话 |
| 暖烟（粒子，不画进砖） | 有生活；C 的家 |
| 旧石阶 | 把「屋」接到草地上 |

## 4～5. Tile 还是独立 Sprite

**原则：** 会左右/上下重复、要碰撞成面的 → Tile。只会摆一次、轮廓独特、或要动画的 → Sprite。

### 做成 Tile（`TileMapLayer`，建议 32×32）

| ID | 名称 | 碰撞 | 备注 |
|----|------|------|------|
| T-grass | 草皮盖土顶砖 | 实心 | 主地面；左右无缝 |
| T-dirt | 土填充 | 实心 | 四向无缝 |
| T-edge | 左右端、悬崖面、内角 | 实心 | 草要包边 |
| T-slope | 45° 上下坡 | 斜碰撞 | 跟猫脚线对齐 |
| T-stone | 苔石填充 / 岩台顶 | 实心 | 溪谷石墩也可用 |
| T-root | 根土填充 | 实心 | F5 |
| T-water-top | 水面 | 无或伤害以后再定 | 第一章建议无伤浅水 |
| T-water-fill | 水体 | 无 | 四向无缝 |
| T-waterfall | 瀑布中段 | 无 | 上下无缝；后可走 |
| T-vine-climb | **可爬墨绿藤面** | 爬墙检测 | 四向或至少上下无缝；**有横档感但不能画成木梯** |
| T-trunk | 树干段 | 实心墙 | 上下无缝 |
| T-oneway | 薄草/木顶 | 单向 | 可做 32×16 半格 |
| T-break | 可破坏苔墙 | 实心→空 | 外观接近 T-stone |

### 做成独立 Sprite（节点摆放，可加动画）

| ID | 名称 | 为什么不做成砖 |
|----|------|----------------|
| S-tree | 大树（干+冠可拆） | 轮廓太大，砖会切冠 |
| S-canopy | 叶簇 3 尺寸 | 叠在树干上，不规则 |
| S-vine-deco | **一条带叶墨绿垂藤** | 你要的装饰藤；不规则弯曲，砖会假 |
| S-vine-top | 藤的挂点（钩在枝上） | 只出现在顶 |
| S-rock-* | 卵石到巨石，多尺寸 | 要大小变化，砖一种会「全图复制粘贴」 |
| S-bush / S-fern / S-flower | 灌木蕨花 | 摆在地面上沿，不参与填充 |
| S-log / S-stump | 倒木、树桩 | 既是道具也可当短平台（碰撞盒另加） |
| S-reed | 芦苇 | 只在岸边 |
| S-save | 存档石 | 唯一、要 2 帧呼吸光 |
| S-door | 林屋门洞 | 唯一 |
| S-pickup | 种子/果/木符 | 24px 级，要闪 |
| S-beam | 光柱 | 半透明叠层 |
| S-fg-grass | 前景草带 | 横向可平铺的长条，但是前景层 |
| S-leaf-fall | 落叶粒子图 | 特效，不进砖 |
| S-break-chunks | 墙碎块 | 破坏动画 |

**同一条藤的两种身份（不要混）：**

- `S-vine-deco`：一条墨绿色、带叶子、自然下垂。**无碰撞。**  
- `T-vine-climb`：仍然是墨绿带叶，但柱面更直、能竖着拼，玩家贴上去能爬。第一章密林主路用这个，装饰用那一条。

## 6. 推荐尺寸

对照现状：窗口宽 **1280**；猫碰撞约 **36×22**；精灵 `scale 0.12`。地砖必须和这只猫同一「一格大约一只蹲着的猫那么高」的量级。

| 类型 | 像素 | 原因 |
|------|------|------|
| 所有地形 Tile | **32×32** | 和猫体量匹配；PixelLab / Godot 最稳 |
| 半高单向台 | 32×16 或 96×16 条 | 薄，才像「跳上去的檐」 |
| 卵石 | 8～16 | 衬托猫脚 |
| 中石 | 24～40 | 可当跳点则顶面 ≥ 猫宽 36 的一半以上 |
| 大石 / 倒木 | 48～96 宽 | 独立 sprite |
| 装饰垂藤（一条） | 宽 16～32，高 **96～160** | 够长才像从台上挂下来 |
| 可爬藤 Tile | 32×32 | 竖着连成任意高 |
| 灌木 / 蕨 | 32～64 | 不超过猫身长太多 |
| 大树 | 冠 128～192 宽；干用 32 砖叠高 | 整棵一次出 320 高容易糊 |
| 存档石 | 48×64 | 比猫高，像地标 |
| 林屋门 | 64×96 | 猫能走过去的洞 |
| 收集物 | 16～24 | 发光点要干净 |
| 视差条 | 宽 640 或 1280，高 360 | 横向无缝；不要 1px 描边 |
| 光柱 | 宽 32～96，高 240 | 独立半透明图 |
| 粒子 | 8～16 | 落叶、花粉、碎土 |

**生成画布：** 给 AI 出图时，道具可以画在 256 画布里，但**有效内容**必须符合上表；透明边可以留。进 Godot 后按上表裁切。

## 7. 生成顺序（按商业管线，省试错）

先能走路，再能好看，再能藏。**不要**先画大树和林屋。

| 序 | 出什么 | 验收（过了才进入下一步） |
|----|--------|--------------------------|
| 0 | 锁色盘 + 锁图（A 猫 256 参考） | 绿是翠绿/墨绿，不是灰，不是荧光 |
| 1 | **T-grass + T-dirt + T-edge** | 三块横拼无缝；猫站上去脚不陷、不漂 |
| 2 | T-slope | 斜坡上走不卡 |
| 3 | L1/L2 远中景各一条 | 黑猫叠在上面还看得出轮廓 |
| 4 | S-rock 多尺寸一套 | 同一屏里有大有小，不像复制 |
| 5 | S-bush、小花、前景草 | F1 一屏能摆完「晨光林缘」 |
| 6 | **S-vine-deco 一条墨绿带叶** | 不是梯子、不是黄绿霓虹；你已否决梯子 |
| 7 | **T-vine-climb** | 猫能贴着爬；远处仍能看出「能爬」 |
| 8 | T-water-top / fill、岸、倒木 | F2 能过溪 |
| 9 | T-trunk + S-canopy + 一棵组合大树 | F3 能围成房间 |

## 氛围变化（同一套砖如何换心情）

| 区域 | 空气（极轻） | 装饰密度 | 光 |

## 进 Godot 时怎么挂（方案落地，不是现在改代码）

- 碰撞地：`TileMapLayer`（Physics）  
- 装饰砖：第二个 `TileMapLayer`（无碰撞）  
- 大树/石/藤：`Sprite2D` 或 `AnimatedSprite2D`  
- 远景：`Parallax2D`（Godot 4）三层  
- 可爬：藤砖层设成 climb 检测，或独立 `Area2D`；**装饰藤不要挂碰撞**  
- 猫：继续 `cat_player.tscn`，不换皮
