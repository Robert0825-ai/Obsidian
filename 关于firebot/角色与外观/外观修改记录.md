## 2026-08-15 · 待机拆成 idle1 / idle2（他说这样更有灵性）

- 他要的：一开始先普通坐着、尾巴微微晃，坐一阵再舔毛。所以新画 **idle1 = 普通坐着**，舔毛那套改名 **idle2**。
- idle1 三个姿势（尾巴贴地 → 半抬 → 尖端上卷）排成 `A A C C B B C C`，尾高 `64→83→91→83`，摆 27px（身高 5.7%），末帧接回第一帧。
- 游戏里：Idle1 一直循环；站住不动 4 秒播一次 Idle2，舔完自动回 Idle1（`cat_player.gd` 的 `idle_groom_delay` 可调；Idle2 在 SpriteFrames 里 loop=false）。另留 `Idle` 别名指向 Idle1。

**这次抓到一个审帧脚本原本会漏的坑**（值得记住）：

- idle1 画出来比 idle2 **小 28%**。两个动作各自都很稳、`AUDIT_OK` 也过了，因为归一化只在**单个动作内部**做。可一旦从坐着切到舔毛，猫当场大一圈——还是他一直烦的那个毛病，只是换成跨动作。
- 先试了「所有动作一起按面积归一化」，**方向是错的**：坐着的猫腿收在身子底下，剪影面积本来就比站着小，结果把 idle2 从 339 拉低到 281，整个坐姿比走路小 20%。
- 也试过找「跟姿势无关的尺子」：眼睛（红耳朵会被算进去）、白爪面积/爪高（同一动作里就在 17~29 飘，爬树因为角度是 43）——**都不够准，靠不住**。
- 最后的做法：`SCALE_ANCHOR = {"idle1": "idle2"}`，新动作对齐一个**已经认过的同姿势动作**。现在 idle1 = idle2 = 339，全部动作落在 339~378（差 11%）。
- 审帧脚本加了跨动作体量表 + 同姿势对必须 ≤6%；另出一张 `sheets/compare_actions.png`（每动作抽一帧、同脚线）给人眼看。
- 验收：`AUDIT_OK` + SpriteFrames `VERIFY_OK` + 场景 `VERIFY_OK`（含脚踩地检查）+ `PREFLIGHT_OK 21`。未覆盖 `idle.png`，未换 fighter。素材库旧的 `四脚猫/idle/` 留着当存档，没删。

## 2026-08-15 · 走路终于有循环了；改成量化验收

上一版的毛病（他说的「后腿不交替、dash 顺序怪」全都对得上）：

- **walk 不是走路，是滑行**。8 帧每帧看着都有腿，但整圈后爪间距是 `275→175→0→200`，后爪中心只挪了 16px；第 5、6 帧两只后爪还粘成一块。
- **dash 只有 2 个姿势**（`A A B B A A`），放起来是闪烁；其中 4 帧后爪只差 84px，等于并排。
- **jump 空中帧的猫小了一号**。它斜着放，包围盒被撑大，所以旧的体量检查没抓到。
- **climb 第 1、2 帧尾巴形状和后面完全不同**，身形 0.43 对别的帧 0.70，像猫在拉伸。
- **slide 3 帧一模一样**，等于静止图。

改了什么：

- walk 重画 4 个姿势（张开→收拢→张开换脚→收拢换脚），各占 2 帧。后爪间距 `230→64→274→23`，摆幅 31% 身长。
- dash 3 个姿势按真实步态排：收拢 → 推蹬 → 伸展，间距 `116→235→103`。身形一直是 4.2–4.4，全程长而低，不再缩成一团。Godot 里 dash 提到 14fps。
- slide 留 2 个姿势（第 3 帧只动尾巴尖）。jump 空中帧重画成同一只大小、身子放平。climb 弃掉那张瘦长的，换成和 climb_03/05 同族的三个姿势。
- 体量判据改成**数不透明像素**，不再用包围盒。新增身形（宽高比）检查。
- 帧图画布写死 1280×960、脚线 940；以前跟着「最大的那只猫」浮动，一改帧脚线就挪、猫在游戏里浮起来。`cat_player.tscn` 的 `AnimatedSprite2D.position.y` 跟着改成 -40。
- 新工具 `firebot/tools/audit_cat_frames.py`（量整圈，出 `AUDIT_OK`）；`verify_cat_test.gd` 加了「脚有没有踩在碰撞盒底边」，并且故意改坏验证过它真的会报错。
- 验收：`AUDIT_OK` + SpriteFrames `VERIFY_OK` + 场景 `VERIFY_OK` + `PREFLIGHT_OK 21`。
- 未覆盖 `idle.png`。未换 fighter。量化判据写进 [[生成提示词]] 和 look-lock 规则。
