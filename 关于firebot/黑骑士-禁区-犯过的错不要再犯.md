## 存档规矩

用户没说「保存动画 / 切帧 / 做 GIF」时：

1. 只生成给他看
2. 把**还没分割的原图**存进 `unsliced/`（一张图一帧按动作分文件夹）
3. 每个动作文件夹里留一张 **`未分割.png`**（人与人间隔要大，默认 480px），方便以后改间距
4. **不要**自动跑 `slice_and_animate.py`，不要自动更新 `frames/` 和 `gifs/`

只有他明确要保存动画时，才切帧、做 GIF。

Godot 用的单帧必须同一画布、脚对齐。当前 idle / walk / dash / slide / climb / attack 单帧都是 **1166×1145**。

Cursor 点开 GIF 经常只停在第一帧。展示效果用浏览器循环播。

## 腿：走路 / 跑 / 冲刺必须左右交替

默认生成图会一直画「靠近镜头的右腿在前」。那不是走路，是同一只脚在原地抖。

正确周期（面向右）：

| 阶段 | 靠近镜头的右腿 | 远处的左腿 |
|------|----------------|------------|
| 右脚接触 / 支撑 | 在前、踩地 | 在后 |
| 路过（passing） | 收到身下 | 从后向前摆过 |
| 左脚接触 / 支撑 | 在后 | 在前、踩地 |
| 路过回去 | 从后向前摆 | 收到身下 |

检查口诀：**画面最右边那只脚，有一半帧必须是远处的左脚。**  
如果 8 帧走路里有 6 帧都是右腿在前，作废重画。

可靠做法：先画一张「青腿=左/前、黄腿=右/后」的姿势示意图，再把示意图当参考去生成骑士。不要只靠文字说 left leg forward。

**示意图只借姿势，不借颜色。** 成品四肢必须是炭黑盔甲。曾把 `dash/06` 生成带青腿+黄腿，那是把调试色画进精灵了，禁止再犯。生成后扫一遍：成品里不该出现大块高饱和黄/青/蓝（缨的红除外）。

## 剑尖：每一帧都要有完整尖头

不是扁切口、不是缺一截、不是贴在画布右边缘。

- 生成时：剑尖右边和下边留大块灰空（不要让剑顶到画框）
- 带剑动作用「一张图一帧」，不要整表等宽切开
- 未分割表上人和人要隔开，否则一切会把上一帧剑尖切进下一帧

## 攻击顺序

准备 → 蓄力 → **白虚影就是挥砍那一帧** → 砍完定住 → 收回。

禁止「平刺完了才出白虚影」。先想整段动画再拆帧。

## 已经犯过、禁止再犯

1. 黑底或白底 + 黑盔甲 → 抠图把填充抠空。背景永远 `#888888`。
2. Idle 做成蹲 / 喘气下蹲。Idle = 站着，只动披风和红缨。
3. 盔甲变银、披风变红/蓝。锁定：近黑盔甲、深灰黑披风、只有缨是绯红、剑是银。
4. 攀爬带杆子 / 梯子 / 墙。只要姿势，不要杆。
5. 用整张表等宽切片直接做 GIF（骑士缩在灰条里）。
6. 冲刺六帧同一只脚在前、只动披风。

8. 攻击不要「平刺完了才出白虚影」。
9. 攻击/带剑的动作不要挤在一张表上。一帧一张图。
