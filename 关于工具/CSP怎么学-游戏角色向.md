# CSP 怎么学（yehai · 游戏角色向）

> 更新：2026-08-14  
> 原则：先会画「能用的角色」，别一上来学全部功能。  
> 目标：有脸、有表情的简笔游戏人 → 导出 PNG → 以后 Spine。

## 你不需要先学的

- EX / 长动画 / 多页漫画  
- 上百种笔刷、复杂厚涂  
- 和 Spine 抢活：连招动画仍用 Spine  

## 总路线（三句话）

1. **试用期内**：只练「界面 + 线稿 + 平涂 + 四表情」  
2. **每课 15～25 分钟**，画完一张小图就停  
3. **软件跟官方 Tips；人物表情跟简笔/Q 版教程**

---

## 第 0 周：能打开、能保存（1～2 天）

1. 装好 CSP，登录试用账号  
2. 新建插画：尺寸先 **512×512** 或 **1024×1024**  
3. 只记住 4 个东西：  
   - 笔（描线）  
   - 橡皮  
   - 图层（线一层、色一层）  
   - 保存 `.clip` + 导出 `.png`  
4. 官方：[CLIP STUDIO TIPS](https://tips.clip-studio.com/) 看「界面」「图层」入门各 1～2 篇  

过关：能新建 → 画几笔 → 存盘 → 导出一张 PNG。

---

## 第 1 周：有脸的简笔人（身体仍可很简）

每天画 **1 个小人**（15 分钟）：

| 天 | 画什么 |
|----|--------|
| 1 | 圆头 + 点眼 + 身体棍 + 四肢 |
| 2 | 同上，换笑脸 |
| 3 | 怒脸 |
| 4 | 惊脸 |
| 5 | 累脸（弯眼+汗珠，像你看的那种） |
| 6～7 | 挑一个表情，加双刀（两条线即可） |

口诀：**先脸后身**；表情靠眉、眼、嘴三笔。

B 站可搜：`简笔画 表情`、`Q版 五官`（跟步骤，别跟特效片）。

过关：同一身子，至少 **4 张不同表情** PNG。

---

## 第 2 周：键鼠画得顺一点

只学这几项（CSP Tips / 设置里找）：

1. **笔刷稳定/修正**（线会直很多）  
2. **放大画、缩小看**  
3. 线稿层锁定，下面新建上色层  
4. 颜色：平涂即可，先不搞复杂阴影  

过关：一张「双刀小人」线稿干净 + 简单填色。

---

## 第 3 周：为游戏做准备

1. 角色固定成「部件」想法：头 / 身 / 臂 / 刀（以后好进 Spine）  
2. 先整身画一张「标准站姿」当主图  
3. 头单独再画 4 表情（或整头重画 4 张）  
4. 全部导出 PNG，放到例如 `D:\ClipStudio\Works\stickman\`  

过关：站姿 1 张 + 表情头 4 张，能给 Spine 用。

---

## 每周固定资源（别贪多）

| 用途 | 去哪 |
|------|------|
| 软件按钮 | [CLIP STUDIO TIPS](https://tips.clip-studio.com/) |
| 表情/简笔 | B 站「简笔表情 / Q版脸」 |
| 动态感觉（可选） | YouTube `gesture drawing stick figure` |
| 动画进游戏 | Spine（另课），不是 CSP EX |

---

## 愚笨时用的规则（请照做）

1. **一次只学一个按钮**（今天只会「稳定笔」也行）  
2. 画砸了就新建图层，别删整个文件  
3. 对比对象用「昨天的自己」，别跟大神厚涂比  
4. 卡住超过 10 分钟 → 截图问师傅，写清「我想做____，卡在____」  

## 和买 PRO / 付款

试用期先学上面三周；好用再考虑买 PRO。  
没信用卡：试用优先；付费再看优动漫 / 其他国内可付方式（见聊天记录）。
