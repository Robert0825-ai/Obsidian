## 为什么你会觉得「梯子不稳」

常见组合问题：

| 设置 | 效果 |
|------|------|
| **全局模式** | 所有流量都走节点，节点一抖整机抖 |
| **TUN 虚拟网卡** | 从网卡层劫持，易和游戏/本机 `127.0.0.1`/显卡软件冲突 |
| **全局 + TUN 同时开** | 最猛，也最脆（See-through 曾因此 Gradio 502） |

模型已经下到本地后，**跑 WebUI / Godot 一般不需要梯子**。

## 三套开关（照抄）

### A. 日常上网（推荐默认）

**目标：** 刷网页、看文档、轻量翻墙，尽量稳。

| 项 | 怎么设 |
|----|--------|
| 代理模式 | **规则**（不要全局） |
| 网络设置 | **系统代理**（优先）；TUN 先关掉试稳不稳 |
| 节点 | 选延迟低的；别死盯一个「新加坡C」 |
| Clash 总开关 | 开 |

口诀：**规则 + 系统代理**。

若必须开 TUN（某软件不走系统代理）：仍用 **规则**，不要全局。

---

### B. 下模型 / 访问 Hugging Face（装 See-through、下大文件）

**目标：** 能连上 HF / GitHub，下得动几 GB。

| 项 | 怎么设 |
|----|--------|
| 代理模式 | **规则** 或临时 **全局**（下完立刻改回规则） |
| 网络设置 | 系统代理或 TUN 均可；以「能打开 huggingface.co」为准 |
| 节点 | 换几个测速，挑下载稳定的 |
| 注意 | 黑窗口/`install.bat` 跑的时候**不要中途关梯子**，也别乱切模式 |

口诀：**能下就行；下完改回 A。**

可选：国内镜像 `HF_ENDPOINT=https://hf-mirror.com`（有时比翻墙更稳）。  
本机代理端口常见：`127.0.0.1:7897`（以你 Clash 设置为准）。

---

### C. 本地跑 See-through / Godot / 本机网页工具

**目标：** 本机 `127.0.0.1` 畅通，不被代理拐走。

| 项 | 怎么设 |
|----|--------|
| 代理模式 | **直连**（最省事） |
| 或 | 规则模式，但确认本地地址不走代理 |
| TUN | **建议关**（曾导致 WebUI 502） |
| Clash | 可关；不关也行，只要别全局+TUN 硬拦 localhost |

See-through 启动：

1. 文件夹：`C:\Users\yehai\Projects\see-through-webui`
2. 双击 `run.bat`（已加：启动时临时绕过系统代理，降低 502）
3. 浏览器：http://127.0.0.1:7860  
4. 黑窗口保持开着

口诀：**本地干活 → 直连（或关 TUN）。**

## 不稳时 1 分钟排查

1. 看是不是 **全局 + TUN** 同时开着 → 先改成 **规则**，TUN 先关。  
2. 换节点测延迟；单节点挂了就换。  
3. 本地工具报 502 / 连不上 `127.0.0.1` → 切 **C 本地（直连）**。  
4. 只有 HF 下不动 → 切 **B**，或试 hf-mirror。  
5. Clash 流量长期 `0 B/s` 且网页打不开 → 检查订阅是否过期、节点是否全挂、Clash 总开关是否开着。
