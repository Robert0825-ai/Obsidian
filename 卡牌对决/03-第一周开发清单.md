## 本周验收

Play `scenes/battle.tscn` 能打完一场（某方生命 ≤ 0 出胜负字）：

- 攻击牌红、防御蓝、破防橙、功能灰（本周功能牌可以先不进组，颜色常量要先写上）
- 卡上只显示：费用、名称、伤害或格挡
- 玩家 / 敌人是不同颜色方块
- 预告是敌人头顶数字
- 完美格挡：方块闪白 + 跳字；不要粒子、不要刀光、不要动画资源

## 场景（.tscn）

主场景只设一个：`scenes/battle.tscn`。不要先做主菜单。

| 场景 | 节点要点 |
|------|----------|
| `scenes/battle.tscn` | 根 `Control` 或 `Node`。挂 `battle.gd`。放：玩家方块、敌人方块、手牌行、能量/怒气/生命文字、「结束行动」按钮、胜负 Label。 |
| `scenes/card_view.tscn` | 一张牌：`ColorRect` + 三个 Label（费用、名称、伤害或格挡）。脚本 `card_view.gd`。按类型设红/蓝/橙/灰。 |
| `scenes/actor_view.tscn` | 一个角色：`ColorRect` 方块、生命 Label、格挡 Label、头顶预告数字 Label。玩家一种颜色，敌人另一种。脚本 `actor_view.gd`。闪白改 `modulate`。 |
| `scenes/float_text.tscn` | 跳字：一个 Label，向上移后消失。完美格挡显示「完美格挡」，受伤显示扣血数字。不是特效图。 |

不需要：地图场景、卡组编辑、掉落界面、图集。

## 脚本（.gd）

| 路径 | 职责 |
|------|------|
| `src/app/constants.gd` | 已锁：`ENERGY_MAX = 7`，`DRAW_COUNT = 5`，`BREAK_MULT_GUARDED = 2.0`，`BREAK_MULT_OPEN = 0.5`。颜色：攻击红、防御蓝、破防橙、功能灰。`TEMP_PLAYER_HP`、`TEMP_ENEMY_HP`、`TEMP_RAGE_MAX`。 |
| `src/data/card_type.gd` | 枚举：`ATTACK` / `DEFENSE` / `BREAK` / `SKILL`（功能）。不要加新类型。 |
| `src/data/card_data.gd` | `Resource`：`id`、`display_name`、`cost`、`type`、`power`（攻击/破防=伤害，防御=格挡）。不写稀有度、升级、立绘路径。 |
| `src/data/actor_stats.gd` | 玩家与敌人分开：`max_hp`、`hp`、`block`、`energy`、`rage`、`defended_this_turn`。不要合成一份双方共用数据。 |
| `src/battle/deck.gd` | 抽牌堆 / 手牌 / 弃牌堆。抽 5、打出、回合结束弃光。抽空则洗回弃牌（漏洞 TEMP，注释标明）。 |
| `src/battle/enemy_ai.gd` | 本周 1 个敌人。每回合给一个预告伤害数字（整数）。到敌人阶段打出该伤害。不要技能树。 |
| `src/battle/battle.gd` | 状态机，严格：回能抽5 → 玩家行动 → 敌人按预告攻击（防御窗口用剩余能量打蓝牌）→ 清格挡、清能量、弃光手牌。胜负判定。 |
| `src/ui/card_view.gd` | 显示费用/名称/power；点牌通知战斗。能量不够则忽略或提示文字，不加新系统。 |
| `src/ui/hand_ui.gd` | 把手牌实例化成若干 `card_view.tscn`，排成一行。 |
| `src/ui/actor_view.gd` | 刷新生命、格挡、头顶预告数字；提供 `flash_white()`。 |
| `src/ui/float_text.gd` | 跳字。完美格挡 / 扣血共用。 |

Autoload 本周**不要**。常量用 `class_name` 或战斗节点引用即可。

`project.godot`：主场景 = `res://scenes/battle.tscn`。现有 `4.7` + Mobile 先不管；本周 Windows 能 Play。

## 本周占位牌（不是 10 张卡表）

写在 `src/data/starter_cards.gd` 一个函数里返回数组即可，不要做卡牌编辑器。

| 类型 | 颜色 | 卡上显示 |
|------|------|----------|
| 攻击 ×2（费用可不同） | 红 | 费用、名称、伤害 |
| 防御 ×1 | 蓝 | 费用、名称、格挡 |
| 破防 ×1 | 橙 | 费用、名称、伤害 |

功能灰本周可以零张，但 `constants.gd` 里灰色要先定。怒气只由完美格挡增加。

---

## 纯色怎么做（不要图）

- 牌：`ColorRect.color` 按类型。
- 玩家方块、敌人方块：两个不同的 `Color`，不是精灵。
- 预告：敌人方块上方 Label，只写数字（例如 `6`），不要图标。
- 完美格挡：`actor_view.flash_white()` + `float_text` 冒「完美格挡」。
- 不要 `Sprite2D` 贴图、不要 `.png` 进战斗、不要 AnimatedSprite。

---

## 遇到规则空洞

见 [[02-规则漏洞]]。本周最小 TEMP（写进注释）：

- 玩家阶段不能打防御；防御窗口不能打攻击/破防
- 本周 1 个敌人
- 一次窗口可连打多张蓝牌叠格挡
- 完美格挡每次攻击各判一次
- 破防不算「攻击牌」，不吃怒气强化（未确认前先这样，好写）
- 抽空洗弃牌

这些是为了能编译、能打完，不是新系统，也不是终锁。
