# 06 · 玩法说明：逻辑、可玩性、优点与不足

## 1. 这游戏在玩什么

一句话：**看预告、挡这一刀、拆这面盾。**

单人 1v1 短局卡牌格斗。没有随从场面，也不走炉石式铺板。核心体验是：

- 每回合开始先看到敌人要干什么  
- 你的回合主要负责输出或拆盾  
- 敌人要砍时，用剩余费用和手牌去「对数字」格挡  
- 完美格挡攒怒气；有盾时用破防专门拆  

目标是几分钟内打出胜负，靠读招和资源分配，而不是先靠厚养成碾压（养成是后段轻量层）。

---

## 2. 一回合逻辑（流程）

1. <span style="color:#8b9098"><em><s>能量回满 7</s></em></span> 能量回满 **5** → **先亮本回合预告** → 抽牌补到 5。<span style="color:#8b9098"><em><s>过夜留 2 张则再抽 3。2026-09-22 工程已接上：手牌多于 2 张时先盲留，留满再抽到 5。</s></em></span> **2026-09-27 留牌先撤下。** 回合结束整手弃掉，下回合再抽 5。  
2. **玩家行动**：可出直刺、破绽一击；不可出小盾、弹反。  
3. 结束行动：**不弃牌**；剩牌剩费进入敌人阶段。  
4. **敌人阶段**（见预告）：  
   - 轻斩 / 重斩 / 举盾斩 → 开防御窗口 → 出防御牌 → 结算这一刀  
   - 蓄力架势 → 本回合不砍；有盾；挂「下次斩更疼」  
5. 双方未用格挡清零；手牌**自选弃到 2 张过夜**（选时不可见下一回合预告）。  
6. 任一方生命 ≤ 0 → 胜负。

### 牌各自干什么

| 牌 | 作用 |
|----|------|
| 直刺 | 便宜削盾 / 打血 |
| 破绽一击 | 对方**当前有盾**时强；无盾时弱 |
| 小盾 | 仅在「要挨刀」的窗口出；可叠两张（更费） |
| 弹反 | 窗口内独占；格挡较高；完美时可反打一点 |

怒气：完美格挡叠层；满后强化**下一张**攻击，再清零。

### 四种预告在逼什么

| 预告 | 压力 |
|------|------|
| 轻斩 | 刀轻，常一盾可完美，偏稳节奏 |
| 重斩 | 刀重，完美更贵，要不要留费硬挡 |
| 举盾斩 | 同回合有盾有刀：拆盾与挡刀抢同一条能量 |
| 蓄力架势 | 本回合相对安全，但不能无偿打肉；下刀加伤，过夜要赌 |

过夜留 2 是盲的：留盾防斩，或留破防/刺赌举盾、蓄力——这是回合之间的第二条决策。

更细的数字与权重见 [[05-战斗规则锁定]]。

## 3. 可玩性（好玩在哪、会卡在哪）

### 好玩的点

- 决策短、反馈快：一回合内完成「看字 → 出手 → 挡刀 → 留牌」。  
- 读招真实：预告诚实、出手前可见，智斗来自分钱和留牌，不是骗招。  
- 输出与格挡分阶段：才有「留费挡刀」的紧张感。  
- 举盾斩把「拆盾」和「挡刀」绑在同一回合，比「敌人纯防守你尽管输出」有内容。  
- 规则面瘦（四种意图、四张牌），适合个人做完第一版，也适合反复打同一场练手感。

### 容易卡住的点（体验上）

- 新手可能不懂为什么盾只能窗口出、为什么要过夜留牌。  
- 见盾就破防，若数字没调好，决策会变薄。  
- 重斩 / 蓄力加重后，完美成本高，可能挫败。  
- 蓄力回合若盾太薄，仍可能变成「拆完继续打肉」。  

这些优先改 [[05-战斗规则锁定]] 的数字和权重，不先加新系统。

---

## 4. 优点

1. **买点清楚**：一句话能对外解释。  
2. **品类差异明确**：卖反应式格挡与拆盾，不是场面运营，也不易做成「又一个炉石」。  
3. **相对 STS 短战斗更瘦**：第一版不做大地图、卡池、多角色，范围可控，利于做完能上架的最小完整版。  
4. **逻辑可先于美术验证**：纯色占位就能判断好不好玩（见 [[00-美术与开发顺序]]）。  
5. **扩展方向干净**：以后加牌、加区域，多半是同一套环换内容，不必先推翻核心。  
6. **已避开早期大洞**：废除「纯防御 / 纯蓄力不攻击」的白打回合，改为举盾斩与蓄力架势。

## 5. 不足（诚实清单）

### 设计与体验

1. **决策深度有天花板**  
   第一版只有四张牌、四种预告，熟悉后可能感到「每回合在算同一套账」。深度要靠后段加牌和区域，不在第一周硬堆系统。

2. **破防仍容易公式化**  
   「有盾才强、无盾很弱」清晰，但也容易变成见盾必交破防。数字已压过一版，仍需试玩验证。

3. **过夜盲留对新手不友好**  
   看不见下回合预告是有意的张力，也可能造成「乱留 / 不知为什么输」。需要教学或战斗内提示，目前笔记里未做完教学设计。

4. **完美格挡门槛两极**  
   轻斩偏易、加重后重斩偏难；若手感不齐，会在「太稳」和「挡不住」之间跳，挫败或无聊。

5. **蓄力架势的「趣味」弱于举盾斩**  
   举盾斩交叉明确；蓄力更偏「这回合安全、下回合更疼」，节奏容易空半拍，要靠盾厚与下刀威胁撑住。

6. **怒气爽感依赖完美**  
   防不住就叠不满怒气；越崩盘越难靠怒气翻盘，和「用操作翻盘」的卖点可能打架（数值与满值仍可调）。

7. **单敌人、无地图时内容密度低**  
   战斗环本身成立，但若没有区域 / 多战 / 掉落，重复打同一场会腻得快。这是范围选择的代价，不是规则写错。

### 产品与制作

8. **养成、区域、卡组构建尚未闭合**  
   碎片、升星、三区域 Boss 等仍在总定位里，战斗锁之外大量内容未设计完，第一版「完整可上架」路程仍长。

9. **美术与主题未定**  
   纯色有利于验证玩法，但对外演示、商店页、情绪记忆都偏弱，需要第 3～4 步才补（见 [[00-美术与开发顺序]]）。

10. **代码与笔记可能漂移**  
    工程里曾有留 2、弹反、旧意图等试玩加料；必须以 05 为准对齐，否则试玩反馈会测错规则。

11. **个人开发、无完整上架经验**  
    平衡、新手引导、时长控制都要靠多轮试玩补课，没有现成团队套路可抄。

12. **对标期待**  
    玩家若拿完整《杀戮尖塔》比，会觉得系统少；需要宣传与范围上诚实：这是短局格斗环，不是大 roguelike 全集。

---

## 6. 小结

| 维度 | 判断 |
|------|------|
| 核心环 | 成立：读预告 → 输出/拆盾 → 挡刀 → 盲留牌 |
| 相对优势 | 买点清、差异大、范围可控、可纯色验证 |
| 主要不足 | 深度靠后段内容；破防/过夜/蓄力与完美门槛要试玩调；养成与美术未齐；需防代码与 05 不一致 |
