# 09 · 养成会不会搞废特色（定调）

日期：2026-09-15

## 结论

- **要**局外养成，否则短战斗留不住人。  
- **不要**用大养成定义游戏；游戏仍由战斗环定义。  
- **不要**第一版做「合成特殊卡主线」。  
- 认同结构：**短战斗 + 一串怪 + 局外变强**；单场因读预告对策而必须短。

## 什么想法容易搞废（该骂的）

1. 为了留人把单场拖长、堆爆发 → 和读预告节奏冲突。  
2. 融合/升星/碎片/商店/神器一起上 → 普通二游养成柜，特色被淹没。  
3. 特殊卡另搞规则（场面、连招表）→ 半成品炉石。  
4. 只加卡不删卡 → 牌库胀、新手手气挫败、单场变磨。  
5. 养成还没上就先做 Midjourney 全套 → 验证错误。  
6. 难度靠「不教规则 + 重数值」→ 劝退；应靠敌人预告配比与数字分层。

## 什么该坚持（特色）

- 预告诚实；攻防分阶段；破防打盾；完美攒怒；过夜盲留。  
- 新内容（怪、牌、区域）都是这套的变奏。
