## 目标

1. **交流**：日常能说、能听懂大意，不怕开口  
2. **阅读**：逐步能读说明、教程、文献，少用/不用整页翻译

## 推荐资源（辅助，不是替课）

- [British Council LearnEnglish](https://learnenglish.britishcouncil.org/) — 分级听力/阅读，免费靠谱

- [News in Levels](https://www.newsinlevels.com/) — 同一新闻三个难度，练「先懂大意」
