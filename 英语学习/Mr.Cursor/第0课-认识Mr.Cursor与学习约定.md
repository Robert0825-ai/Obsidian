## 今日三个「种子句」（先混个脸熟）

用在以后上课开头/结尾：

1. **I'd like to practice English today.**（我今天想练英语。）  
2. **Can you explain that again, please?**（能再讲一遍吗？）  
3. **I don't need the translation for every word.**（我不需要每个词都翻译。）

人话：上课时你可以中英夹着说；卡壳就用第 2 句。

## 学习方式小诊断 · 已答（2026-08-10）

1. **说和读都怕**：水平差 → 长文看不懂；想说时常不知怎么表达、会卡住。  
2. **怎么记**：不确定单一通道；自己感觉是 **经常出现**——常用到、或在不同句子里反复见到。  
3. **时间**：暂定、不稳定（Godot + 求职/可能长工时）。微课制。  
4. **「做游戏」**：已澄清 → 主要指用 **Godot/做游戏话题** 当英语素材，不是必须玩背单词小游戏。详见 [[学员画像]]。
