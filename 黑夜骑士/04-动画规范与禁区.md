# 04 · 动画规范与禁区

作者角色：动画监督 / QC  
目的：不再犯「顺序不对、最后一帧不对、颜色缺一块」。

## 1. Demo 怎么处理动画（已拍板）

**Demo 不生产走跑循环。**  
用：`Idle`（站）与 `Attack`（五帧播一次再回站）。  
位移靠代码，翻转靠 `flip_h`。  
攻击顺序：准备 → 蓄力 → 白虚影 → 定住 → 收回。禁止平刺完了才出虚影。

## 2. 以后做帧时的流水线

1. 锁一张标准站姿（朝右、右上光、色板齐）  
2. **一张一张**生成，不要并行同一循环的相邻帧  
3. 扣 `#888888`  
4. 对表（下面）  
5. 过了才能进 `SpriteFrames`

## 3. 检查表（每一圈必勾）

### A. 顺序

- [ ] 写好中文分镜再画：例如走 = 右脚接触 → 路过 → 左脚接触 → 路过  
- [ ] 文件名 `walk_01` … 与播放顺序一致  
- [ ] 不是「随机帅姿势串起来」

### B. 末帧

- [ ] 最后一帧能接到第 1 帧（尾巴/衣摆/剑位置只许慢变）  
- [ ] 末帧没有突然镜像朝左  
- [ ] 末帧没有突然变大变小

### C. 颜色

- [ ] 盔缨是绯红；披风是深灰黑；剑是银  
- [ ] 没有某一帧变成灰片/缺块/盔甲换成别的色  
- [ ] 没有莫名其妙少一只手、少一截剑尖

### D. 光与朝向

- [ ] 亮边在**右上**（进游戏）  
- [ ] 每一帧头在右、朝右  

### E. 体量（人 + 武器都要定）

锁图：炭盔待机（旧 `pixel-knight/unsliced/idle/01.png` 已删）。**不要**用 `cemetery_knight/knight_01` 当锁。见 [[13-拍板锁-2026-08-24]]

| 尺子 | 锁值 | 允许 |
|------|------|------|
| 盔甲像素（去掉剑、白虚影、缨） | 约 183000 | 82%～118% |
| 红缨宽度 | 约 208px | 70%～140% |
| 银剑像素 | 约 3250 | ≥55%；白虚影帧跳过 |

- [ ] 同一动作里人不能一帧大一帧小  
- [ ] 剑不能某一帧变短成小剑  
- [ ] **不要**只查脚到底到头顶：蓄力举剑会把小骑士撑得一样高  
- [ ] 跑 `pixel-knight/audit_knight_frames.py`，要 `AUDIT_OK`  
- [ ] 设计说明（为什么这样量）：[[设计说明-人物与武器体量]]  
- [ ] 脚底接触线同一高度（否则会跳）

## 4. 攻击帧（完整版预告）

建议最少：准备 → 蓄力 → 白虚影（挥砍）→ 定住 → 收回。  
禁止：平刺完了才出光。Demo 已按此五帧进 `SpriteFrames`。
