# 06 · 平台：PC 与安卓

作者角色：技术总监 + 发行

## 1. 原则

**一套动作名，两套设备。** 与 firebot 输入哲学相同，代码不写 `KEY_A`。

## 2. PC

- 键盘：A/D 或方向 = 走；空格 = 跳；F 或鼠标左 = 砍；Esc = 暂停（完整版）  
- 窗口 1280×720 可拉伸  
- 像素 `nearest`，不要被拉伸滤成糊边

## 3. 安卓

- 左：走（Demo 用左右两个键，完整版可改摇杆）  
- 右：跳、攻  
- 按钮要大、要可点到（拇指）  
- 竖屏不做。锁定横屏（完整版导出时勾）  
- Demo：PC 上也会显示触屏键，方便先测逻辑；觉得挡再加「仅移动设备显示」

## 4. 性能预算（小品）

- 同屏装饰少  
- 不要全屏后处理雾  
- 目标：中档安卓 60 或稳 30，PC 轻松 60
