你是「夜班的」：炭黑盔甲、深灰黑披风、绯红缨、银短剑。在**一张很大的黑森林世界**里走（像空洞骑士），墓园和城堡是里面的房间，去**击败吸血鬼**（最终 Boss）。神秘、匿名、夜间、带点压迫感。不是圣骑士，不是白袍红十字，不是赛博，也不是 firebot 的猫。

## 策划 · 这是什么游戏

| 项 | 锁 |
|----|----|
| 类型 | 2D 横版近战。长、很多房间、能回去。角色和房间都是积木。**第一局不要能力门。** |
| 给谁 | PC + 安卓，同一套动作名。这一局是长线，不是地铁打完一块区就结束 |
| 不是 | 马里奥、蝙蝠侠电影、猫头鹰《Night Knight》、firebot 猫、塔防、枪战 |
| 成功感 | 准、近、夜、你本来不该赢。不要神选、刷装备、加冕 |

核心循环（Q9、Q10）：

```
在黑森林大地图里走（荆棘、枯树）→ 路上打蜘蛛/蝙蝠
→ 进房间可能打精英（路上偶尔一两只）
→ 走进墓园房间、城堡房间（都在同一张图里，能回去）
→ 最终 Boss 吸血鬼 → 结局
```

灯和月亮只是好看，不改砍。房间能回去。第一局不要能力门。  
失败：很脆，挨几下就死，扣一条命，就近检查点重来。命用完仍回检查点，补几条命继续。不是回标题结束。

## 操作（锁）

脚本只听动作名，不写死键码。和 firebot 同一套字的，继续用，省得两套手。

| 动作名 | PC | 安卓 |
|--------|----|------|
| `Left` / `Right` | A D / 方向 | 左摇杆或左右键 |
| `Jump` | 空格 | 跳 |
| `Attack` | F / 鼠标左 | 攻 |
| `Pause` | Esc | 暂停 |
| `Climb` / `Down` | W S / 上下 | 摇杆上下（爬上 / 爬下） |

| `Block` / 弹反 | — | 规格见 Q15–Q16，**第一局不做** |
