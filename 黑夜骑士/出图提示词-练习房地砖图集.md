## 先说给你听（怎么交给那个 AI）

1. **新开一个对话。** 不要把和 Grok 的长聊天贴进去。
2. **必须用会画图的模型。** 只会写字的模型给了提示词也没有 PNG。Cursor 里是能出图的模型；ChatGPT / 即梦等选「生成图片」。
3. **一次只干一件事。** 先只要「一条四格横图」。不要同一条消息里再要角色、要整座林子。
4. **把下面「开场白」+「提示词」整段粘贴。** 提示词用英文（出图模型更听这个）。开场白用中文，告诉它格子顺序和禁止项。
5. **把现成 `tiles/blocks.png` 当参考图附上**（若那个 AI 能看图）：告诉它「四格位置、种类顺序必须和这张一样，只换画风」。
6. **像素尺寸它经常不听。** 你要的是 **128×32、无缝挨着四格**。它若出成 1024 宽：下载后用最近邻（Nearest）缩到 128×32，不要用平滑缩放（会糊）。
7. 图来了先看：是不是从左到右仍是 **地、墙、能爬、单向台**；格子有没有被字、骑士、UI 污染。不对就只重出这一张，不要接着要 20 种砖。
8. **没签字不要当终皮**，也不要覆盖到 firebot 玩家。练习房若要试：备份旧 `blocks.png` 再替换同路径；`blocks_tileset.tres` 的碰撞和 `kind` 才能继续用。

若要贵模型只审方案、不要量产图，新对话可粘：

## 开场白（中文，贴在提示词前面）

```
你只出一张图：横条瓦片图集，不是海报，不是角色。

游戏：2D 横版，黑森林夜里的冷石/枯藤，压迫感。不是马里奥，不是空洞骑士盗图，不是赛博霓虹，不是暖绿童话林。

硬规格：
- 整张正好 4 个正方形格子，从左到右紧挨，中间不要缝、不要编号、不要文字。
- 每格 32×32 像素。整张 128 宽 × 32 高。
- 每格画面填满格子，不要灰边、不要透明一圈（进游戏会露缝）。
- 光从右上来。像素硬边，不要油画、不要照片。
- 从左到右种类锁死，不许换序：
  1）地面（能站的石地）
  2）墙壁（挡路的石墙）
  3）可攀爬（荆棘藤/枯藤，人要能走进格子，所以不要画成实心砖块）
  4）单向台（顶边更亮的薄石沿，看起来能站上面）

禁止：蘑菇、问号砖、管道、亮绿圆丛、红白点蘑菇、骑士、猫、剑、UI、字母、数字、水印。
```

## 出图之后你怎么收进练习房

1. 备份：复制 `tiles/blocks.png` 另存，例如 `tiles/blocks_color_backup.png`。
2. 新图处理成 **128×32**、四格紧挨、PNG。
3. 用新图**覆盖** `C:\Users\yehai\Documents\room\tiles\blocks.png`（文件名不变）。
4. 回到 Godot，等导入（出现 `blocks.png.import`）。不要只把图丢在桌面。
5. 打开 `Scenes/main.tscn`，点 **Tiles**，看房间里黄红蓝品红是否变成新皮。碰撞和爬绳仍走旧 `kind`，因为格子顺序没变。
6. 若某格画成了实心墙但应该是绳子：那是图错了，重出第 3 格，不要改 `kind` 去迁就坏图。

**不要**把四种砖的左右顺序换掉。换序等于 `kind` 对错材料。

### PixelLab 大图放哪、能不能直接用（2026-08-24）

可以放进练习房工程，Godot 会导入。**不能**当 `blocks.png` 的替换件，也**不会**自动出现在房间里。

- 图放哪都行，只要在 `C:\Users\yehai\Documents\room\` 下面。`scripts/maps/` 能放，但那是脚本目录，容易和 `.gd` 混在一起。更合适：`tiles/lookdev/`。
- 你现在那张 `pixellab-tileset-...-godot-....png` 是 **768×256**（按 32 切大约 24×8 格），是自动拼接地形表。练习房真正在用的是 `tiles/blocks.png`：**128×32、只有 4 格**（黄地 / 红墙 / 蓝绳 / 品红单向）。格子数对不上，覆盖会把碰撞和 `kind` 全对错位。
- 放进去之后：打开 `Scenes/main.tscn` 不会自动换成墓园石。要试皮，另做一个 TileSet、另加一层 TileMap，或只当预览。爬绳 / 单向仍用原来四格。

## PixelLab 网页（Maps / Tilesets / Tiles）点哪个

界面最上有三个：**地图 Maps**、**瓦片集 Tilesets**、**瓷砖 Tiles**。中间那句「创建你的第一张地图」**不要点**。

那是 PixelLab 自己的**地形图工坊**（常见是俯视拼地图），不是 Godot 练习房要的「四格图块源」。点了会空出一张 Map，和 `blocks.png` 对不上。

**「地图 Maps」是什么意思：**  
瓦片集 = 一堆能重复贴的小砖。地图 = 用这些砖在 PixelLab **里面**铺出来的一张大图（哪一格是地、哪一格是水）。用来在网页上预览「这套砖铺开长什么样」，也可以继续在上面摆树、房子。  
它**不是** Godot 的 `TileMapLayer`，也**不是**黑夜骑士工程里的房间 `.tscn`。也**不是**游戏里的背景（天空、远山那种不能踩的一层）。更接近「在网页上预览的一整张关卡地面」。导出多半是 PixelLab 自己的图/工程，不能拿来当 `main.tscn` 里那间房。要玩还是得把砖进 Godot 再刷。

**看起来更方便？** 在 PixelLab 里铺图、看效果，是方便。那张地图**不能**代替 Godot 里的碰撞、爬绳、单向、换房。若只导出成一张大图当背景，人其实踩不了那些「地」——还得在 Godot 再铺一层能站的砖。所以：画画方便，当游戏关卡并不更省事。

| 你要点 | 不要点 | 为什么 |
|--------|--------|--------|
| 上面的 **瓦片集 Tilesets** | 中间按钮 **创建你的第一张地图** / 分页 **地图 Maps** | 地图是在 PixelLab 里铺世界，不是给 Godot 的四格说明书 |
| 若出现 **横版 / Sidescroller / 平台跳跃** | **俯视 / Top-down / Wang** | 黑夜骑士是侧面横版，俯视砖进不去现在的房间 |
| 只要四格玩法砖（地/墙/爬/单向） | 只靠 PixelLab 瓦片集当一对一替换 | PixelLab 瓦片集是「能自动拼接的平台地」，**不是**黄红蓝品红那四格 |

**只认屏幕上的英文标签。** 横版页是 **Center Tile**（平台石头）和 **Top Tile**（盖在顶上的那一层）。不要说下层/上层——俯视页才是 Lower Terrain / Upper Terrain，和横版不是同一套字。

**Sidescroller 要和黑夜骑士素材同一套画风。** PixelLab 默认绿草/亮砖对不上。锁：夜、炭、冷灰石、少量苔、光从右上；禁止马里奥绿丛、赛博霓虹、空洞骑士盗图。助手**没把握** PixelLab 一次长得和炭盔锁图一模一样——尽量靠 **Import 参考图** + 下面这两段字。

**先 Import（比改字更重要）：**  
瓦片集页的 **Import**，丢一张已经认的黑夜骑士图当风格参考（墓园石/枯枝件；没有墓园图就用炭盔待机锁图，只借笔法和色，砖上不要出现骑士）。没有参考图，模型会画成自己的卡通砖。

**Center Tile**（平台石头，整段替换）：
```
dark cemetery stone platform, same pixel style as a charcoal-armored night knight sprite: hard-edged pixels, high density not chunky 8-bit cubes, selective 1px near-black outline, light from upper-right. Palette: charcoal #1a1a22, near-black purple #0b001b, cold grey stone, tiny muted moss only. Worn cracked bricks, oppressive night, not cartoon, no neon cyan, no gold trim, no red except accidental specks
```

**Top Tile**（顶盖，不要绿草地，整段替换）：
```
almost no grass. thin dried moss drips on the stone top, dull olive-grey not bright green, no wildflowers, no Mario turf, no candy bushes. same lighting upper-right, same hard pixel edges as the center stone
```

**Walkable — not set：** 不管。

**Transition Size：** 15%～25%。太大顶上会变厚草皮。

**Roundness：** **0**（blocky）。

**Raggedness：** 20%～45%。

**Platform Thickness：** **auto** 可以先留。

**Enhance descriptions with AI during generation：** **不要勾。** 勾了会改写你刚贴的 Center / Top 原文，还可能自己挑成亮绿、变回默认草皮，和锁死画风打架。

**Detail Level：** 想靠近炭盔那种密像素，改 **Highly detailed**；先试可以 **Medium detail**。

**Shading Level：** 改 **Detailed shading** 或 **Highly detailed shading**（光仍要像右上）。**Medium shading** 往往更平、更卡通。

出图后对照炭盔/墓园件：是不是同一套冷灰炭石。偏绿、偏圆、偏玩具就重出，不要当终皮。仍**不要覆盖** `tiles/blocks.png`。

### Mode Pro（你截图这页：Lower Terrain / Upper Terrain）

**不一定更好。** Pro 32×32 标了 EXPERIMENTAL，一次大约 **20 generations**。这一页是**俯视两种地**能拼（Wang），框名是 **Lower Terrain** 和 **Upper Terrain**。  
不要把 Sidescroller 的 **Center Tile / Top Tile** 那两段（platform + 顶上苔）贴进这里——那是侧面平台盖层，不是俯视两种地面。

练习房是侧面走跳：要平台砖请回到 **Sidescroller**。只有你想先看「墓园石地接到枯林地」的俯视拼图，才用 Pro。

**Tile Size：** 可留 **32×32**。不要选 16。64 更实验、更贵。

**Lower Terrain**（第一种地面，整段，尽量别截断）：
```
dark cemetery flagstones, charcoal #1a1a22, near-black #0b001b, cold grey stone, tiny muted moss only, hard-edged dense pixels, selective dark outline, light from upper-right, night oppressive, not cartoon, no neon cyan, no gold
```

**Upper Terrain**（第二种地面，不是「平台顶上的草」）：
```
dry black-forest thorn floor, dead brown leaf litter, dull olive-grey moss drips, same pixel style as lower stone, no bright green grass, no wildflowers, no Mario turf, no candy bushes
```

**Transition Height：** **0%**（flat）。对。拉高会出悬崖墙，练习房用不上。

**Transition Size**（若和 Height 是同一类滑条、说明写着 higher = height difference）：先 **0%～10%**。25% 容易出一层台阶墙，不像侧面房间那种平地砖。

**Edge Shape：** 选 **Square**。不要 Round。

**Roundness：** **0%**（blocky）。60% 会把角磨圆，和炭盔硬边像素打架。

**Raggedness：** **0%** 可以（干净边）。想要墓石裂一点就 20%。

**Side Wall Thickness / Placement：** Transition Size 已经接近 0 时几乎看不出，可留默认 10% / 50%。

**Transition Description**（两种地交界长什么样。不要用默认的 muddy dirt wall。整段替换）：
```
thin seam of cracked cold grey cemetery stone meeting dry thorn litter and dull olive moss, hard-edged pixels, light from upper-right, no mud wall, no bright grass, no flowers, no cartoon dirt
```

**Enhance descriptions with AI during generation：** **勾掉。**

**Detail Level：** **Highly detailed**

**Shading Level：** **Highly detailed shading**

**Advanced Options：** 先折叠着就行。若有 Enhance descriptions，**不要勾**。

生成仍当试稿，不要覆盖 `blocks.png`。

若地图方向是 **Sidescroller**，请用上面的 **Center Tile / Top Tile**，不要用这两段 Lower / Upper。

四格（地/墙/爬/单向）换皮：回到 **Tiles**，尺寸 32，一次一格，用本文 B1～B4。
