给谁：个人开发、对着编辑器点  
引擎：**Godot 4.7**，界面按**简体中文**写标签  
练习工程：`C:\Users\yehai\Documents\room`  
场景：`Scenes/main.tscn`，场景树里那层叫 **Tiles**（类型 `TileMapLayer`）  
官方对照：[使用 TileSet](https://docs.godotengine.org/zh-cn/4.7/tutorials/2d/using_tilesets.html)

不做插件。下面是引擎自带做法。

## 先记住三句话

1. **往房间里摆格子**，和 **改「这种砖」有什么本事**，是两件事、两个底部分页。
2. 属性写在 **TileSet（图块集）** 上，不是写在场景树里每一块单独的物体上。你房间里刷了 80 块黄地，它们共用黄地这一份属性。
3. **同一种黄图，但有的结冰、有的不结冰** → 不要再画一张黄图，用 **备选图块**。看起来还是黄的，只是另一份属性。

对照你现在的色板（从左到右）：

| 图 | 大概是 | 已经有的本事 |
|----|--------|----------------|
| 黄 | 地面 | 实心碰撞 |
| 红 | 墙 | 实心碰撞 |
| 蓝白条 | 绳子 | 无碰撞、能爬（`kind = 2`） |
| 品红 + 绿顶 | 单向台 | 薄顶碰撞 + 单向 |

工程里已经有一层自定义数据叫 `ice`（结冰，是/否）。下面仍从「怎么加一层」写起，你若列表里已经有 `ice`，**第 3 节跳过，从第 4 节开始刷**。

## 1. 打开对的场景、点对的节点

1. Godot 左下 **文件系统**，进 `Scenes`，双击 **`main.tscn`**。  
   不要开 `node_2d.tscn`（那是两个碰撞盒，不是这套色块房间）。
2. 左上 **场景** 树，点 **Tiles**。  
   名字右边类型应是 **TileMapLayer**。点中后，中间视口会是那间红墙房间。
3. 看编辑器**最底下**一排标签。这里通常有两个，不要混：

| 底部分页标签 | 干什么 | 人话 |
|--------------|--------|------|
| **TileMap** | 在**中间大视口**的格子上左键摆砖、右键擦 | 布置房间 |
| **TileSet** | 改左边那条色块图：**这种砖**撞不撞、有没有结冰 | 改砖的说明书 |

你截图里若中间是「绘制属性 / 物理层 0」，那是在 **TileSet** 里给砖画碰撞，**不是**在往房间里砌墙。房间已经砌好了。

4. 右边 **检查器** 顶端应写着节点名 **Tiles**。往下找到 **Tile Set**（图块集）。  
   槽里应是 `blocks_tileset.tres`（有时只显示成 `block` 一类短名）。  
   **点这个资源的名字/折叠箭头把它展开**，不要只看节点自己的「物理 / 启用」。

---

## 2. 两个「检查器」别点错

Godot 这里最容易晕，因为屏幕上有两块都能改属性：

| 位置 | 标签附近写什么 | 改的是谁 |
|------|----------------|----------|
| **窗口右边**那一长列 | 检查器，标题是 **Tiles** | 这一**层**地砖：用哪份 TileSet、层是否启用物理 |
| **窗口底部 TileSet 面板的中间一列** | 选中某一块黄/红之后才会填满 | **这一块砖种类**的碰撞、自定义数据 |

加「全图都有的新字段」（比如结冰）→ 在**右边**展开 TileSet，找 **自定义数据层**。  
给黄地勾上结冰、给红墙不勾 → 在**底部 TileSet**，用 **选择** 或 **绘制**。

---

## 3. 加一个新属性（不用新画基础图块）

目标：所有已有色块都能带一个「结冰」勾选。图画一个都不用加。

1. 场景树仍点着 **Tiles**。
2. 右边检查器里展开 **Tile Set** 资源（点进 `blocks_tileset.tres`）。
3. 往下滚，找到分组 **自定义数据层**（英文界面是 Custom Data Layers）。
4. 点该分组右边的 **+** / **添加元素**（Godot 数组那一排加号）。  
   会多出一层，默认名字可能是空的或 `custom_data_0` 这种。
5. 填这一层的两格：

| 标签 | 你填什么 | 为什么 |
|------|----------|--------|
| **名称** | `ice`（建议英文，和代码里字符串一模一样） | 脚本用 `"ice"` 去读；改中文名字代码也要一起改 |
| **类型** | **bool**（下拉里也可能写 **布尔**） | 只有是 / 否，当勾选框用 |

还可以再加别的层，例如：

| 名称 | 类型 | 用途 |
|------|------|------|
| `kind` | **int** / **整数** | 你们已经有了：0 地、1 墙、2 绳、3 单向 |
| `hurt` | **int** | 踩上去每秒扣多少血 |
| `slip` | **float** / **浮点** | 摩擦力倍率 |

**加层这一步不会改画面。** 只是声明「砖可以带这个字段」。默认全是关 / 0，要你再赋给具体哪一种砖。

6. `Ctrl+S` 保存。保存的是 TileSet 资源，房间场景也会显示已改。

## 4. 给「某一种砖」填这个属性（选择模式，一次一块）

适合：只改黄地，红墙不动。

1. 确认场景树点的是 **Tiles**。
2. 点编辑器底部的 **TileSet** 分页（不是 TileMap）。
3. 底部面板**左上**有一排小工具，点 **选择**（箭头；和旁边的 **绘制** 画笔要分开）。  
   你之前截图停在 **绘制**，改单块属性请先切回 **选择**。
4. 底部**左边**那条色块图（官方叫图集；你工程里有时也叫 **基础图块** 那一块）上，**左键点黄地**。  
   黄块周围应出现选中框。
5. 看底部面板**中间那一列**（不是窗口最右边）。往下找 **自定义数据** / **Custom Data**。
6. 应能看到你起的名字 **ice**。点成勾上（bool 为开）。  
   `kind` 若在，黄地保持 `0`，不要改成绳子。
7. 再点红墙，确认 **ice** 是关的。这样只有黄地滑。

人话：你改的是「黄这种砖的说明书」。房间里已经摆好的黄格会立刻共用这份说明书，不用重刷房间。

## 5. 一次刷很多种砖（绘制模式）

适合：8 种地都要结冰，一块块点太慢。

注意：这里的「绘制」是画在**底部那条色块图**上，**不是**画到中间大房间。

1. 底部仍是 **TileSet** 分页。
2. 左上工具改点 **绘制**（画笔）。你截图里就是这个。
3. 中间列会出现 **绘制属性**（或「要绘制的属性」一类）。点开下拉。
4. 不要停在 **物理层 0**。往下找 **自定义数据**，再选 **ice**。  
   若显示成 **自定义数据 1** 而不是名字，多半是旧版显示 bug；以检查器里你起的 **名称** 为准，按添加顺序：0 常是 `kind`，1 常是 `ice`。
5. 下拉下面会出现这个属性的值：bool 就是一个勾。**先勾上**，表示「画上去的都是开」。
6. 到**右边/图集上的色块**上，对要结冰的那些砖 **左键点（可拖）**。点过的砖就带上 `ice = 真`。
7. 若要「擦掉结冰」：把勾取消，再点那些砖，等于刷成关。

**和物理层绘制的区别：**

| 绘制属性下拉选 | 你在图集上点砖时实际改什么 |
|----------------|----------------------------|
| **物理层 0** | 碰撞多边形（实心、单向）。你截图正在干这个 |
| **自定义数据 → ice** | 结冰勾选 |
| **地形** | 自动拼接用的，这间练习房先不用 |

画完切回底部 **TileMap**，才能继续在大视口砌房间。

## 6. 同图不同行为：备选图块（仍不用新基础图块）

目标：还是那张黄地，一份普通实心，一份单向（只能从下往上站、不能从下顶穿）。

官方原话：自定义数据是跟**图块种类**绑的；要变体，就 **创建备选图块**，再改备选上的数据/碰撞。

### 6.1 做出第二份黄地

1. 底部 **TileSet** 分页。
2. 工具用 **选择**。
3. 在图集里 **右键点黄地（基础那一张）**。
4. 菜单里点 **创建备选图块**。
5. 备选出现在**这张图集的右边**（基础色条的右侧，可能要在底部面板里**往右拖/中键平移**才能看见）。  
   另一做法：选中黄地后，备选那一栏旁边有个大 **+**，效果等于再创建一份备选。
6. **左键点那份备选**（不要只点左边基础黄块）。中间列标题会变成在改备选。

中间列和基础砖不完全一样，你会多看到例如：

| 标签 | 意思 |
|------|------|
| **备用 ID** | 这份备选的编号。**不要随便改**，房间里已经刷过的格子会对不上 |
| **渲染 > 水平翻转** | 左右镜像 |
| **渲染 > 垂直翻转** | 上下镜像 |
| **渲染 > 转置** | 配合翻转做旋转 |
| **渲染 > 调制** | 乘一个颜色（可略变色，图还是同一张） |
| **物理层** | 碰撞，和基础砖一样改 |
| **自定义数据** | `kind`、`ice` 等 |

### 6.2 重要坑：备选不会自动抄基础砖的碰撞

官方写明：新建备选时，**基础砖的属性不会继承**。看起来还是黄的，碰撞可能是空的。

所以点中备选之后，在中间列 **物理层 0**：

1. 让碰撞编辑器那一块获得焦点（点多边形编辑区空白处）。
2. 按键盘 **F**：生成默认矩形碰撞（整块实心）。
3. 若要单向台：把矩形改成**只有顶上一薄条**（可删掉下面的点，或只留靠上的边），再勾 **单向** / **One Way**。  
   你们成品品红砖就是这种：顶绿条 + 单向。
4. 需要的话再勾这份备选的 **ice**。

工程里已经有一份黄地备选（单向）。底部点黄基础砖后，右边 **备选图块** 里应能看到。没有就按上面新建。

### 6.3 把备选刷进房间

1. 底部改点 **TileMap** 分页。
2. 场景树仍是 **Tiles**。中间大视口是房间。
3. 在 TileMap 的图块调色板里：先点**黄地**，再在备选列表里点**那份单向黄**（和基础黄是两个选项）。
4. 在房间格子上 **左键** 刷，**右键** 擦。
5. 左边基础黄、右边备选黄，**画面可以一样黄**，站上去手感可以不一样。

这就是「Unity 里复制一份砖资源再改检查器」在 Godot 里的对应：复制的不是 PNG，是 **备选 ID**。

## 7. 什么时候才要新的「基础图块」

| 你想要的 | 做法 |
|----------|------|
| 黄地也能结冰 | 自定义数据层 + 给黄地勾 `ice` |
| 有的黄地结冰、有的不结 | 黄地的一份备选勾 `ice`，基础不勾；房间里刷两种 |
| 黄地改成单向 | 备选，改物理层单向；或直接改基础（那所有黄地都变单向） |
| 新颜色、新图案（尖刺图、水图） | 才要在图集里多一格 **基础图块**（或换 `tiles/blocks.png` 再切） |

换皮以后：同一套 ID 顺序，只换 PNG，碰撞和 `ice` 还在 TileSet 上。不要为了换皮把种类推倒重来。

## 8. 代码里怎么读（游戏运行时）

属性是给人玩的。勾了不算完，脚本要问格子：「你结冰吗？」

练习房玩家脚本：`scripts/player.gd`。现在爬绳看的是 `kind == 2`，或图集坐标 `(2, 0)`。结冰可以同样问 `ice`。

人踩在某一格上时：

```29:40:C:\Users\yehai\Documents\room\scripts\player.gd
func _on_rope() -> bool:
	if tile_map == null:
		return false
	for offset in [Vector2(0, 0), Vector2(0, 10), Vector2(0, -10)]:
		var cell := tile_map.local_to_map(tile_map.to_local(global_position + offset))
		if tile_map.get_cell_source_id(cell) == -1:
			continue
		var data := tile_map.get_cell_tile_data(cell)
		if data and int(data.get_custom_data("kind")) == 2:
			return true
		if tile_map.get_cell_atlas_coords(cell) == rope_atlas:
			return true
	return false
```

### 名词

| 写法 | 来历 | 人话 |
|------|------|------|
| `tile_map` | 你指给玩家的那层 **Tiles** | 问哪一层地砖 |
| `cell` | 格子坐标，整数对，例如 `(3, 5)` | 脚下那一格 |
| `get_cell_tile_data` | TileMapLayer 的函数 | 取出这一格用的那份「砖说明书」 |
| `data` | 类型 `TileData` | 说明书本身；空格子是 `null` |
| `get_custom_data("kind")` | 按**名称**取值 | 引号里必须和自定义数据层的 **名称** 完全一样 |
| `== 2` | 整数比较 | 你们约定 2 = 绳子 |

### 语法点

- `"kind"`、`"ice"` 是**字符串**，左右英文引号，大小写敏感。检查器名称写成 `Ice`，代码写 `"ice"` 会读不到。
- `data and ...`：先确认有说明书，再读。空格子没有 `TileData`，直接读会报错。
- 备选黄地：`get_cell_tile_data` 拿到的是**那份备选**的数据，不是基础黄的。所以备选上勾的 `ice`，只对刷了备选的格子生效。

结冰示例（以后要滑时再接到移动上）：

```gdscript
var data := tile_map.get_cell_tile_data(cell)
if data and bool(data.get_custom_data("ice")):
	# 人话：这一格说明书上结冰是开的
	pass
```

### 行号速查（爬绳这一段）

| 行 | 代码 | 作用 |
|----|------|------|
| 32 | `for offset in [Vector2(0, 0), Vector2(0, 10), Vector2(0, -10)]:` | 脚心、偏下、偏上各查一次，避免差一像素判不到绳 |
| 33 | `var cell := tile_map.local_to_map(...)` | 把世界坐标换成格子坐标 |
| 34 | `get_cell_source_id(cell) == -1` | `-1` 表示这格没砖，跳过 |
| 36 | `var data := tile_map.get_cell_tile_data(cell)` | 拿说明书 |
| 37 | `data.get_custom_data("kind")` | 读自定义数据层 **kind** |
| 39 | `get_cell_atlas_coords(cell) == rope_atlas` | 退路：看是不是图集第 3 格（蓝绳） |

## 9. 对照你现在的界面（防走错）

你最近一张编辑器图里：

- 场景树 **Tiles** 已选中 → 对。
- 底部分页在 **TileSet**，工具是 **绘制**，绘制属性是 **物理层 0** → 这是在给色块**画碰撞**，不是在房间里摆砖，也不是在加 `ice`。
- 要加属性：右边展开 TileSet → **自定义数据层** → 添加；再在 TileSet 里把绘制属性换成 **自定义数据 / ice**，或用 **选择** 点单块勾。
- 要砌房间：底部分页改成 **TileMap**，对着中间大视口刷。
