## 他要解决什么

类银河要一张能自己选路的大地图。拆成两块：

1. **数据：** 每间房在世界的哪里、门通哪、怎么切房  
2. **显示：** 小地图怎么画、没去过的怎么藏  

房间本身是独立场景（地砖、怪、美术），叫 **world room**。地图上的白块只是代表那间房，叫 **map room**。

---

## 构思（人话）

- 世界怎么连，**只在一张「世界地图」场景里定义**，不要在 30 个房间文件里互相填对方路径。  
- 真房间里放 **MapMetadata**：怎么画到地图上 + 这一间有哪些门口。  
- 门口是 **RoomTransition**（Area2D）：角色碰到就切房。  
- 世界地图上用 **MapTransition** 把「A 房的某扇门」和「B 房的某扇门」配成一对。  
- 玩的时候：碰到门 → 拿这扇门的 ID → 问世界地图对面是谁 → 卸掉旧房、装上新房、把人放到对面那扇门。  
- 现在只留当前一间在内存里，以后再预加载隔壁。

## 他在编辑器里怎么操作

门口若手摆，会和镜头边对不齐、走廊高度对不上、人会飞到半空。他改成：

1. **镜头边画出来**（黄线 + 红边，缩放也不丢）  
2. **门口大小用检查器一个数字拧**，改大小不带动出生点  
3. **门口方向一个参数**；蓝块红边对齐黄线镜头边，就算摆对  
4. 创建门口时自动生成 **RoomTransitionData** 资源（名字 + 唯一 ID）  
5. 世界地图上：点两个 map room → 下拉选各房的门 → 连上  

显示地图：先试「把地砖缩小当小地图」（300 间掉到 40 帧，废了）→ 改成房间里一层只给地图用的看不见砖 → 生成贴图/多边形。没探索过的格子怎么藏，他风格没定完，先搁着。
