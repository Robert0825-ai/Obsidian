对照：[[视频笔记-巨大地图怎么做]] · [[概念问答-根基]]

你看了 [Making a Massive Metroidvania Map](https://www.youtube.com/watch?v=FI0-yz5Xcz0)，觉得比 MetSys 更有用：真房间以后能直接贴图，门口和连法单独一张世界地图管。这一刀按他的**数据 + 换房**做了简化版。科幻小地图着色器没做。

---

## 设计原因

MetSys 的正本是格子 `MapData.txt`。格子好画小地图，但：

- 房间外形只能方格拼，拼不出空洞骑士那种弯边
- 真场景要另外「分配」上去，门口怎么对齐镜头要自己猜
- 你已经在插件界面里卡住过（单元格颜色 ≠ 爬藤物体）

他那套把正本拆开：

1. **world room**：一间一个 `.tscn`，地、墙、以后的贴图都在这里改
2. **world map**：只负责「谁连谁」，不负责玩
3. 玩的时候内存里只留当前一间，碰到门再卸旧装新

以后换炭盔精灵、换地砖，是换房间里的图，不是推倒换房逻辑。

---

## 他用的是 Godot，不是 Unity

截图左上角是 Godot；房间文件是 `.tscn`；脚本是 `MapMetadata.gd`。Unity 里对应的会是 `.unity` 场景和 C#。黑夜骑士也用 Godot 4.7，所以是同一套搭法，不是换引擎。

他的一间房，场景树大概是：

```
房间根节点（例如 TestRoom2）
  MapMetadata          ← 这一间的名字 + 门口名单
    RoomTransition_上  ← 真门口（Area2D，人走进去就换房）
    RoomTransition_下
  GroundTiles          ← TileMap 画地；我们现在先用色块墙代替
```

检查器里他点 `MapMetadata`，能看到 **Room Name** 和 **Transitions** 数组（把门拖进去）。控制台那句 `Creating transition resource...` 是脚本自动给每扇门建一个 `.tres`（门的身份证）。我们现在是手写好 `resources/transitions/*.tres`，再拖到门口的 `data` 槽里，意思一样。

## 在编辑器里怎么搭（对照他的截图）

工程：`C:\Users\yehai\Projects\blackout-knight`。先打开已有的一间，看懂再复制。

1. 文件系统点 `scenes/rooms/spawn.tscn`（出生林缘）。
2. 场景树点 **MapMetadata**：右边检查器里有 `room_id`、`room_name`、`transitions`。这就是他截图里那一块。
3. 点 **RightDoor**：这是 `Area2D` + `room_transition.gd`。检查器里 `direction` = 右，`data` 指着 `spawn_right.tres`。人走进这块就会换房。
4. 点 **CameraLimits**：黄框是这一间镜头边。门口的红边要对齐这条边（和他视频里一样）。
5. 打开主场景 `scenes/game.tscn`，点 **WorldMap**：下面每个子节点是地图上的一块（`MapRoom`），`LinkSpawnMouth` 这类是「A 门 ↔ B 门」。玩的时候这张图藏着，只拿来查对面是谁。

**你要新开一间时（和他同一流程）：**

1. 复制一间 `scenes/rooms/` 里的 `.tscn`，另存新名字。
2. 改地面（现在是色块；以后换成 TileMap 或贴图，根节点和门口留下）。
3. 门口：场景树加点 `Area2D`，挂 `scripts/room_transition.gd`，摆在房间边缘。
4. 新建一个 `resources/transitions/某某.tres`，填 `id`（全世界唯一，例如 `hub2_left`），拖到门口的 `data`。
5. 在这间的 `MapMetadata` 里填名字，把新门口拖进 `transitions`。
6. 打开 `game.tscn` → `WorldMap`：加一个节点挂 `map_room.gd`，填 `room_id`，把新 `.tscn` 拖到 `world_room`。
7. 再加一个空节点挂 `map_transition.gd`，填两边的房间 ID 和门 ID。保存，F5 走进那扇门。

不要在房间 A 里填「对面是房间 B 的路径」。连法只写在 `WorldMap` 上。这就是他比 MetSys 好用的那一点。

## 详细代码解释

### 碰到门之后发生什么

`RoomTransition` 发现玩家进来，就叫 `Game.request_transition`：

```gdscript
var pair := world_map.lookup(from.data.id)
var scene := world_map.scene_for(str(pair.room_id))
await _swap_room(scene, str(pair.dest_id))
```

| 名词 | 人话 |
|------|------|
| `from.data.id` | 这扇门的身份证，例如 `spawn_right` |
| `lookup` | 去世界地图翻：这扇门对面是哪间、哪扇 |
| `scene_for` | 那间房对应哪个 `.tscn` |
| `_swap_room` | 把新房装上，人放到对面门口**里侧**，再丢掉旧房 |

语法：`await` 表示「等这一帧物理算完再往下」，避免人和旧门还叠在一起就又触发一次。切完后 `_grace = 0.25` 再挡 0.25 秒，防止刚出来又撞回去。

### 人为什么不站在触发器上

门口脚本里有一个叫 `Spawn` 的记号，按方向往房间里面挪 80 像素：

```gdscript
Dir.RIGHT:
    _spawn.position = Vector2(-SPAWN_IN, 0)
```

人话：右门在房间最右边，出生点往左挪，这样人出现在地砖上，不出现在「再走一步又换房」的蓝块里。

### 以后贴图改哪

改 `scenes/rooms/某某.tscn` 里的地板、墙。`MapMetadata` 和门口节点留下。世界地图那几条 `MapTransition` 不用动，除非你新开一扇门。

## 这一刀故意没做

- 检查器里下拉选门（先手填 ID）
- 小地图科幻着色器、战争迷雾
- 预加载隔壁房间
- 爬藤 / 冲刺 / 滑铲 / 短剑（方块先能走跳换房）
- MetSys 不进这个工程
