## 详细代码解释

### 1. 场景里的两套动作

`scenes/demo.tscn` 里 `SpriteFrames` 有两个名字：`Idle` 和 `Attack`。

Idle 只有一张站图，循环。Attack 五张，不循环，速度 10（每 1.0 时长 = 0.1 秒）。

人话：按砍，从准备播到收回，播完脚本把它切回站着。

语法：`loop: false` 表示播到最后一张就停，等脚本收。`duration: 1.1` 在白虚影那张，让「砍」比蓄力短、看得见，但不拖。

### 2. 出刀时脚本干什么

```gdscript
func _start_attack() -> void:
	_attacking = true
	_attack_left = attack_time
	anim.play(&"Attack")
	_sync_hitbox()
```

| 名词 | 人话 |
|------|------|
| `_attacking` | 现在能不能再按砍（砍的时候先锁住） |
| `attack_time` | 万一动画结束信号没来，0.95 秒后强制收刀 |
| `&"Attack"` | StringName，Godot 用来当动画名的短标签 |

人话：按下 Attack 动作（F 或鼠标左或虚拟「砍」），开始播五帧。

### 3. 判定只在砍的那两帧

```gdscript
const HIT_FRAMES := [2, 3]

func _sync_hitbox() -> void:
	hitbox.monitoring = anim.animation == &"Attack" and anim.frame in HIT_FRAMES
```

| 帧号 | 图 | 开判定？ |
|------|----|----------|
| 0 | 准备 | 否 |
| 1 | 蓄力 | 否 |
| 2 | 白虚影 | 是 |
| 3 | 砍完定住 | 是 |
| 4 | 收回 | 否 |

人话：举剑时碰不到人；白光扫过去和定住那一下才能打中木桩。

语法：`anim.frame` 从 0 起算。`in HIT_FRAMES` 是「在这个名单里吗」。`monitoring` 打开 Area2D 才真正检测重叠。

### 4. 朝左时身子不跑偏

贴图像素里人偏左、剑偏右。`flip_h` 只翻图，偏移要跟着翻：

```gdscript
anim.offset.x = sprite_body_offset_x * facing
```

`facing` 朝右是 `1`，朝左是 `-1`。人话：左右走时碰撞盒还罩在肚子上，不会翻完人去了剑还留在右边。

### 5. 无界面检查

`tools/verify_knight.gd` 对每张 `res://assets/knight/attack_0N.png` 做 `load()`。打印 `KNIGHT_ASSETS_OK` 才算能交给他 Play。
